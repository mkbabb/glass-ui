## §0 · THE THESIS, IN ONE PARAGRAPH

Our glass is not glass. Four independent authored causes were proved by the tri-fold verdict, and the
first of them is still live at HEAD: a blanket seeds `--glass-cell-backdrop-filter: none` onto the
direct-content subtree of seven plate classes (⊘ `material.css:66`, 17 read-sites across 11 files),
so **the designed rungs are structurally unreachable inside any plate** — and the comment above the
line writes the kill up as the mechanism working. But the blanket is only the first cause, and
FROST §1.3 already measured what curing it alone buys: ρ 17-25, which is f5 — the specimen the owner
called *poor*. The rest of the defect is a photometric one. Our plate paints an **additive cream
veil** at α 0.30-0.95 derived from `--card`, wears **four white legs**, **lifts** mean luminance in
six places, and spends its whole opacity budget on paint where the exemplar spends it on **frost**.

This spec re-cuts the material on one law:

> **Occlusion is bought with radius. Legibility is bought with ink. Neither is ever bought with
> alpha.** The medium has exactly three axes — **thickness** (blur radius, per rung), **ink** (a
> subtractive veil, per rung), and **chroma** (saturate, one value for the whole medium). Brightness
> is not an axis. A rung is a *thickness of the same glass*, never a different material.

Everything below is that law made into tokens, files, mechanisms, deletions, and falsifiable
acceptance. The ladder's five hand-tuned alphas, five hand-tuned radii, ten saturate values, six
brightness lifts, four white legs, and the entire parallel `--glass-tint-*` axis collapse into
**four numbers**: a radius base, a radius ratio, a veil base, a veil step.

## §2 · THE RUNG TABLE — four numbers, derived, monotone by construction

### 2.1 · Thickness — one base, one ratio

The radius series is **geometric with ratio 2^(1/3) ≈ 1.26**, anchored on the measured grasp-rest
radius **16px** (EXPERIMENTS Row 38, the capture-validated constant) placed at `resting`, the
canonical consumer plate.

```css
/* tokens/glass.css — replaces five hand-tuned radius literals */
--glass-blur-base:  16px;   /* the canonical resting plate — the measured grasp-rest radius */
--glass-blur-ratio: 1.26;   /* 2^(1/3): ONE step of the frost series */

--glass-blur-wash-radius:     calc(var(--glass-blur-base) / var(--glass-blur-ratio) / var(--glass-blur-ratio));
--glass-blur-quiet-radius:    calc(var(--glass-blur-base) / var(--glass-blur-ratio));
--glass-blur-resting-radius:  var(--glass-blur-base);
--glass-blur-floating-radius: calc(var(--glass-blur-base) * var(--glass-blur-ratio));
--glass-blur-overlay-radius:  calc(var(--glass-blur-base) * var(--glass-blur-ratio) * var(--glass-blur-ratio));
```

Resolves **10.08 · 12.70 · 16.00 · 20.16 · 25.40 px**. Every calm rung is inside F-6's expected
[10,22] band; the heaviest rung sits at 25.4, inside the exemplar band (f1 22px · f4 26px · the grasp
prototype 26px) and above the calm band **by design** — overlay's job is occlusion, and it buys it
with thickness, not paint. `--glass-level` continues to multiply the radius, so the a11y/opaque
escape is untouched.

**F-6 is thereby executed, not asserted:** the banked "the blur radius is not the problem"
(`WAVES.md:481-483, 504-506`) is struck; wash moves 1px → 10.08px, a **10×** change on the rung the
prior record called innocent.

### 2.2 · Ink — one base, one step

The veil becomes an **ink** (F-4 / R-6: subtractive, derived from an ink, never additively from
`--card`; the warm-cream read arrives by **transmission + saturate**, never by painted cream).

```css
--glass-veil-base: 0.22;   /* the resting rung's ink alpha — CAPTURE-DECIDED in [0.16, 0.26] */
--glass-veil-step: 0.03;   /* one rung of ink */

--glass-veil-wash:     calc(var(--glass-veil-base) - 2 * var(--glass-veil-step));  /* 0.16 */
--glass-veil-quiet:    calc(var(--glass-veil-base) -     var(--glass-veil-step));  /* 0.19 */
--glass-veil-resting:  var(--glass-veil-base);                                      /* 0.22 */
--glass-veil-floating: calc(var(--glass-veil-base) +     var(--glass-veil-step));  /* 0.25 */
--glass-veil-overlay:  calc(var(--glass-veil-base) + 2 * var(--glass-veil-step));  /* 0.28 */
```

**Dark arm — one line, not a table:** `.dark { --glass-veil-base: 0.25; }` (one step up: the deep
canvas needs one more rung of ink for the same silhouette read). The entire `.dark` alpha ladder,
saturate table, and brightness table **die** (§7.1).

**Why this band and no other — the arithmetic, not the taste.** F-8's reachability identity is
`σ_kept ≤ (1 − α)`. The content band (wash/quiet/resting) claims *transmission*, so it must clear
G-FROST-TRANSMISSION's σ arm with headroom for the blur's own σ cost; at α ≤ 0.22 the ceiling is
≥ 78%, leaving ~8 points for the blur. The overlay band claims *occlusion*, and its honesty test is
that it occludes by **blur** (hf_kept → ~0) rather than by **paint** (σ_kept still ≥ 60%) — §11's
band-split acceptance. The base is the ONE capture-decided number in the entire table; the step and
both series are fixed by construction.

### 2.3 · Chroma — one value for the whole medium

```css
--glass-saturate: 1.55;         /* the calm medium. Measured grasp-rest 1.50; deep ceiling 1.80 */
--glass-saturate-grasp: 1.75;   /* measured, EXPERIMENTS Row 38 */
--glass-saturate-deep: 1.8;     /* unchanged, glass-deep.css — the upper bound */
```

**Mode-invariant.** Chroma is a property of the *medium*, not of the rung and not of the mode: the
same pane of glass concentrates the same light in both themes. The dark arm's five-value saturate
table and the five-value light table both die. This is where the ⚠ CONTRADICTION recorded at
`WAVES.md:513-526` lands: Q-1 already **struck it as stale** (the veil is the defect, the saturate is
innocent), and the reconciled direction — transmission saturate **up** where a backdrop sample
exists, plate chroma + white rim **down** — is exactly this table plus §7.2's white-leg collapse.
1.55 sits between the measured rest (1.50) and the exemplar band, under the 1.8 ceiling, and is the
ONE knob a consumer retunes.

### 2.4 · Brightness — not an axis

Struck at all **seven** sites (⊘ §1). F-5's signed luminance arm is the law: **a rung that lifts mean
L fails; dims within 10% pass.** The composed rung recipe becomes, in both modes, one line:

```css
--glass-blur-<rung>: blur(calc(var(--glass-blur-<rung>-radius) * var(--glass-level)))
                     saturate(var(--glass-saturate));
```

### 2.5 · The plate paint — one flat mix, no nesting

```css
--glass-veil-ink: oklch(0.28 0.035 70);   /* light: a warm near-black. Plain per-mode pair */
/* .dark */ --glass-veil-ink: oklch(0.17 0.030 70);

/* per rung, resolved at the element (the substitution seam the ladder already uses) */
--glass-veil-alpha: calc(var(--glass-veil-rung) * var(--glass-level));
--glass-veil:       oklch(from var(--glass-veil-ink) l c h / var(--glass-veil-alpha));
--glass-plate-escape: color-mix(in srgb, var(--card) calc((1 - var(--glass-level)) * 100%), transparent);
```

Painted as `background-color: var(--glass-plate-escape)` + `background-image: linear-gradient(var(--glass-veil), var(--glass-veil))`.

- At `--glass-level: 1` the escape leg is transparent and the veil is the rung's ink — the shipped identity.
- At `--glass-level: 0` (reduced-transparency / forced-colors) the veil vanishes and the plate is solid `--card` — the existing opaque escape, through the **same** machinery, no parallel recipe.
- At `--glass-level: 0.3` (prefers-contrast: more) the plate is 70% card under a 0.3×rung ink — firmer and darker, exactly the coordinated escape `a11y-fallback.css` already documents.
- **Zero nested `color-mix()` endpoints** — `oklch(from …)` is the house single-level idiom (already shipped at `material.css:219-220`) and `G-WK-COLORMIX-BUDGET` (the WebKit crash class, born-RED at `morph.css:125`) is honored by construction. This is a hard constraint on any alternative construction.

## §3 · THE TINT AXIS FOLDS INTO THE VEIL — one chromatic writer

Today two chromatic axes darken the same plate: the veil (`--glass-bg-*` from `--card`) and the tint
(`--glass-tint-source` × `--glass-tint-strength`, clamped continuously off the observer's
`--glass-backdrop-luma`). Under F-4 they are the **same channel** — the veil *is* the ink — and two
writers on one channel is the ≤2-pair violation BG §3.3 already ruled against `--glass-fill-tint`.

**THE FOLD.** The observer-driven clamp re-points from `--glass-tint-strength` onto
`--glass-veil-rung`, preserving its exact shape (floor · knee · earned lerp · AA ceiling):

```css
--glass-veil-rung: clamp(
    var(--glass-veil-<tier>),
    calc(var(--glass-veil-<tier>) + 2 * var(--glass-veil-step) *
         max(0, (var(--glass-backdrop-luma, 0) - var(--glass-backdrop-luma-knee)) / (1 - var(--glass-backdrop-luma-knee)))),
    calc(var(--glass-veil-<tier>) + 2 * var(--glass-veil-step))
);
```

A calm/unsampled backdrop resolves **exactly** the rung's own ink (the honest calm identity — a plate
over an unknown backdrop never falsely darkens); a measured-bright backdrop earns up to **two more
rungs of ink** and no more. The `@container style(--glass-backdrop: light)` bucket stays the **band
driver** (a consumer/shell declaring what it knows); the luma clamp stays the **dynamic refinement**.
No double-ownership, zero new compositing seams, and the *entire* `--glass-plate-tinted` recipe plus
both `:where()` clamp blocks in `ladder.css` (~80 lines) delete.

**What survives the fold, unchanged:** the `contrast-color()` ink flip in the bright bucket
(re-keyed onto the luma signal), the `--on-glass-muted` / `-strong` third-state registers, the
overlay band's own darken, the disjoint-selector discipline. **What dies:** `--glass-plate-tinted`,
`--glass-tint-source`, `--glass-tint-strength`, `--glass-tint-strength-floor`,
`--glass-tint-strength-aa`, `--glass-tint-ink` (renamed `--glass-veil-ink`, one home).

**Consumer break, named:** `--glass-tint-strength: 0%` and `--glass-tint-source` are documented
consumer escapes. Their successor is `--glass-veil-rung: 0` and `--glass-veil-ink`. Clean break, no
alias (no-backwards-compat law); relay filed at **#76 W-CONSUMER-BAND** with a MIGRATION table per
repo found by the **G-RELAY** whole-universe walk (the *generated* 15-root universe, S-10 — never a
remembered repo list). ⊘ 27 in-repo files touch the axis; the dock (`adaptive-legibility.css`,
`shell.css`, `search.css`, `dock.css`, `GlassDock.vue`) is the largest single consumer and its cure
rides #47's lane per ⊕²⁰(e).

## §6 · THE GRASP REGISTER — `styles/glass/grasp.css`

Implements TR **§0.S** (the sequenced-floor cross-cover with the decoupled veil and a bounded
over-frost gate). Its four clauses are honored exactly; the *construction* below is simpler than the
two-rung form and satisfies each clause by construction rather than by sequencing luck. Every
deviation is named at §6.6.

### 6.1 · What grasp is

The material **opens under the hand**. A grabbed surface — a slider range being dragged, the dock
plate being held — dilates two rungs of thickness and sheds two rungs of ink, so the world behind it
comes *forward* while your finger is on it. This is the wave's breath-of-life affordance and it is a
**material** register, not a light one: it fires zero light responses (G-6/X-B, EXPERIMENTS §Row-38 —
grasp *is* the gain move), and it mints **no scale writer** (W-CHIP's `1 → 1.015 → 0.97 → 1` ladder
is the one scale authority; the dilation is the affordance). The E-3 naming duty is discharged here:
**the two named consumers are `.glass-track-well`'s range under `[data-held]` (⊘ live at
`Slider.vue:425/439/475/588`) and the dock plate under `useDockHold`'s `data-held` edge (⊘
`useDockHold.ts:54`)** — two-plus at the cut, per #27 and #47. A third consumer requires no new
mechanism: the register is a class pair plus one attribute.

It does **not** consume `data-engaged` — ⊘ 0 hits library-wide (MOMENTUM-CENSUS §1). Wiring the
ENGAGED rung is #26/#47's row; this register keys off the attribute its consumers already write.

### 6.2 · The construction

Three parts, one new element:

1. **The host keeps its own rung, permanently.** Its `backdrop-filter` never fades and its opacity is
   never below 1. Clause 2's `(1 − o_g)(1 − o_r) ≡ 0` therefore holds **trivially at every frame**,
   with no sequencing to get wrong and no 25%-raw-substrate window to measure (the measured defect
   was `25% raw substrate at o = 0.5` under the complementary crossfade — that geometry no longer
   exists).
2. **One engage-only carrier** — `.glass-grasp-frost`, an `aria-hidden` child, `position:absolute;
   inset:0; border-radius:inherit; pointer-events:none; z-index:-1`, mounted **only** while
   `[data-grasp]` is set or the release envelope is running. It carries **only** a `backdrop-filter` —
   no background, no border, no veil, no rim. The host declares `isolation: isolate` **on the grasp
   register only** (not on the ladder), so the carrier paints above the host's own background and
   below its content, and its backdrop is the host's already-frosted, already-veiled composite:
   **the quadrature of §6.4 is then literally the physics, not an analogy.**
3. **The veil lerps on the host.** `--glass-veil-alpha` is a registered `@property <number>`, so it
   interpolates natively — monotone by construction, endpoints exact at every age. Clause 1's
   decoupled veil is satisfied at its strongest form: the veil lives on **one always-opaque,
   never-filtering, never-fading layer** (the host itself), so the measured stacking identity
   `1 − (1 − α_rest)(1 − α_grasp)` — which produced 0.472 dark / 0.426 light and is reproducible to
   three decimals at three seats — **has no two layers to act on**.

### 6.3 · The values, derived not literal

```css
--glass-blur-grasp-radius: calc(var(--glass-blur-rung-radius) * var(--glass-blur-ratio) * var(--glass-blur-ratio));
--glass-veil-grasp:        calc(var(--glass-veil-rung) - 2 * var(--glass-veil-step));
--glass-blur-grasp:        blur(calc(var(--glass-blur-grasp-radius) * var(--glass-level)))
                           saturate(var(--glass-saturate-grasp));
```

**Grasp is exactly two ladder steps, in both channels, at once.** On `.glass-resting` this resolves
**25.40px / veil 0.16 / saturate 1.75** — reproducing the capture-validated prototype (26px / 0.18 /
1.75) to **0.6px and 0.02α**, from a derivation that contains no grasp-specific literal. On
`.glass-floating` — the rung whose α (0.25) the prototype actually sat on — it resolves veil **0.19**
against the measured **0.18**: Δ0.01. The convergence is corroboration, and it is the reason the
series anchors where it does.

### 6.4 · The bound is constant, and the bound is the gate (clause 4)

Stacked Gaussians compose in quadrature. With the grasp radius fixed at `ratio² = 1.5876 ×` the host:

```
r_peak = √(r² + (1.5876 r)²) = 1.877 r
r_peak / r_grasp = 1.877 / 1.5876 = 1.182×
```

**1.182× at every rung, in every mode, by construction** — inside clause 4's `≤ 1.25×` ceiling with
margin, decaying monotonically to `r` as the carrier fades. This closes a real hole in the banked
form: a *fixed* 26px grasp rung over the 25.4px overlay rung would peak at **1.41×** and breach the
gate; the derived ratio makes the breach unconstructible. The over-frost direction matches the grasp
move (thicker, never thinner), so the monotone-dilution law holds through the whole envelope.

### 6.5 · Motion — by name, both channels

| leg | channel | register | clock |
|---|---|---|---|
| entry (rest → grasp) | both | **a true 0 ms discrete step** — no crossfade, nothing to cover (§0.S clause 2, honored verbatim) | — |
| release: carrier opacity 1 → 0 | EFFECTS | `--ease-standard` | `--spring-dock-duration` |
| release: `--glass-veil-alpha` grasp → rung | EFFECTS | `--ease-standard` | `--spring-dock-duration` |
| the carrier unmount | — | fires on `transitionend`, never on a JS timer | — |

**Why `dock` and not a literal.** The measured envelope is **177.9 ms** (CAPTURE ADDENDUM). The named
clocks that bracket it are `press` (settle 0.12 s) and `dock` (settle **0.22 s**, register text: *"A
brisk liquid morph for the dock and its coordinated contents"*). `dock` is chosen: it is the liquid
morph register, it is the register the larger of the two named consumers already lives in, and it
mints **no new clock** — the clock-fence arm on `G-SPRING-ONE-JOB` (⊕⁴ U-39: *a spring owns its own
clock*) is honored, and #26 remains the ONE spring authority. The measured 177.9 ms is recorded as
what the prototype happened to use, not as a requirement.

**Why the entry is discrete, and why that is not a liquid-weight breach.** The universal liquid-weight
edict asks that motion carry inertia. A grab is not motion the interface authors — it is *direct
manipulation*, and inertia on the response to a finger reads as **lag**, not weight. The weight lives
in the release, where the material lets go on the dock spring. §0.S ruled the discrete entry and this
spec implements it; the ground is recorded here so no later seat reads it as an omission.

### 6.6 · Deviations from §0.S, named

| §0.S clause | this construction | status |
|---|---|---|
| 1 · decouple the veil onto one always-opaque never-filtering layer | the **host** is that layer; the ink lerps on a registered `@property` | **stronger** — no separate veil element exists to stack |
| 2 · never both below one; rest steps to 1 first, grasp fades | the host never leaves 1; only the carrier fades | **satisfied by construction**, the ordering hazard removed |
| 3 · the forcing falsifier (a floor α<1 leaks `(1−α)²`; a ≡0 floor on veil-carrying rungs stacks to .426) | no rung carries a veil except the host, which never fades | **the failure mode is unconstructible** |
| 4 · peak effective radius ≤ 1.25× the grasp rung | **1.182× at every rung, constant** | satisfied, and now *provably* so |
| 5 · rest cost stays zero (engage-only mount) | ONE carrier mounts, not two | **halved**: the measured +1.07 ms/frame at 32 plates (≈33 µs/resting rung) is zero at rest either way; #69 owns the many-surface arithmetic |
| 6 · falsifiers armed | §13 | carried, plus one new arm (the isolation paint delta) |

**The one paint delta this construction introduces, declared:** `isolation: isolate` on the grasp
register changes what the specular `::before`'s `mix-blend-mode: plus-lighter` blends against (the
host's own composite rather than the page). Scoped to two consumers, and it is a π cell at §12, not a
promise. If the π reds, the ratified default is to drop `isolation` and give the carrier `z-index: 0`
with the host's content lifted — a strictly worse branch (it re-introduces a stacking dependency on
consumer markup), recorded so it is one word away.

Struck: `--glass-highlight` (**the token**, both arms — §5b's two-channel law kills a third leg
regardless of α; C-4 corrected the dark value to 0.08 as a *table* correction only, and 0.08 does not

its under-shadow, its ink, and its transmitted saturated chroma. **This is the riskiest single value
in the spec and it is armed at §13 F-3.**

The `::before` retains only the pointer-tracked gleam whose rest intensity is **0** — an unwired
surface paints nothing, which is already the shipped `@property initial-value: 0` intent, presently
