## Scope

Four distinct substrate additions in the metric/table family:

1. **Toggle card-variant CVA compound rule** (`beec35e` toggle hunk) — `<ToggleGroupItem variant="card">` had `h-auto` declared, but the `size` axis (default `h-10`) won the equal-specificity source-order race, clamping card toggles to a fixed height that their icon-over-label-over-description stack overflowed. A `compoundVariants` entry re-asserts `h-auto` for every `card` × `size` pair — CVA emits compound classes last, so the card now sizes to its content.

2. **MetricStack `register` prop + `--metric-row-value-clamp-cqi` token** (`9ba68ca`) — adds `register: "audacious" | "result"` prop to `<MetricStack>`. The `"audacious"` default preserves the poster-scale hero clamp bit-for-bit. The `"result"` register retunes all three value-clamp arms for a compact ledger layout inside a bounded card — including routing the previously hard-coded `34cqi` middle arm through the new `--metric-row-value-clamp-cqi` token so consumers can opt the whole register down.

3. **DataTable responsive card-per-row layout** (`1c6c3e5`) — new `responsive?: boolean` + `cardBreakpoint?: number` props. Below the breakpoint (container-driven via `useElementSize`), the table collapses to a stacked card-per-row layout: first column = card header + row-actions docked beside it; every other column = label/value pair. At/above the breakpoint the tabular layout renders unchanged. Preserves select + context-menu row behaviour across both layouts.

4. **MetricStack label-clamp tokens + tighter value ceiling** (`d244dd5`) — follow-on to `9ba68ca`. The label, not the value, is the binding row-height term in the `result` register (uppercase + tall line-box). Routes the label clamp through `--metric-row-label-clamp-{min,cqi,max}` (4 tokens), mirroring the value-clamp family; defaults preserve audacious-poster label behaviour bit-for-bit. Tightens the `result` value clamp ceiling (3rem, 9cqi) so a 4-row stack seats in a chassis-clamped card with measured headroom.
