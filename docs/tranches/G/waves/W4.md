### Design fidelity gate

Every story must land a deliberate, design-language-committed choice that's visible in <2 seconds of looking. Corporate-safe demos fail the gate. The orchestrator records pass/fail per story in `audit/W4-design-fidelity.md`, with a screenshot or single-sentence rationale per row. Bold-maximalist commitment is the bar; a story that "could be from any UI library" fails.

### Manifest taxonomy

Update `demo/stories/manifest.ts` so:

- Foundations runs colors → cream → golden-ratio → flourishes → typography → icons → radii → motion (or whatever order makes the design language read top-down).
- Primitives groups: status / badges / metric-badge / pulse / icon-stamp / skeuo-controls / swatch / color-pill / notification-dot / pop / weight / kbd / etc.
- Containers: card / cream-card / paper-card / floating-panel / etc.
- Motion: scroll-type / display-axes / bezier-canvas / timeline / etc.
- Compositions: hero-quiet / audacious-hero / math-paper / dictionary-pronunciation / prose-block / etc.
