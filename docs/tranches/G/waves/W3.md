# G.W3 - Components + CVA Branches + Composables

**Opens after**: W2 close.
**Agents**: 4-5 (disjoint component families).
**Hard gate**: every new component mounts in dev; CVA branches type-check; slot-class props cover prior `:deep()` sites; runtime tokens module exports the new constants; every src/ artefact has ≥2 call sites or is a primitive other artefacts depend on.
**Status**: complete (closed 2026-05-04 — orchestrator + 5 dispatched lanes + 3 residual-recovery agents post watchdog stalls; 14 new custom packages, 14 CVA branches, 4 composables, 3 slot-class props, 5 runtime helpers, 3 keyframes, 1 transition pair; W1 + W2 orchestrator-direct edits had to be recovered after a residual agent's git-stash dance reverted them; build/typecheck green; `audit/W3-component-proof.md` records evidence).

## Purpose

Land the components, CVA branches, slot-class props, composables, and runtime-tokens additions that downstream stories and consumers will absorb. Lanes are split by family to allow parallelism; orchestrator coordinates shared barrels and the public-surface map.

## Scope

### Lane A — design-language primitives (cream / paper / flourish / hero)

New components in `src/components/custom/`:

- `<CreamSurface>` (`custom/cream-surface/`) — props `tone?: "warm" | "cool"`, `padded?: bool`. Wraps `.cream-surface`.
- `<DisplayHero>` (`custom/display-hero/`) — props `size?: "display-3" | "display-mega" | "display-ultra"`, `variation?: "wonk" | "stretch" | "depth"`. Composes display-italic + per-rung variation-settings + optional `.depth-text`.
- `<FlourishDivider>` (`custom/flourish-divider/`) — props `tone?: "rainbow" | "gold" | "section-N"`, `tapered?: bool`.
- `<IconStamp>` (`custom/icon-stamp/`) — wraps a Lucide icon; props `size` (xs..mega), `frame?: "stamp" | "emboss" | "plain"`, `accent?: section-color name`.

CVA branches:

- `Card variant="cream"` and `variant="paper"` (composes `.cream-surface` / `.paper-card` from W2).
- **No `Switch variant="skeuo"` / `Toggle variant="skeuo"`** — per G.md invariant 7, no new bevel vocabulary; the modern-skeuo axis is delivered by extending cartoon shadows.

### Lane B — math + iconographic typography primitives

New in `src/components/custom/`:

- `<MathSurface>` (`custom/math-surface/`) — props `mode: "inline" | "display" | "popover"`. Hosts pre-rendered KaTeX HTML or any math content via slot. Consumes `math.css` utilities.
- `<MathFormula>` — slot-based: `display-mode?: "inline" | "block"`, `accent?: viz-basis or section name`. Applies `.formula-block`.
- `<MathGlyph>` / `<TypographicIcon>` (`custom/typographic-icon/`) — props `char`, `font?: "display" | "serif" | "mono"`, `weight?: number`, `axes?: { wonk?: 0|1, soft?: number }`. Renders typography-as-icon pattern.

### Lane C — palette + categorical-color primitives only

Blob, Swatch, SvgFilters, RainbowGradientDef, useWatercolorBlob, useMetaballRenderer, useBlobMood, useBlobPointer, useBlobSatellites, useBlob, mulberry32 — **all moved to sub-tranche β** (`docs/tranches/G/blob/`). This wave does not ship them. See `docs/tranches/G/blob/SPEC.md` and `waves/Wβ0–Wβ3`.

What stays in main W3 Lane C:

- `<ColorPill>` (`custom/color-pill/` OR `Badge variant="color"` with `:icon` slot per Q18) — props `color`, `active?: bool`, `icon?: VNode`. Consumes `--color-pill-{fill,border,active-fill}-alpha` tokens. Bbnf evidences a `:icon` slot (sectionTheme.ts; 5+ sites); D evidences tier-badge variant (4 sites). Single primitive covers both.

Lane C is the smallest lane in W3 now that Blob has its own track.

### Lane D — motion + timeline + bezier primitives

New in `src/components/custom/`:

- `<KeyframeTimeline>` family (`custom/timeline/`): `<KeyframeTimeline>`, `<TimelineMarker variant="diamond" | "circle">`, `<TimelinePlayhead>`, `<TimelineRuler>`. Lifted from keyframes.js demo; generalized via composables.
- `<BezierCurveCanvas>` (`custom/bezier-canvas/`) — SVG-based curve editor with draggable handles, axis labels, gridlines, traveling progress dot, viewBox auto-clamp for overshoot.
- `<StatusDot variant="progress">` — extends existing `StatusDot`. Props `model-value: number` (0..1), `color?`, `pulse?`. Conic-gradient + glow stack.
- New keyframes in `animations.css`: `rainbow-drift`, `idle-bob` (synthesis E #9, C #5).
- New transition pairs in `transitions.css`: `pane-swap-scale` (synthesis #17). `<Transition name="pane-swap-scale">` matches existing `pane-swap` shape but on scale.

### Lane D' — `useMonacoTheme()`, `<PipelineFlow>`, `<LiveSnippet>`

New in main G.W3 (post user-disambiguation pass):

- `useMonacoTheme(monaco, options?: { light?: string; dark?: string; custom?: monaco.editor.IStandaloneThemeData })` (`src/composables/monaco/useMonacoTheme.ts`) — watches `useGlobalDark()`, calls `monaco.editor.setTheme()` with the matching theme name. Accepts custom theme data for cream-tinted Monaco themes. ~15 lines. New package barrel `src/composables/monaco/`.
- `<PipelineFlow>` / `<NodeChain>` (`custom/pipeline-flow/`) — vertical chain of node pills with arrow connectors. Props: `:nodes: { label: string; detail?: string; color?: string; href?: string }[]`, `:orientation?: "vertical" | "horizontal"`, `:connector?: "arrow" | "line" | "none"`. Hover lift via `--shadow-cartoon-md`; optional click-through.
- `<LiveSnippet>` / `<RunnableCode>` (`custom/live-snippet/`) — `<slot name="input">` + `<slot name="output">` + a slot for the run button. The harness (the actual code execution) is consumer-provided via `:onRun` prop returning a Promise. Output area shows pending/success/error states; collapsible. Glass-ui ships the surface; the engine binding stays consumer-side.
