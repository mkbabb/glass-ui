## Scope

### Story `primitives/blob`

Location: `demo/stories/primitives/blob.vue`.

Sections (top to bottom, designed as a single composed page):

1. **Hero specimen.** A single `<Blob :color="var(--gold)" mood="curious" :size="20rem" :pointer-attract />` centered in a `var(--cream-warm)` canvas, surrounded by generous φ-spacing whitespace, captioned with `<DisplayHero size="display-mega">A living specimen.</DisplayHero>` underneath. The blob and the title share the breath cadence.
2. **Mood gallery.** Five blobs in a row, one per mood, each at `:size="6rem"`, labeled in Fraunces italic with caption-tier type. Each labeled with the mood name and a single-sentence character description. Full mood vocabulary on display in 5 seconds.
3. **Color spectrum.** A horizontal strip of fifteen blobs, each `:size="3rem"`, colored through `--rainbow-{vivid,pastel}` and `--viz-*` and `--gold` family. Demonstrates the accent contract.
4. **Configuration playground.** An interactive controls panel (using `<Slider>`, `<NumberField>`, `<ToggleGroup>`) wired to a single `:config` prop on a 12rem blob. Every BlobConfig field exposed; users can pin the satelliteCount, smoothK, eccentricity, etc. and see the effect immediately. The φ-anchored defaults are pre-marked on the sliders so consumers see "this is the golden default."
5. **Multi-instance composition.** A grid of nine `<Blob>` instances at `:size="5rem"`, each with a different mood × color combination, demonstrating that 60fps holds. Visibility gating proven by scrolling — blobs offscreen pause; on-screen blobs animate.
6. **Accessibility states.** Three side-by-side blobs evidencing the three a11y contracts: the PRM-frozen specimen, the reduced-transparency disc, the contrast-more border. Each labeled.
7. **Watercolor swatch family.** A row of `<Swatch variant="watercolor">` at all four sizes, demonstrating the small-blob recipe sibling.
8. **`<SvgFilters>` mount.** Single line at the bottom showing the SvgFilters component's role: `<SvgFilters />` is mounted once at app root; everything above consumes it implicitly.

The page itself uses `<CreamSurface>` as its substrate, `<FlourishDivider tone="gold">` between sections, and a `<DisplayHero size="display-3">` for each section heading. The Blob story exemplifies the design language across cream + paper + flourish + audacious-typography + audacious-iconography axes simultaneously — the full bold-maximalist commitment.

### Stress test

Location: `demo/stories/_internal/blob-stress.vue` (private story; not surfaced in main manifest unless behind a debug flag).

Thresholds derived directly from SPEC.md §9 budget:

- **Single instance, 256×256, 4 sources, full motion** — must hold 60 fps; per-frame GPU ≤ 2 ms on M1 / iPhone 12 / Pixel 5.
- **Four instances on one page** at `:size="6rem"` (canvas 256×256 each) — must hold 60 fps total via shared `useRafLoop`. Per-instance: GPU ≤ 2 ms, CPU renderer ≤ 0.5 ms, CPU state machine ≤ 0.3 ms.
- **Eight instances on one page** — degraded gracefully: visibility gating pauses offscreen blobs; visible blobs hold 30+ fps.
- **PRM enabled** — zero rAF activity; one-time first-frame paint; all instances static.
- **Memory** — ≤ 256 KB per instance (canvas + GL buffers + state); 100 mount/unmount cycles total heap growth ≤ 4 MB.
- **Bundle delta** — shader source + composable bundle delta ≤ 200 KB raw / ≤ 30 KB gzipped vs pre-Wβ HEAD. Measured via `scripts/profile-bundle.mjs` re-run.
- **Multi-instance cast-shadow correctness** — render four `<Blob>` instances on a cream substrate, each with a different `--blob-cast-shadow-mix` (8%, 18%, 32%, 48%). Verify each instance's box-shadow color-mix resolves to the expected value via `getComputedStyle`. Confirms SPEC.md §11.3 cast-shadow contract is per-instance settable.

Recorded in `audit/Wβ3-stress-proof.md` with profile screenshots / numbers and the bundle-delta column.
