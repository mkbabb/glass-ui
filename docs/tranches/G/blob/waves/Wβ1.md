## Purpose

Implement the seven composables and the renderer that the canon `<Blob>` will compose in Wβ2. The component itself doesn't ship until Wβ2; this wave produces the substrate.

## Scope

### Lane I — `useMetaballRenderer` (orchestrator-owned, the renderer)

Location: `src/composables/blob/useMetaballRenderer.ts` (new package).

Implements:

- **Instance-local WebGL2 context** per SPEC.md §11.1 lock. No singleton shared compositor; each renderer call acquires its own context via `canvas.getContext('webgl2', { alpha: true, premultipliedAlpha: true, antialias: false, preserveDrawingBuffer: false })`.
- Fragment shader sourced from `src/composables/blob/blob.frag.glsl` and loaded via Vite `?raw` import: `import fragSource from "./blob.frag.glsl?raw"`. The GLSL file is the byte-for-byte port of the Wβ0 reference (SPEC.md §6 verbatim with the canonical `hsl2rgb` 8-line transform and Ashima `snoise` 24-line implementation inlined; provenance comment retained at file head).
- Vertex shader: 4-line fullscreen-triangle via `gl_VertexID` (no buffers, no attributes) — same form as the Wβ0 playground.
- Uniform pipeline: `uTime`, `uResolution`, `uColor` (HSL), `uSmoothK`, `uSourceCount`, `uSources[8]`, `uHueRange`, `uSatShift`, `uBrightnessShift`, `uColorNoiseFreq`, `uColorNoiseSpeed`, `uChromaticAberration`.
- `uChromaticAberration` is sourced from the consuming element's resolved `--blob-chromatic-aberration` CSS custom property each frame via `getComputedStyle(canvas).getPropertyValue("--blob-chromatic-aberration")` (SPEC.md §11.2 lock — exposed as a per-instance CSS variable). Default `0.002`; zero is valid (kills the R/G/B fringe entirely).
- Per-frame: update uniforms, single draw call (`gl.drawArrays(gl.TRIANGLES, 0, 3)`), no readback.
- Canvas2D fallback path when `getContext('webgl2')` returns null. Port value.js's `useMetaballRenderer.ts:1-319` to `src/composables/blob/canvas2d-fallback.ts`. Same source state machine, same color logic. Hard-cap canvas at 200×200.
- Returns `{ render(time: number): void, dispose(): void, isWebGL: Ref<boolean> }`.

Symbol exports from this file: `useMetaballRenderer` (default named export), `MetaballSource` type, `RendererHandle` return-type alias.

Cleanup contract:

- `dispose()` deletes WebGL program, buffers, textures.
- ResizeObserver torn down on dispose.
- WebGL context lost / restored events handled (`canvas.addEventListener('webglcontextlost', ...)` → `dispose` and recreate on restore).

### Lane II — Mood, pointer, satellites composables

Location: `src/composables/blob/`.

Files + symbol exports:

- `useBlobMood.ts` — accepts `Ref<BlobMood>` and optional `{ params?: Record<BlobMood, MoodParams> }`. Returns reactive `MoodParams` blended via `@vueuse/core` `useTransition` over `--duration-panel` with `--ease-apple-spring`. Exports: `useBlobMood`, `BlobMood` type (`"idle" | "happy" | "curious" | "sleepy" | "excited"`), `MoodParams` type, `BLOB_MOOD_PARAMS` (the 5-mood × 11-param table from SPEC.md §5).
- `useBlobPointer.ts` — accepts `Ref<HTMLCanvasElement | null>`. Returns `{ pointerNDC, attractionForce }`. Listens via `useEventListener` (`pointerenter`, `pointermove`, `pointerleave`); auto-disabled on `(pointer: coarse)` unless explicitly forced. Exports: `useBlobPointer`.
- `useBlobSatellites.ts` — accepts `Ref<BlobConfig>`, `Ref<MoodParams>`, `Ref<{ x: number; y: number } | null>` (pointer NDC), `seed: number`. Returns `Ref<MetaballSource[]>` (reactive list of body + N satellites, each with x/y/radius/opacity in NDC). State machine ported from value.js with deterministic PRNG via `mulberry32(seed + i)` per satellite. Exports: `useBlobSatellites`, `BlobConfig` type, `BLOB_CONFIG_DEFAULTS` (the 25-field default object from SPEC.md §4).
- Tap-mood handling: when `<Blob>` (Wβ2) drives `mood` through `:tap-mood` + `:tap-duration` props, the mood ref it passes to `useBlobMood` is a derived ref that switches to `tap-mood` for `tap-duration` ms on a `pointerdown` / `click` event then reverts. The composable itself sees only the resulting Ref<BlobMood>; it does not own the timer.

### Lane III — `useWatercolorBlob`, `useBlob` facade, `mulberry32` utility

Location: `src/composables/blob/` and `src/composables/utils/`.

Files:

- `src/composables/utils/mulberry32.ts` — top-level utility. ~30-line deterministic PRNG. Exported from `src/composables/index.ts`.
- `src/composables/blob/useWatercolorBlob.ts` — port of value.js. Inputs: seed, intensity (0..1), boil cadence (Hz). Returns `Ref<string>` (CSS `border-radius` value oscillating between two random sets via `requestAnimationFrame`, gated on PRM).
- `src/composables/blob/useBlob.ts` — facade. Composes the four blob composables. Inputs: `BlobProps` from SPEC.md §3. Returns `{ canvasRef, sources, color, render, dispose }`.

### Cross-cutting — shared `useRafLoop`

The shared rAF driver (`useRafLoop` in main G.W3 spec) is a load-bearing dependency. If main G.W3 lands first, blob lane consumes it. If blob lane lands first, ship the driver here under `src/composables/motion/useRafLoop.ts`, document, and main G.W3 picks it up.

`useRafLoop` API:

```ts
function useRafLoop(callback: (time: number, deltaMs: number) => void, options?: {
  immediate?: boolean;
}): {
  start(): void;
  stop(): void;
  isActive: Readonly<Ref<boolean>>;
};
```

Internally maintains a single global rAF subscription; `n` consumer subscriptions share one tick. `prefers-reduced-motion` matched + no override → callbacks invoked once on `start()` then the loop halts.
