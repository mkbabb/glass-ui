## Scope

### Lane A — `<Blob>` component

Location: `src/components/custom/blob/`.

Files:

- `Blob.vue` — root component. Composes `useBlob(props)`. Renders `<canvas ref="canvasRef">` plus an optional `<slot name="label">` wrapped in `<div class="blob-label">`.
- `index.ts` — exports `Blob`, `BlobProps` type, `BlobMood` type, `BlobConfig` type, `BLOB_CONFIG_DEFAULTS`, `BLOB_MOOD_PARAMS`.
- Cast shadow + label CSS lives inline in `Blob.vue` `<style scoped>`. The wrapper element's box-shadow is sourced per SPEC.md §11.3 lock:
  ```css
  .blob {
      box-shadow: 0 var(--blob-cast-shadow-y, 0.5rem)
                  var(--blob-cast-shadow-blur, 1.5rem)
                  color-mix(in srgb, var(--blob-color, var(--easing-accent))
                            var(--blob-cast-shadow-mix, 18%),
                            var(--foreground));
  }
  .blob-label {
      font: italic var(--type-caption) / 1 var(--font-display);
      font-variation-settings: "WONK" 1, "SOFT" 100;
  }
  ```
  All three knobs (`--blob-cast-shadow-y`, `--blob-cast-shadow-blur`, `--blob-cast-shadow-mix`) ship as W1 tokens so consumers override per-instance via plain CSS or the `:style` attribute. No JS-side cast-shadow code.

Props per SPEC.md §3 (including the SPEC.md §11.5-locked `:tap-mood` and `:tap-duration` props). Internal:

- `useBlob(props)` returns `{ canvasRef, render, dispose }`.
- `:tap-mood` handling: a `pointerdown` listener on the wrapper element switches the internal `mood` ref to `props.tapMood` for `props.tapDuration` ms (default 800) then reverts. No-op when `tap-mood` is null. Listener is `passive: true`; cancelled in `onBeforeUnmount`.
- `useRafLoop` subscription wired with visibility gating.
- `prefers-reduced-motion` / `prefers-reduced-transparency` / `prefers-contrast: more` media-query subscriptions via `@vueuse/core` `useMediaQuery`.
- IntersectionObserver pause/resume.

PRM contract: `reduced-motion="auto"` + matches → render `time=0` once via `render(0)`, do not start rAF. Mood transitions snap (no `useTransition` smoothing).

Reduced-transparency contract: render the no-metaball fallback path via the same Canvas2D fallback file (with smoothK = 0 ⇒ no union, sources render as separate cartoon-shadowed discs).

### Lane B — `<Swatch>` component + `<SvgFilters>` + `<RainbowGradientDef>`

Location: `src/components/custom/swatch/`, `src/components/custom/svg-filters/`.

Swatch files:

- `Swatch.vue` — accepts `:color`, `:size`, `:variant`, `:animated`, `:seed`. Variants:
  - `solid` — a `<div class="swatch swatch-solid">` with `background-color: var(--swatch-color)` (set inline from prop).
  - `cartoon` — adds `--shadow-cartoon-sm` and 2px border with `color-mix(in srgb, var(--swatch-color) 40%, var(--foreground))`.
  - `watercolor` — `<div class="swatch swatch-watercolor">` consumes `useWatercolorBlob({ seed, intensity: 1 })`; reactive `border-radius` from the composable; `filter: url(#watercolor)` references the SVG filter from `<SvgFilters>`.
- `index.ts` — exports `Swatch`, `SwatchProps` type.

SvgFilters files:

- `SvgFilters.vue` — single-mount component that emits `<svg style="position: absolute; width: 0; height: 0;">` containing `<defs>` with the canonical filter pack:
  - `<filter id="watercolor">` — `feTurbulence baseFrequency="0.02" numOctaves="2" seed="…" /> <feDisplacementMap scale="6" />`.
  - `<filter id="paper-grain">` — placeholder for the paper-grain filter (already exists elsewhere; consolidate here).
  - `<filter id="pencil-wobble">` — fine-grained displacement for hand-drawn icon edges.
  - `<filter id="canvas-grain">` — coarser grain for canvas-backed compositions.
- `RainbowGradientDef.vue` — emits `<linearGradient id="rainbow-gradient">` with stops referencing `--rainbow-{red,orange,yellow,green,blue,indigo,violet}`. Companion to `.rainbow-stroke` utility (W2 of main tranche).
- `index.ts` — exports both.
