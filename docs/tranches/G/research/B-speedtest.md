## 4. Design-language signal toward the new axes

The eleven tranche-G axes (cream / colorful flourishes / mathematical / modern skeuomorphic shadowing / bold / audacious / large typography / large iconography). Each row cites the strongest call site in speedtest and what glass-ui would need to absorb it as a primitive.

### Cream
- Speedtest *retains* the warm-cream identity inherited from glass-ui v0.4 (`--neutral-0..5` at hue 48). The consumer doesn't override the neutral ladder. **Strongest signal**: `/Users/mkbabb/Programming/speedtest/src/components/dashboard/composables/useEChartsTheme.ts:15` — the chart neutral quartet uses cool grays (`#1a1a1a`/`#737373`/`#e5e5e5`), not the cream ladder. This is *drift away from* the cream identity into echarts' default palette. Glass-ui needs to: ship `chartNeutrals` from `@mkbabb/glass-ui/tokens` reading the actual `--neutral-{0..5}` hex equivalents so echarts inherits cream automatically.

### Colorful flourishes
- **Strongest signal**: the **aurora gradient** as a named consumer token (`/Users/mkbabb/Programming/speedtest/styles/tokens.css:35-43` `--aurora-gradient`) used as the survey progress fill at `/Users/mkbabb/Programming/speedtest/src/components/survey/SurveyWizard.vue:10` `'--progress-fill': 'var(--aurora-gradient)'`. Six-stop linear gradient (purple→blue→pink→emerald→amber→violet) consumed by a `Progress variant="gradient"`. The colorful sweep *is* the flourish.
- **Next-strongest**: per-metric chart-color `:style` injection at `/Users/mkbabb/Programming/speedtest/src/components/dashboard/StatsCards.vue:7-9` (4 cards) and `/Users/mkbabb/Programming/speedtest/src/components/dashboard/charts/MetricGaugeCards.vue:5` (5 cards) — color-keyed display numbers.
- **Glass-ui absorption**: a `--rainbow-gradient` token composing the existing `--rainbow-{red,orange,yellow,green,blue,indigo,violet}` 7-stop family. The aurora 6-stop is consumer-specific; the rainbow 7-stop is library-canonical and already half-built. The *missing primitive* is a named gradient token, not the colors.
- Also: `MetricBadge :color` already exposes the per-metric color mechanic; the dashboard is reinventing it without the badge wrapper.

### Mathematical
- **Strongest signal**: the **PHI ladder canvas geometry** at `/Users/mkbabb/Programming/speedtest/src/components/speedtest/utils/canvas/meter/config.ts` (and the worked example in DESIGN.md:660-684). Three concentric rings sized by `lineWidth × PHI`. Speedtest is the first consumer where φ shows up *on screen* as ring geometry, not just typography scale. Speedtest does this in its own canvas math; not a CSS pattern.
- **Adjacent signal**: the survey wizard's **progress percent** = phase-completion / total-phases — a clean step-fraction metric, not a smooth linear position.
- **Glass-ui absorption**: nothing immediate. The φ-ladder is canvas-bound; the value primitive (`PHI = 1.618`) lives in `@mkbabb/value.js` which glass-ui already depends on. *If* tranche G wants a "mathematical" badge, the path is a `<MathLabel>` custom that renders Computer Modern italics + token italic = `--font-serif` (CM Serif) which is already canonical. The font is already there; consumer just hasn't used it because the brand-uniform-sans preset overrides serif → General Sans.

### Modern skeuomorphic shadowing
- **Strongest signal**: DESIGN.md §"Modern skeumorphism — edge light + edge shadow (at rest)" lines 356-368, which is *spec'd* but not yet in source. Spec calls for `inset 0 0.5px 0 0 rgb(255 255 255 / 0.06)` (top edge catches light) + `0 0.5px 0 0 rgb(0 0 0 / 0.04)` (bottom falls to shadow), as a vocabulary applied to chassis + primary tab + metric pills + ghost pills.
- **Live signal**: `--glass-highlight: inset 0 0.5px 0 0 hsl(0 0% 100% / 0.25)` in glass-ui `tokens.css:327` is the rest-state hairline lift. Speedtest spec'd `--glass-specular: inset 0 1.5px 0 0 hsl(0 0% 100% / 0.45)` as the active-state catch-light (DESIGN.md:506).
