# D9 — dock tab red underline too prominent

**Lane** D9 · **Severity** minor · **Verdict** augment-existing-wave (AX.W40) · **Surface** `demo/layout/dock-nav.css` (the BottomDock active-tab affordance) — NOT a library defect.

## The defect (user ledger D9, screenshot 15.01.32)

> "The red underline under dock items is too prominent — should be subtle / NO underline." (dock tabs e.g. "Dialog")

## Root cause — source-grounded

The red underline is the **demo-private** bottom-dock active-story affordance in `demo/layout/dock-nav.css` (last touched by `c02ada3` — AW.W28, the merged-but-untrusted demo nav shell). Two coupled rules paint it:

`demo/layout/dock-nav.css:106-127`:

```css
.demo-bottom-dock__tab.is-active,
.demo-bottom-dock__tab[aria-current="page"] {
    --dock-active-color: var(--demo-nav-accent);
    color: var(--demo-nav-accent);          /* full-strength RED text */
}
.demo-bottom-dock__tab.is-active::after,
.demo-bottom-dock__tab[aria-current="page"]::after {
    content: "";
    position: absolute;
    inset-inline: 18%;
    inset-block-end: 0.15rem;
    height: 2px;
    border-radius: var(--radius-pill);
    background: var(--demo-nav-accent);      /* the RED underline pseudo-element */
    transition: opacity var(--duration-fast, 150ms) var(--spring-snappy, ease);
}
```

`--demo-nav-accent` resolves to `--viz-fourier` = `oklch(0.579 0.201 30.4)` light / `oklch(0.693 0.151 28.1)` dark (`tokens.css:490,1607`) — the NCSU warm-red the brand wordmark rides (`dock-nav.css:17-21`). So the active "Dialog" tab gets **both** full-strength red text AND a 2px solid-red underline bar at high chroma (C≈0.20) — that's the "too prominent" read.

**The library is innocent.** The shipped `.dock-tab-button` active rule (`src/styles/dock-controls.css:263-266`) is neutral by construction:

```css
&:is(.is-active, .active, [aria-current="page"], [aria-pressed="true"]) {
    background: var(--surface-tint-10);   /* 10% foreground tint — subtle */
    color: var(--foreground);             /* neutral, no accent */
}
```

`--surface-tint-10 = color-mix(in srgb, var(--foreground) 10%, transparent)` (`tokens.css:399`) — a hairline neutral pill, no underline. The DockTabButton SFC (`src/components/custom/dock/DockTabButton.vue`) adds nothing visual beyond `text-decoration: none`. The red is 100% the demo overlay; **no `src/styles/` edit is warranted**.

## Gestalt fix direction (token-first, in-shell)

The demo active-story affordance should read as a **subtle** active mark, not a saturated red bar. The W40 charter already mandates the gestalt here — Scope §3 + FileBounds: "re-express the nav-shell CSS against the rebuilt dock contract (no bespoke rail accent the W06 variant owns; tokenized clearances)" and "No bespoke hand-rolled accent rule in the shell that the variant should own." The D9 fix is precisely that rebuild applied to the BottomDock tab:

1. **Drop the bespoke `::after` underline bar entirely** and let the affordance be the dock's own active-pill (`--surface-tint-10` neutral pill the library already paints on `[aria-current="page"]`), restyled via the `--dock-active-*` cohort the dock exposes — `color-on-the-cascade`, not a parallel hand-rolled rule. This is the W40 "demo == shipped contract" discipline: the BottomDock should consume the dock's active-state vocabulary (the `--dock-active-{bg,color}` cohort, exactly as `dock-nav.css:55-61` already does for the SidebarDock left-edge case via `--dock-active-color`), not fork a second affordance.
2. **If an accent IS retained**, it must be *quiet*: bind it through a low-alpha `color-mix(in srgb, var(--demo-nav-accent) N%, transparent)` (subtle accent tint on the active pill) rather than a full-chroma 2px solid bar + full-strength red text. The brand-red at C≈0.20 full-strength is the over-prominence; an alpha-attenuated accent on the existing neutral pill keeps brand identity without the jarring bar.
3. **Pick ONE affordance, not two** — today the active tab carries red text *and* a red underline (double-marking). The subtle read is a single quiet cue (the dock's neutral pill, optionally tinted), not text-color + underline stacked.

All token-routed (`--surface-tint-10`, `--dock-active-color`, `color-mix in srgb` per house alpha pattern), no new magic literal, no library edit, no legacy.
