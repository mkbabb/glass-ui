## Rationale

**T1 — `--chassis-max-block-size`** answers a long-standing chassis-tier gap. Consumer cards (speedtest's `.results-card` is the canonical site) needed a layout-tier guardrail that respects the dock footer space without each consumer re-implementing the calc. The token composes consumer-owned fallbacks (`--dock-footer-space`, `--page-padding-top`) so the calc evaluates correctly inside any consumer; the consumer cascade overrides the fallbacks at runtime. Used clamp-first / no-scroll-first: consumers shrink internal regions before falling back to scroll.

**T5 — `.dock-label` @utility** closes a typography-vocabulary mismatch. Consumers were applying `.text-heading` to dock-pill text labels (Start, Next, Submit, Done, New Test) — but `.text-heading` is the heading register at `font-weight: 700`, which reads as literal bold inside a dock pill. The user mandate ("the Start text should not be bold") generalized to every bottom-dock text label. `.dock-label` is the explicit canonical register so `.text-heading` keeps its semantic weight contract while dock pill labels read at medium weight.
