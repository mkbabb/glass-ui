## Rationale

AB.W2 is a single coordinated structural rewrite landing as 3 commits in 1 minute (`215ad06` at 23:33:19 → `6263330` at 23:33:35 → `14631b7` at 23:33:44). The triplet shape reflects the dependency graph:

1. `<HoverPopover>` must expose `v-model:open` first (T2 wraps markers in HoverPopover and consumes the controlled cadence for the new `hoverEnd` event).
2. `<GlassTimeline>` continuous variant restructures into 4 coupled fixes (T1+T2+T3+T4 land in one commit because the Option C DOM rewrite couples opaque-dot perceived-centering + popover wrap + currentSegmentKey + hoverEnd into one substrate change).
3. CHANGELOG + DESIGN canon-refinements doc commit publishes the API additions.

The structural rewrite is the most consequential AB.W2 deliverable. The continuous variant's old DOM nested focusable `<button class="continuous-dot">` descendants inside `.continuous-track[role="progressbar"]` — an axe `nested-interactive` violation (serious; WCAG 2.0 A — 4.1.2). Option C restructures the rail and the marker buttons into SIBLINGS inside `.continuous-track-wrap`, closing the AA-carry-forward violation cleanly. The DOM rewrite simultaneously fixes B2.a perceived-off-centre (marker overlay no longer clipped by rail `overflow: hidden`).
