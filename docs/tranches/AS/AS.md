# Tranche AS — Make the verification fleet pure, portable, and singular (the gate-integrity class) + the modern-web leverage AR left

AS is glass-ui's post-AR tranche. AR closed the binding-verification class for platform-binding surface — `proof:vt-names` (inv-η) made the `view-transition-name`/`anchor-name` collision statically impossible, the GlassDock counter bug shipped fixed at 3.1.1, and the release CI was repaired so the constellation's #177 blocker cleared. But AR.W2's execution exposed a second-order fact the AS.W0 deep audit (six lenses) made load-bearing: **the proof-gate fleet that guards glass-ui is itself unsound.** Fixing the one `npm ci` failure unmasked the entire gate matrix that the broken install had hidden, and three separate `proof:*` scripts went red on a clean runner — each independently re-inventing "what to do when a sibling repo is absent." They were point-fixed one at a time (`8515034`, `53a0fb3`, `707f346`); none made the property structural.

AS is the dual of AR's headline, lifted one level. AR made a *component's* platform binding statically sound; AS makes the *verification substrate* statically sound. The audit found the gate fleet hardcodes the constellation membership list **five times** (already drifted — `bbnf-buddy` in two gates, `bbnf-lang/playground` in two others), solves "absent sibling" **three different ways** (registry-fallback, logged-skip, existsSync-continue), writes its output as a **side effect on git-tracked history-artifacts** parked under closed tranches (22 `generatedAt`-bearing JSONs that CI itself re-dirties and a human hand-restores), and curates **three divergent gate lists** (`proof:all`=6, `ci.yml`=8, `release.sh`=4-with-zero-`proof:*`) so a local `proof:all` reports green while CI is red and a tagged release re-checks no binding-correctness gate at all. This is not five bugs; it is one missing abstraction the house already declared (the G.W5 §8 registry-default amendment, inv 53) and never absorbed into the tooling.

AS also takes the modern-web *leverage* AR specified but never ran — re-derived against 3.1.1 HEAD, because AR's A1-era roster has gone stale (the OKLab aurora machinery and `--glass-opacity-dock` are already shipped; the carousel scroll-state site is the overflow-fade listener, not a pager; cross-document VT is consumer-owned app-shell, not a library artefact). The gate-integrity substrate is the headline (the elegance/simplicity/performance transposition); the leverage is the additive 3.2.0; the chronic deferrals fold or are terminally ruled.

## § Thesis

AR.W2 verified clean at HEAD and 3.1.1 is a coherent releasable unit — but the audit found three structural facts about the substrate around it. First, the **gate fleet is not portable**: five hardcoded copies of the constellation list (drifted), three ad-hoc encodings of absent-sibling handling, and a recurring lockfile-drift chore (`file:../keyframes.js` poisoning the committed lockfile) all trace to one missing `resolveSibling` policy — and the G.W5 §8 amendment that declares registry-default-resolution the primary world is already written but unabsorbed, so the scripts still treat the local sibling layout as primary and the clean runner as the patched exception (inverted). Second, the **gate is not a pure function**: 22 tracked `docs/tranches/**/audit/*.json` carry `new Date().toISOString()` and `profile-bundle.mjs` writes a timestamp into a tracked `.md`, so every gate run mutates committed history-artifacts parked under closed F/K tranches — the exact dirtying the AR.W2 session hand-restored repeatedly. Third, the **gate aggregate lies**: `proof:all` omits `proof:resolution`/`proof:phantom-classes`/`audit:stash` (so local-green ≠ CI-green), and `release.sh` runs zero `proof:*` (so VT-name / surface / phantom-class drift between the last CI run and the tag ships unguarded). Separately, the AR headline gate `proof:vt-names` is **over-claimed**: it is a single-shape object-property kebab regex scan, four real mint forms (camelCase IDL, `setProperty` 2-arg, `setAttribute` style-string, `.vue` template inline) slip silently, and its `fileHasUseId` check is a file-level boolean, not a per-mint dataflow trace — so "structurally impossible / the dual of AQ's color-mix closure" overstates a regex with gaps.

The AR.W3-W6 leverage stands but must be re-derived against HEAD: G4 `scheduler.postTask` is the strongest, widest-Baseline forward lever; G1 density container-style-queries stand clean; G2 re-scopes to `@container scroll-state(scrollable)` retiring `useGlassCarousel`'s overflow-fade JS listener (the snapped/pager framing targeted the wrong carousel primitive, 0 consumers); G3 cross-document VT downgrades to demo-or-named-forward (`navigation: auto` is consumer-owned app-shell, not a component-substrate artefact); the AS-GU bundle is partially-landed (`deriveAurora`'s OKLab math and `--glass-opacity-dock` already ship — do not re-mint).
