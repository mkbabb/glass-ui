## Four decisions that shaped the rest

1. **P6 states O-350's ruling, and BM builds it** (law blocking 1). The first fold rewrote P6 to describe `R111` `a11y-overrides.css`, whose own comment calls it "the instant fallback" (`:6`). O-350's ruling was placed for 11.1.1 and only its consumer-override clause was built (`faf12109d`), and S112 counts O-350 among the rows 11.1.1 built, so no row held the rest. P6 now states the rule (opacity and colour transitions of 150 ms or less pass; travel, scale, size and filter stop) and names 11.1.1's zero and `view-transition.css:28-34`'s `animation: none !important` as shortfalls. BM-3 gains a step 3 that builds the rule in BM's parts minor, BL is asked whether 11.1.2 builds it first (BM.md §8), BM.md §1 narrows a carve to the forms the rule cannot express, and G-5's reduced reading covers every part glass's demo mounts once the rule ships.
2. **The theme's crossfade is `useGlobalDark`'s own transition** (evidence blocking 1, law majors 1 and 2, evidence major 2, law minor 1, evidence minor 5). The public helper skips every view transition under Reduce Motion (`R111` `useViewTransition.ts:144-150`) and is daraksha's import (`src/veil/film/Layer.vue:20`), so BM-1 leaves it alone. `useGlobalDark` starts a typed `theme` transition around the class write (an `html` class where types are not taken), from `isDark`'s setter and from `useColorMode`'s `onChanged` (vueuse 14), so a toggle, a menu row, an `isDark` write, a system flip and a stored write all cross. `::view-transition` takes `pointer-events: none` and a second flip reverses the running animations. The live glyph is an attribute that `useGlobalDark` turns into a per-instance name only while the transition runs, so gaggle's two toggles never share a name and `toggleDark` takes no argument. The reduced crossfade is a `theme`-scoped carve that beats `view-transition.css:28-34`. Below Safari 18 and Firefox 144 (glass's floor is Safari 16.4, `R111` `vite.targets.ts:4-10`) the flip is a 200 ms colour transition, O-353's other form.
3. **The Blob BM-15 designs is color's hero** (law blocking 2, evidence major 4). value.js's hero scales its own values by its config over glass's defaults, and the config is a clone of those defaults (`HeroBlob.vue:201-202`, `heroBlobConfig.ts:15`), so a new glass geometry default divides out. BM-15 ships the geometry as `BLOB_HERO` (`R111` `presets.ts:41-61`), keeps `BLOB_CONFIG_DEFAULTS`' geometry, lets the motion's constants reach the hero through its clone, and asks value.js to mount the preset or set its values, and whether its fission stays at 0.8. BL is asked to film 11.1.2's jitter reading on the hero's values as well (BM.md §8).
4. **A seat's plate waits for BL's word** (evidence major 1). W-B.17 puts `.plate` on the dock's controls in 12.0.0 (`W-B.17.md:513`, `:489`), as W-I.8 does (`:36`). BM-2 splits: the rungs, the toggle's plate and the on-mark attribute go in the dock-redesign minor; the seats' cells run in the release that puts the seats on the plate. §8 asks BL to place them in the dock-redesign minor, and the six notes that promised the seats' plate in that minor now tie it to that release.
