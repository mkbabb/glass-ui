## What it builds

FourierField draws through the published package, so the series maths lives in one place, fourier's.

1. **The map.** Each name glass's maths leaf exports (`src/components/fourier-field/math.ts`: `dftFromPoints`, `partialSumAt`, `positionsAt`, `makeEllipticSpectrum`, `makeHarmonicFigure`, `FOURIER_FIGURES`, `FOURIER_FIGURE_KEYS`, `BasisComponent`) is set against the package's exports (`packages/fourier/src/index.ts`: `spectrumOf`, `evaluateAt`, `partialSum`, `chainAt`, `samplesFor`, `fft`, `coef`, `toComponents` and the `BasisComponent` and `Spectrum` types, among others). The map is written into the wave record before any code moves.
2. **The swap.** `@mkbabb/fourier` joins glass's `dependencies` at `^0.1.0`. FourierField and `useFourierField` compute their spectrum, partial sums and epicycle positions through it. glass's own DFT and partial-sum code goes from `math.ts`.
3. **What stays glass's.** The figure generators and the figure table (`makeEllipticSpectrum`, `makeHarmonicFigure`, `FOURIER_FIGURES`) are the demo's and the field's content, not series maths, and stay where the package has no counterpart. The WebGPU renderer, its shaders and the clock are glass's.
4. **The public names in this minor.** `./fourier-math` (`scripts/lib/subpath-policy.mjs:209`) and the barrel's maths names stay until 12.0.0, each a call into the package with glass's signature, so one implementation runs and nothing a site might import breaks in a minor. BM-9 removes them in 12.0.0 with MIGRATION rows naming the package's functions. No site imports them on 2026-11-24.
5. **FourierField's props, events and paint do not change.**
