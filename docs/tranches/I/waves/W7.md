# I.W7 — Close Ceremony + 6-Agent Post-Close Audit (canonical)

**Opens after**: W4 + W5 + W6 close.
**Agents**: 1 orchestrator + 6 audit lanes (the new canonical close pattern: α/β/γ/δ/ε/π).
**Hard gate**: 6-agent audit returns; FINAL.md authored AFTER findings absorbed; per H invariant 4 + I invariant 4 the audit lanes run BEFORE FINAL is final.
**Status**: pending W4 + W5 + W6.

## Purpose

Honest close per the canonical 6-agent post-close audit pattern (codified in I.W0). This is the FIRST tranche to use the new pattern as binding precept (H demonstrated it as a one-off ceremony; I codifies it).

## Steps

### A. Pre-close orchestrator pass

- Verify build / typecheck / test green at HEAD.
- Re-run β-style overfitting audit at HEAD; confirm zero remaining library-orphans (across the whole library, not just G additions).
- Re-run γ-style doc-drift audit at HEAD; confirm DESIGN.md + CLAUDE.md + README.md align.
- Re-run δ-style idiomatic-gestalt audit at HEAD; confirm zero round-trip alias families remain.
- Re-run recovery-diary canonical grep against src/ + demo/; confirm zero hits.
- Re-run Playwright probe against the canon stories (foundations / primitives / containers / compositions); confirm no runtime regressions.
- Verify per-wave commits landed (`git log --oneline tranche-i/w0..tranche-i/w6`).
- Verify PROGRESS.md status entries match reality.
- Stage `audit/I-pre-close.md` listing every artefact's final disposition + commit hash.

### B. 6-agent post-close audit (parallel)

Per the binding precept (now in `tranche/SPEC.md`'s close criteria), run 6 read-only / probe-only audit agents:

- **Lane α — plan-vs-actual**: walk every wave spec line-by-line against PROGRESS.md + close docs. Findings: silent additions, silent narrowing, hard-gate violations.
- **Lane β — substrate-without-consumer**: re-run the overfitting audit at HEAD post-W6. Findings: library-orphans that survived W1; new orphans introduced by W2-W6.
- **Lane γ — doc-drift**: walk DESIGN.md + CLAUDE.md + README.md + PROGRESS.md + each wave-spec status line + I.md against current source. Findings: misalignments, stale claims, undeclared brittleness windows.
- **Lane δ — idiomatic gestalt**: walk every refactor + new addition for KISS / one-path / single-authority violations. Findings: shim-like patterns, duplicate authority, recovery-diary leaks.
- **Lane ε — performance**: re-run bundle audit; verify subpath retires landed; verify CI workflows run; stress baseline rerun.
- **Lane π — visual-runtime (Playwright + Chrome MCP)**: walk canon stories; computed-style probes; verify shimmer matrix repair; verify dock-keep-open round-trip; verify per-rung Fraunces axes; capture full-page screenshots.

Each lane writes `docs/tranches/I/audit/I-audit-{α,β,γ,δ,ε,π}-*.md`.

### C. Findings absorb

For every accepted finding from the 6 audits:

- **Doc-only fix**: orchestrator applies the fix in W7 (within-wave absorb).
- **Source fix**: open a residual entry in `audit/I-residuals.md` with named destination (most likely a small W7-residual pass before FINAL.md is final).
- **Gestalt fix**: same as source-fix.

If absorb requires substantive code changes, the wave splits: the absorb work becomes W7.W7-pre-close-fix, and FINAL.md is delayed until those changes land + the audit re-runs clean.

Per H invariant 4 + I invariant 4: FINAL.md is authored ONLY when the audit returns clean.

### D. FINAL.md authoring

After the 6-lane audit returns clean (or after absorb closes any open findings), write `docs/tranches/I/FINAL.md`:

- Tranche thesis, opening + closing date.
- Wave-by-wave table with status + commit hash + close evidence.
- Substrate convergence stats: how many artefacts retired in W1; how many subpaths retired in W6; how many stories uplifted in W4.
- Process hardening stats: precept files updated (6-agent pattern, bundle-budget non-negotiable, recovery-diary scrub binary lesson).
- Architectural tensions resolved: substrate-tier hierarchy, story-fidelity policy, F-vs-G axis ownership.
- Cross-tranche debt + named-destination residuals (the I residue list — should be SHORTER than H's because I folded chronic deferrals).
- Brittleness windows (none for I, expected; if W4's 41-story uplift required a window, declare it here as restored).
- Authority — I closes clean.

### E. Lessons-learned reconciliation

If I surfaces any new process-failure incidents, append to `docs/precepts/instructions/LESSONS-LEARNED.md` per the format. Otherwise mark I as a clean tranche close.

### F. Final commit

Orchestrator commits W7 close: `feat(tranche-i/w7): close ceremony + 6-agent post-close audit (canonical)`. The commit includes FINAL.md + the 6 audit reports + any absorb fixes + the LESSONS-LEARNED reconciliation.
