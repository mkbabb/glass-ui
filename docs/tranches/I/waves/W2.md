## Purpose

The H deep-audit Playwright lane caught one runtime regression that read-only audits missed: `flourishes.vue` shimmer matrix is silently broken by `cn() + tailwind-merge` (the `text-shimmer-{blue,vivid,pastel}` classes are stripped because tailwind-merge treats them as conflicting with `text-display-3` under the `text-*` prefix heuristic).

Plus the ε performance audit found 3 failing tests in `tests/public-surface.spec.ts` (utilities.css `--shimmer-duration` / `.code-badge` strings + dock surface key-list drift) sitting unguarded at HEAD — never run by CI.

Plus the δ audit's CRIT-2 (Tabs provide/inject NOT delivered) was a false positive per H FINAL but the dispute lives on; W2 re-verifies under runtime probe to settle.

## Scope

### Phase A — Shimmer matrix fix

`demo/stories/foundations/flourishes.vue` line 197 (or near the `SHIMMERS` iteration): change

```vue
<p :class="cn(s.cls, 'text-display-3')">{{ s.sample }}</p>
```

to

```vue
<p :class="[s.cls, 'text-display-3']">{{ s.sample }}</p>
```

Vue's native array binding bypasses tailwind-merge's conflict resolution. The shimmer class survives. Verify with Playwright `browser_evaluate` probe:

```js
() => {
  const samples = ['Aurum', 'Boreal', 'Carnival', 'Daydream'];
  return samples.map(word => {
    const xpath = `//*[contains(text(), '${word}')]`;
    const el = document.evaluate(xpath, document, null, XPathResult.FIRST_ORDERED_NODE_TYPE, null).singleNodeValue;
    return { word, classList: Array.from(el.classList), color: getComputedStyle(el).color, bgImage: getComputedStyle(el).backgroundImage.slice(0, 50) };
  });
}
```

Expected: each sample's `classList` contains `text-shimmer-{gold,blue,vivid,pastel}` AND `text-display-3`; `color: rgba(0,0,0,0)`; `bgImage: linear-gradient(...)`.
