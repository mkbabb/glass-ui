2. **Migrate** any retired-symbol root-barrel imports to subpath imports per L MIGRATION.md (carry-over from W0 + new discoveries).
3. **Audit** for cross-cutting duplication per M.Rε §B inventory:

5. **Tranche-format adoption** (optional): if consumer has no `docs/tranches/`, propose adoption decision.
