## Per-lane scope

Each consumer-lane does:

1. **Read** the consumer's current state at HEAD:
   - `package.json` glass-ui pin (file: link OR published version)
   - `package.json` Vue + Tailwind + reka-ui + vueuse versions vs glass-ui v1.0 peer-dep stack
   - Entry imports + retired-symbol audit

2. **Migrate** any remaining retired-symbol root-barrel imports per L MIGRATION.md (carry-over from W0 + new discoveries). Patterns:
   - `Input` / `Textarea` / `Combobox*` → `@mkbabb/glass-ui/forms`
   - `useGlobalDark` → `@mkbabb/glass-ui/dark`
   - `useKeyboardShortcuts` family → `@mkbabb/glass-ui/keyboard`
   - `Carousel*` / `useCarousel` → `@mkbabb/glass-ui/carousel`
   - `useOffsetPagination` → external (`@tanstack/vue-virtual` OR native)
   - `useVirtualSection*` / `useWindowedStore` → external

3. **Audit** cross-cutting duplication per M.Rε §B inventory. For each duplication, decide:
   - **DOCUMENT-AS-DIFFERENT**: consumer's impl is genuinely different (e.g., consumer-specific feature). Document the divergence in proof.
   - **ELEVATE-via-glass-ui-subpath**: if glass-ui already exports the canonical impl, migrate consumer to consume it.
   - **KEEP-AS-IS**: trivial 5-line helper; KISS says don't move it.
   Per the revised M plan: most duplications stay KEEP-AS-IS or DOCUMENT-AS-DIFFERENT. ELEVATE only where it's a clear simplicity win.

4. **Verify version-coherence**: glass-ui pin should be v1.0.x (file: or published); Vue ≥ 3.5; Tailwind ≥ v4; reka-ui ≥ 2.0; vueuse ≥ 14.0.

5. **Build + test** the consumer; report PASS/FAIL.

6. **Author** per-consumer proof doc + per-consumer CHANGELOG entry (if consumer has one).
