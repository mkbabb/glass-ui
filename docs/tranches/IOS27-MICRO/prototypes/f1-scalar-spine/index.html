All three channels are followers off ONE spine.

R1 — per-frame spine-var cost over a 40-consumer subtree

40 elements each consume --gl-t through calc transfers (opacity + transform). The spine writes per frame for 180 frames. "natural" reports rAF frame gaps (dropped > 24ms); "forced" adds a synchronous getComputedStyle read per frame — a style-recalc cost proxy, not the real pipeline number. The browser seat owns the DevTools trace.

—

R2 — CSS-transition followers under scrub reversal

Two registered <number> props with per-state transition durations (medium-like 75/420ms, fade-like 195/165ms — 3τ linear stand-ins for the exponential followers). The storm toggles targets at irregular 80–180ms intervals while sampling computed values every frame; a retarget must continue from the current computed value — any jump > 0.30 is a snap and fails the probe.
