The tuning is reference-anchored: every change is read back against the W-AUR1 metric numbers, not by
eye. The five moves:

1. **T1 — the −5/3 turbulence-cascade eddy/dab size law (the keystone; `mediums.glsl.ts` +
   `brush.glsl.ts`).** The current three-layer cascade (`paintStrokeLayers` `:329-392`) uses HAND-SET
   radius multipliers `sBig = baseScale*2.4`, `sMed = *1.1`, `sSml = *0.45` (`:334-336`). Re-space the
   layer radii so the dab-size ENERGY distribution follows the −5/3 Kolmogorov law across the
   large→mid band (H-research §2: β=1.67±0.13 on Starry Night; the radii should be −5/3-power-spaced,
   not arbitrary). The van-Gogh `bestOil` energy-grade (`brush.glsl.ts:337-342`) already modulates
   length by luma+coherence; the cascade RADII are the missing axis. The fill layer (`:373-381`,
   van-Gogh `densityFill=0.09`) crosses to the −1 fine-dab regime. The falsifiable target: the live
   van-Gogh readback's radial-luminance power-spectrum slope ∈ **[−1.85, −1.45]** (W-AUR1 §4.3).

2. **T2 — colorfulness-anchored chroma (`atoms.ts:150-155` + the per-medium `pigmentSat`).** The
   `COLOR_ENERGY` poles (`saturation {calm 0.85, vivid 1.2}`, `valueVariance {calm 0.04, vivid 0.14}`,
   `temperatureShift {calm 0.15, vivid 0.5}`) and the per-medium `prof.pigmentSat`

   van-Gogh + oil mediums render Hasler-Süsstrunk colorfulness `C` within
   **[ref−15, ref+25]** of the `starry-night-crop.png` reference C (W-AUR1 §4.1; named cutoffs
   moderately 33 / averagely 45 / quite 59 / highly 82 / extremely 109). The constraint is BIDIRECTIONAL:
   not washed-out (a pastel smear scores ~20 → fail), not garish (over-saturated past ref+25 → fail).
   The smooth default's colorEnergy midpoint (`t=0.5`, the wispy-sky default) is UNTOUCHED — only the
   poles + per-medium sat shift, and `proof:aurora-atoms-roundtrip` DEFAULT-PRESERVING locks the
   default config byte-identical.

3. **T3 — ETF stroke-coherence tuning (`mediums.glsl.ts` `structureTensorField` :37-81 + the van-Gogh
   profile).** The structure-tensor field already exists and the van-Gogh bridge forces tensor
   orientation. Tune the coherence-weighted blend (`:79` `mix(fallbackDir, tangent, A)`) and the
   van-Gogh profile's hardness/density (`:262,266-270`) so the rendered van-Gogh field's mean interior
   structure-tensor anisotropy `A = (λ₁−λ₂)/(λ₁+λ₂)` lands in the W-AUR1 §4.2 band off
   `starry-night-crop.png` — high-but-not-degenerate (strokes FLOW along iso-bands, the van-Gogh
   signature), with NO periodic spike in the orientation HISTOGRAM (the Kuwahara-pinwheel / grid-banding
   regression detector).

4. **T4 — Kubelka-Munk subtractive chroma for oil-pastel (`mediums.glsl.ts` `mediumOilPastel` :460-463 /
   `profileFor` MEDIUM_OILPASTEL :284-300).** The oil-pastel scumble currently composites overlapping
   strokes via the OKLab `paintOverOklab` path (`brush.glsl.ts:175-179`) — which holds chroma at the
   midpoint (NOT the linear-mix grey collapse), so the K-M direction is already correct. The TUNE: lift
   `pigmentSat` (`:293`) / the `uBrokenColor` jitter magnitude so the oil-pastel medium's colorfulness
   clears the same §4.1 band (subtractive mix PRESERVES chroma; a lerp muds it grey → fails). The
   existing `proof:aurora-oilpastel-medium` gate STAYS green (the medium-distinct contract); this ADDS
   the colorfulness read on top.

5. **T6 — Khronos PBR-Neutral tonemap (`tonemap.glsl.ts`).** Swap the Narkowicz ACES (per-channel
   blue→magenta skew on saturated stops — visible on van-Gogh's saturated blues) for Khronos PBR
   Neutral (hue+saturation preserving, built for well-exposed [0,1] designed backdrops, ~13 lines,
   texture-free). The DELTA on a saturated van-Gogh frame must show NO magenta skew (and the T2
   colorfulness metric catches a skew regression as a chroma swing outside the band). AgX stays behind a
   `cinematic` opt-in ONLY if a consumer needs it (no speculative addition — the default is PBR-Neutral).
