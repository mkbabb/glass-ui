   `challenge/{1,2,3}.md`.

   path (what to keep/refine/re-invent — deft integration, KISS) + the concrete WAVE AMENDMENT
   (augment/update/prune extant `docs/tranches/BD/union/waves/` specs, referencing GOLDEN.md). →
