### 2. The mid-flight snap-flash GUARD — `setSilhouette` is VELOCITY-CONTINUOUS re-seat, NOT `clearFlips`-hard-snap (the ONE src edit)

The mechanism:

- **`clearFlips()` on re-entry is REPLACED by a re-seat that preserves continuity.** Instead of `clearFlips()` (which writes `transform = ""` → the box JUMPS to its untransformed layout rect for one frame), the re-entry RETAINS each in-flight `ElementMorph`'s last-applied transform until the new morph's first `apply()` overwrites it (the no-intermediate-clear discipline). The `flips[]` array is rebuilt from the live rects; the OLD `ElementMorph`s are dropped only after the new ones own each element (a swap, not a clear-then-build).
- **The rAF time-ramp gains a velocity carry on re-entry (the C¹ re-base).** The manual `(ts - startTs) / durationMs` ramp re-bases its `startTs` so the new transition's eased curve starts at the eased-value the interrupted transition was AT (not 0) — the curve is C⁰-continuous in position.
