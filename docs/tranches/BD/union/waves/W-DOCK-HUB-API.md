## The defect / the ask
The dock today expands into FIXED shapes: the two-layer grid (default + `collapsed` slots), `DockLayerGroup`/`DockLayer` panes, the `DockStack` rail, the cta-receive card morph. Each is a SPECIFIC facility. The user wants the dock to be a GENERALIZED HUB: expand from a dock control into ARBITRARY content — a card, a panel, a viz, a configurator, a custom surface — via ONE generalized API, with the liquid morph, NOT a per-surface hardcoded path. AND: zero app-specific hardcoded refs (no "maps", no overfit names) — the library ships generalized glass/dock precepts; the consumer supplies the content.

## The mechanism (generalize, compose, no-dual-path)
`<DockExpand>` (or a `useDockExpand` + a generalized expand-target contract on `GlassDock`): a dock control declares an EXPAND TARGET (a named slot / a render-prop / a `:is` component target) + an `expand` trigger; on expand the dock morphs (the EXISTING liquid dock-morph + the W-LIQUID-REVEAL bloom-from-source) into the slotted content, ANCHORED at the control (the source-rect bloom), over a glass surface, bidirectional (collapse morphs back). The CONTENT is fully consumer-supplied (any component) — the library owns the MORPH + the glass chrome + the anchor geometry + the a11y (focus move, escape, aria-expanded on the trigger), NEVER the content shape.
- Composes the SHIPPED primitives: the dock-morph orchestrator (`dockMorphContext`), `useLiquidReveal` (the source-rect bloom), `useDockCtaReceive` (the inverse — external→dock), the box-INVIOLATE `.glass-dock-frame` escape, the `<DockStack>` rail. It does NOT fork a second morph engine.
- The SUB-DOCK split (the ios27 video — the apple-music logo goo-splits off the core dock to form the bottom dock): a generalized `DockSplit`/`spawnSubDock` — a dock control goo-splits (the metaball-bridge / the morph-showcase goo) into a SEPARATE sub-dock, which is itself a `GlassDock`. Generalized (any control can spawn a sub-dock with consumer content), not a maps-specific path.
- The expand can target ANY layout: a floating card, a full panel, a sheet, a viz stage — the consumer picks; the dock provides the morph + anchor + glass.
