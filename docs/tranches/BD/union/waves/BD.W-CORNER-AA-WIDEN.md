The CSS Filter Effects fact: **`backdrop-filter` is clipped to the element's `border-radius` ONLY when the element establishes its own backdrop-root cleanly; a `border` + `box-shadow` rim + a transformed/`isolation`-affected ancestor degrades the corner sampling so the saturated backdrop region is rasterized to the PADDING/BORDER box, not the rounded content box** — the square-halo + jaggy-arc the user screenshotted. `overflow: hidden` does NOT clip a `backdrop-filter` (the b538dec7 commit-body fact). ## The mechanism

Clip every glass tier's `backdrop-filter` layer to its OWN corner radius, idiomatically — compositor/paint-only (`clip-path` is a paint property, never layout; `proof:no-layout-animation` stays GREEN by construction), `isolation`-safe, with the two-sided fence the architecture demands (clip the plate halo; NEVER clip a surface whose decoration legitimately overhangs).

1. **Clip the backdrop halo to the box radius on the SHARED material group.** The five ladder rungs + `.glass-card` already share ONE `position: relative` group in `material.css:36-49` (the single source — "adding a surface to the band material is one comma-entry here"). Add a library-wide `clip-path: inset(0 round var(--radius, …))` arm on that SAME group (or the ladder rungs directly where each rung's radius differs), the `<radius>` reading the surface's OWN corner token so the clip MATCHES the painted `border-radius` exactly. `clip-path` DOES clip a `backdrop-filter` (the b538dec7 mechanism), so the saturated backdrop region cannot bleed a square behind the rounded plate — the corner reads the smooth arc. The radius source is the EXISTING token the tier already paints with (`--radius-card` for `.glass-card`, the rung radius for the ladder; the `border-radius: inherit` precedent in `material.css:95`/`ladder.css:442`) — NO new radius token, NO magic number.

2. **`inherits`/`isolation`-safe — the clip travels with the painted box.** The clip-path lands on the SAME element that carries the `backdrop-filter` (the rung/`.glass-card` itself), NOT an ancestor — so a transformed/`isolation`-scoped descendant cannot mismatch the clip against the scaled child (the BF.W-CORNER-AA C4 in-flight-clip lesson, generalized to the static ladder). Where a surface's radius is dynamic (a consumer retunes `--radius-card`), the clip re-resolves through the same token automatically (presets-in-consumers).

3. **The Safari floor (the ABSOLUTE fence).** `clip-path: inset(… round …)` is cross-engine Baseline (WebKit-safe; the `-webkit-` prefix is auto-injected by the build's `publishStyleAssets()` prefix pass where needed, the ladder's existing `-webkit-backdrop-filter` precedent at `ladder.css:21`). The AA MUST hold on WebKit — Safari's `backdrop-filter` corner sampling is the WORST case (the saturate halo squares most visibly on Safari), so the clip is load-bearing there. NO `clip-path: url()`, NO mask-image second layer, NO `backdrop-filter: url()` — the fix is a single cross-engine `inset(… round …)` paint property.

4. **The two-sided fence — NEVER clip a legitimately-overhanging decoration.** The clip is scoped to the SELF-CLIPPING plate tiers (the ladder + `.glass-card` + `surface="clear"`). It must NOT clip:
   - the moving-specular `::before` / grain `::after` (they already `border-radius: inherit` + `inset: 0`, so they self-clip to the rounded box — clipping them again is a no-op but the gate records they are NOT amputated);
   - the dock fission pieces (`.dock-fission-piece` fly OUTSIDE their host box — the BF.W-CORNER-AA C3 `splitClip:none` invariant; a box clip-path on the fission host amputates the goo halves);
   - the `.glass-dock` shell (the `dock-shell-exempt` named exemption in `proof:glass-cohesion` — the dock owns its own `--glass-*-dock` family + the dock-band `morph.css`/`shape.css` clip).
   The gate's anti-evasion bite: a box-level clip-path on the fission host or the dock shell REDs.

This is NOT a re-fork — it composes the EXISTING corner-radius tokens + the EXISTING `clip-path`-clips-backdrop mechanism the dock band already uses (`fission-bridge.css`/`morph-bridge.css`/`squircle.css`/`liquid-morph.css` all `clip-path`). The fence is ONE paint arm on the shared material group, library-owned. It SUBSUMES BF.W-CORNER-AA: that wave's dock-only clip becomes the `.liquid-*` member of the SAME library-wide fence (the dock surfaces keep their per-surface clip; the ladder gains its own), recorded as one AA fence, not two.
