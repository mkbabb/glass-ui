## The defect / the ask (Pass-D code-grounded — `viz/fleet2/deep-audit-original-plan.md:109`, `UNIFIED-ROSTER.md:108`, the RE-CAPTURE dep-edge `EXECUTION-DAG.md:96,210`)

The goo-fission split is the headline iOS-27 dock move, and it is the single most per-frame-expensive dock paint: an in-document SVG `<filter>` (`#dock-fission-goo`, `fission-bridge.css:106-112`) running a `feGaussianBlur` + `feColorMatrix` threshold over the splitting pieces, every frame, while the `--dock-split-t` spring drives the pieces apart. The roster row (`deep-audit-original-plan.md:109`) is verbatim *"the real-Metal p50 goo budget; mandate-affirmed (re-captures after the fidelity waves)."* The defect is two-fold:

1. **The pre-fidelity number is STALE by construction.** The DEVTOOLS-VALIDATION real-Chrome run (`union/DEVTOOLS-VALIDATION.md:10-11`) confirmed the HEAD goo neck PAINTS on real GPU at mid-pinch (`--dock-split-t = 0.42`, a smooth continuous metaball waist), but that is the HEAD goo — a FIXED-radius blur on a confined per-piece neck. The three Tier-2/Tier-4 fidelity waves each make the per-frame goo **HEAVIER**:
   - **W-FISSION-FILAMENT (T4)** re-anchors the neck to a BODY-ANCHORED spanning filament with a per-frame `--dock-goo-blur` `stdDeviation` write (`f(gap / --dock-goo-spacing)`) — a per-frame-varying `feGaussianBlur` radius is more expensive than a fixed one (the blur kernel re-derives each frame, AND a larger gap-sized radius is a wider kernel).
   - **W-DOCK-SUBDOCK (T2)** lands the PERSISTENT sub-dock terminus (the iOS-26 `.tabViewBottomAccessory` re-seat law) — the goo `<filter>` stays ARMED past the snap (the persistent accessory keeps the metaball mass alive), so the goo cost is no longer a transient during-split spike but a STANDING per-frame cost while the sub-dock persists.
   - **W-DOCK-GOO-SPACING (T4)** lands the `--dock-goo-spacing` merge-threshold + the adaptivity flip — the per-frame `--dock-goo-blur` the orchestrator writes scales against it (the blur is no longer a constant).
   So the p50 budget captured BEFORE these waves measures a goo that no longer ships. **The budget MUST re-fire over the FINAL goo cost** (the spanning neck + the persistent terminus + the merge-threshold), never the pre-fidelity number — the RE-CAPTURE dep-edge the roster + DAG record (`EXECUTION-DAG.md:96,210`).

2. **The Safari-on-Metal number is UN-AUTOMATABLE.** The general `BD.W-VIZ-PERF-BUDGET` worst-case methodology runs on the Metal dev-box via chrome-devtools — but chrome-devtools is **Chromium** on Metal, and the goo `<filter>` is a WebKit-specific SVG-filter path (the §8 Safari fence: the goo is the regular `filter: url()` sRGB, WebKit-supported, NOT `backdrop-filter: url()` bug 245510). WebKit's SVG-filter rasterizer is a DIFFERENT cost than Chromium's, and `playwright`'s bundled WebKit is **Linux-WebKit** (a different rasterizer than Safari-on-Metal). The binding number is a hand-driven **real Safari 26 on a real Metal device** capture — the manual un-automatable arm this wave owns (the W-SAFARI-CAPTURE / VIZ-PARITY-METAL device-rig precedent).
