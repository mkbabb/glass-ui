## The loop (per the goal)
For each FEATURE (dock, liquid-tabs, aurora, card, glass-every-element, buttons/icons, the KISS API, …) run the **triumvirate**:
1. **Research** — archaeology of the 4 tranches + the 100+ sessions + the reference media (frame-by-frame) + external SOTA (Apple HIG / Awwwards / birthdaycolor.com / Safari feasibility).
2. **Plan + tranche-write** — author the wave spec(s), pursuant to precepts.
3. **Prototype (if needed)** — aggressively prototype the facility to validate the spec; spawn the dev server; **Safari + Chrome**.
Then **deploy a hardening fleet** to ruthlessly critique the research / wave set / prototype — iterate feature-by-feature **until each wave set converges**.

Finally a **gestalt-hardening pass**: inter-wave consistency + cogency — hunt dissonance + development friction, challenge the waves in totality, add/prune/re-write to **CONGRUENCE** with: the design language · KISS · DRY · component/composable/sub-component encapsulation · default-shadcn abrogation · no-legacy · paint-first · presets-in-consumers · compositor-only · Safari-first.
