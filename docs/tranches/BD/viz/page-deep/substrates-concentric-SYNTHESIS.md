### Conflicts resolved

- **No real conflicts** between the three lenses — they agree on every defect. The design lens elevates the dead-stage + bleed-through to P0 rendering bugs (the demo lens names the same two as §1/§7); the component lens confirms BOTH are demo-scope (the component math paints correctly when the substrate arms) and contributes the three small component arms (A/B/C).
- **Dead-stage root-cause reconcile (the binding one).** The component lens reads P0-a as a SHARED substrate WebGPU dead-stage (concentric + dot-flow both 0px). The dot-flow SYNTHESIS already resolved this class: the blank field is the **deferred-arm-vs-zero-extent-flex resize race** the substrates-GESTALT names systemic [BROKEN] #1 — the hand-rolled `tier="field"`/raw-Configurator surface gives the canvas no resolved box, so `armAsync`/the resize never fires; `<DemoStage>` (the `W-STORY-PAGE-STANDARD` stage primitive) **fixes it BY CONSTRUCTION** (a resolved stage box that fires the resize). The shared WebGPU-output/readback fault is OWNED by `W-PRESET-RENDER` + `W-DOTFLOW-REBUILD` (the same read-back-within-the-frame fix); concentric ENROLLS in the `<DemoStage>` resize π that reds a 0px / 300×150 canvas. **Resolution: P0-a is NOT a new wave — it folds into the `<DemoStage>` migration (W-STORY-PAGE-STANDARD) + the shared WebGPU readback root (W-PRESET-RENDER), with concentric as a co-exemplar of the resize π.**
- **Bleed-through reconcile (P0-b).** The design lens names the stacking/`isolation` fix; this ALSO dies by construction in `<DemoStage>` (the stage primitive owns an opaque/isolated paint floor + a proper z-layer over the scrolled-up chrome). One migration, both P0s die. The floor (if the migration slips a loop) is a literal `isolation: isolate` + an opaque/near-opaque stage backdrop on the existing tile.
- **Default-colorless reconcile.** P0-a's "warm-cream-over-transparent is invisible" and finding #5's "colorful premise unmet" are the same precept failing (W54: glass/field needs a rich backdrop to POP). Per the dot-flow resolution and the one-GL-per-route budget already spent on the field, the move is to TINT the field's OWN palette to a loud `--section-color` event as the demo LEAD (a `presets-in-consumers` demo preset — the teal-on-navy register promoted to default, or a warm-amber→violet walk), NOT to mount a second `<Aurora>` context. One deliberate color event, the suffusion rule.
- **Component "no redo" vs demo/design "broken":** not a conflict — different layers. `src/components/custom/concentric/` needs no new wave (only A/B/C arms); `demo/stories/substrates/concentric.vue` + the chassis is where #1–#9 live, all zero/near-zero `src/` paint.
