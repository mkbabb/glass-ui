## Lane A—`CONFIGURATOR_DENSITY_KEY` paired helpers (P-3a)

Per Pδ §"3/6 compliant"—`src/components/custom/configurator/density.ts` ships only the typed `InjectionKey<ComputedRef<ConfiguratorDensity>>`. Add per the invariant 25 canon (analog of O.W2 dock):

```ts
import { inject, provide, type ComputedRef, type InjectionKey } from "vue";

// Existing typed key preserved.
export const CONFIGURATOR_DENSITY_KEY: InjectionKey<
    ComputedRef<ConfiguratorDensity>
> = Symbol("configuratorDensity");

export function provideConfiguratorDensity(density: ComputedRef<ConfiguratorDensity>): void {
    provide(CONFIGURATOR_DENSITY_KEY, density);
}

/** Strict—throws when used outside `<Configurator>`. */
export function useConfiguratorDensity(): ComputedRef<ConfiguratorDensity> {
    const ctx = inject(CONFIGURATOR_DENSITY_KEY);
    if (!ctx) throw new Error("[glass-ui:configurator] useConfiguratorDensity() called outside <Configurator>");
    return ctx;
}

/** Befitting silent default—falls back to `'comfortable'` for primitives that may render outside a Configurator. */
export function useOptionalConfiguratorDensity(): ComputedRef<ConfiguratorDensity> | null {
    return inject(CONFIGURATOR_DENSITY_KEY, null);
}
```

Migrate `Configurator.vue` + `ConfiguratorRow.vue` to use the new helpers. Internal callsites: ConfiguratorRow's density fallback (currently `inject(CONFIGURATOR_DENSITY_KEY, undefined)`) → `useOptionalConfiguratorDensity()` (returns null → null-coalesce to `"comfortable"` matches prior visual).

Per Pδ R3: ConfiguratorDensity's `undefined` default is load-bearing for pre-N.W2 visual preservation. The migration preserves this via the optional helper's `null` return + consumer-side null-coalesce; typecheck-enforced.
