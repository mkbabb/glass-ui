## 0. What this seat had to be careful about

The de-duplication pass rewrote `PLAN.md` hours before this seat ran. That inverts the usual redo
posture: the opus-begat text is no longer what is on disk, so "assume the artifact is wrong" could
easily have meant "restore what the de-duplicator struck" — which is the single worst thing this
seat could do, and is explicitly forbidden by the charter. The SCRUTINY phase therefore ran against
two different suspicions at once:

1. the ORIGINAL suspicion — is the surviving prose true at HEAD?
2. the NEW one — did the strike leave a hole? A pointer that points nowhere, a cross-reference to a
   section that was renamed, an obligation whose owner was removed with the text that named it.

Suspicion 2 is where every finding below came from. **The de-duplication pass's strikes were all
correct and none is reversed here.** What it did not fully do is re-thread the references that ran
through the struck text — which is a different job, and is precisely the capstone's.
