- Penetration ≈ 12pt at ≈520pt/s entry → rubber-band gain ≈ 0.023pt per pt/s (linear-ish for small overpull).
- Release is a single asymptotic return over ~380ms — no oscillation past rest, +1px-per-frame creep for the final third. One bounce, sealed.
- Compression is 4-5x faster than release (≈90ms in, ≈380ms out) — the asymmetry is what makes it read as elastic resistance rather than a symmetric spring.
