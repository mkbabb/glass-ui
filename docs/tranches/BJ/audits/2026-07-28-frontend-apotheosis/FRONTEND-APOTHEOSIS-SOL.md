## Terminal verdict

The frontend direction is good; the shipped frontend is not yet that direction.
At `d844bef6` plus the live dirty tree, BK is a formulated execution programme,
not a landed reduction: `src/components` still has 62 governed family
directories and 174 Vue SFCs; 81 component files import Reka; `data-slot` occurs
180 times; `data-part` occurs 11 times; and 122 source sites call `cn()`. The
Browser proves a working fixed shell, focus transfer, reachable desktop/mobile
endpoints, and credible individual controls. It does not prove system-wide
Golden Glass, Breath of Life, or Movement of Momentum.

Resume BK only after the in-flight stage-2 fold is sealed through its durable
workflow. The three arm candidates and scratchpad canon are evidence, not current
authority. The coordinating audit preserved the scratchpad canon's exact bytes
under
`../2026-07-28-claude-resume/salvage/W-DESIGN-CANON-APOTHEOSIS/`:

`d625484bf564edf6c8507b06231c9f226a0214fd5de1260aa795190fb9fdf77a`;

`8cd8377e8b9331f21921f47ce4d10446cc982e827fdcb7a51749395a249b523b`.

its public anatomy, default appearance, naming, or documentation promise from the
shadcn catalogue. It is not the removal of all headless dependencies, utilities,
part attributes, or consumer classes.

## Demo/workbench architecture

Keep `AppShell`'s one main scroller, route scroll reset, focus transfer, live
announcement, and bottom-row reservation. Keep `StoryPage`/`StoryHero` as the one
page chassis, but bind `SectionLanding` to `landing.heroScale` instead of the
hard-coded `"4"`.

```text
category rail ┃ title + one-sentence contract
              ┃ ACTIVE LENS — one live specimen, one revealing field
              ┃ state / keyboard / material / motion controls
              ┃ API, behavior, migration, copyable example
──────────────┻ previous · current · next · all stories…
```

- Desktop keeps a compact category rail. Mobile uses the on-demand chooser.
- The persistent bottom control exposes previous/current/next plus one full-story
  menu; it does not expose all 87 stories as permanent tabs.
- Split manifest route/content identity from optional demo-presentation metadata.
  Delete keys that restate component defaults.
- Replace the identity-title preview floor: use a reusable family specimen, an
  honest frozen renderer still, or no preview. Reserve authored `.tile.vue` files
  for marquee specimens.
- Put the component before explanatory prose. `/dock/overview` and
  `/substrates/aurora` currently reverse that priority; `/forms/inputs`
  over-containerizes comparison states.
- Do not add a new font or token rainbow during reduction. Keep Plus Jakarta Sans,
  Fira Code, warm paper/ink, legendre violet, and gold; spend chroma in the active
  specimen field.
