### 4.4 The terminal method — and the instrument defect it exposes

**Method of record (v3, unchanged and correct):** strip comments before extracting anything; parse rather than grep for `defineProps`/`withDefaults`/`interface *Props`/`defineEmits`/reka imports; seven independent feature spaces never collapsed to one number; a space with <4 members on either side returns `null`, not a score; a pair is a candidate only when ≥2 independent spaces agree at ≥0.5. The generalisable lesson stands: **a structural-similarity metric over a component library must be multi-space, comment-blind, and degenerate-set-guarded.**

**But the *superfluity* instrument is defective, and the headline claim does not survive it.**

```
components with ≥2 non-CSS src consumers ......................  1 of 62   (dock — and its 7 are leaks INWARD)
components with zero non-CSS src consumers ..................... 54 of 62   (44,664 LOC)
components whose ONLY src consumer is a stylesheet ............. 12
  button(1) card(1) chip(1) completion-seal(1) configurator(1) dark-mode-toggle(1)
  drawer(1) header-ribbon(1) instrument-chassis(1) metric(1) scroll-progress-rim(1) toast(1)
```

`Button` has **zero** runtime src consumers and **50** demo consumers. Applying "≥2 src consumers" as computed deletes 61 of 62 components including Button. **In a leaf-component library, zero src consumers is the architectural norm, not a defect signal** — components are consumed *by consumers*, and the only in-repo consumer is the demo. The "42 of 62 have zero src consumers, 67% of the tree" headline is measuring library shape, not overfitting.

**The corrected bar, and the frontier it actually produces.** A component earns its seat if it has **≥2 demo consumers OR ≥1 external/documented consumer OR a stated non-demo purpose**. Applying *that*: **34 components** (25,666 corrected LOC) sit at zero runtime src consumers **and** ≤2 demo consumers — that is the honest frontier, and it is where `W-DAG-REDUCE` should run. It is a smaller, sharper set than 42 and it does not contain Button.

> **The claim to carry forward is not "42 components are superfluous." It is: duplication is refuted (one candidate pair in 1,891; zero CSS pairs ≥0.34 anywhere), and superfluity must be judged on demo-and-external consumption, because src consumption is structurally near-zero by design.**
