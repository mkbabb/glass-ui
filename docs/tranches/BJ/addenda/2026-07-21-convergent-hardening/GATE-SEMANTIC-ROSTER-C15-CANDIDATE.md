## C14 blocker redress

### Live writers: execute the real carrier and token classes

C15 keeps the direct reka-ui origin sentinel as a necessary origin-forwarding
proof, but no longer treats it as sufficient. Every rendered branch of all
seven current carrier SFCs now has a structured `carrierExecutionWitness`.
Each witness names:

- the exact exported Glass carrier and rendered branch;
- its exact minimal root/provider/portal harness;
- the exact built-in `[--overlay-pad-inline:*]` and
  `[--overlay-pad-block:*]` class strings;
- the exact connected native tag and owner identity.

The class strings must traverse the actual carrier source expression and the
approved `cn`/`computed` implementation onto that owner. A direct underlying
component sentinel, unrelated harness node, sibling or different descendant
cannot satisfy the witness.

The decisive mutation keeps every source literal, binding and approved origin
intact while changing the resolved `cn` implementation to filter only those
two token-definition families. The direct origin sentinel may remain GREEN;
the actual carrier witnesses must turn RED. A second mutation makes one actual
carrier branch non-rendering while its underlying origin sentinel remains
GREEN. Thus static AST flow and component forwarding can no longer combine
into a false end-to-end claim.

### Chip: exact static-host boundary

The Chip row now promises only what its mechanism executes. The lifecycle
captures the exact component host at each settled mode. At static settle, the
host must be a Span with no forwarded role, tabindex, pressed/state relation,
descendant Button or hostile consumer click listener. The hostile click is
dispatched at that exact static host and its spy must remain zero.

The born-RED listener mutation forwards the hostile consumer `onClick` onto
that static host. Consumer-authored slot descendants and clicks originating on
those descendants are explicitly outside this row, as are caller-authored
`contenteditable` and unlisted events. This prevents both an unearned global
event claim and a loophole in the exact host contract.
