### W2-B5 — CSS capture is fail-open and can alter order

Capture accepts one repeated aggregate rule count, proceeds silently after exhaustion, skips
inaccessible sheets, hashes nothing, and deduplicates equal `cssText` by first occurrence. Equal
counts can hide replacement, while deduplication can change later cascade position. One Drawer
route's route-unioned development CSS is not either published style graph.

Opening is followed by two rAFs rather than a semantic settle. `probeScrim()` overwrites the real
producer's inline `--stage-t`, then removes the property instead of restoring its original value.
Screenshots therefore follow diagnostic mutation, not an untouched settled lifecycle. The mobile
arm resizes a Desktop Chrome context rather than creating a true coarse/touch receiver.

### W2-B7 — the Command negative can pass unopened
