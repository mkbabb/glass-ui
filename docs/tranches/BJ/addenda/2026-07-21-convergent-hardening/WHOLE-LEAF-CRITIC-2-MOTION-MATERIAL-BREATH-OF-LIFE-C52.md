## 1. Failure-assumed reading of the owner direction

“BREATH OF LIFE” is not permission to make every resting object breathe.
`PLAN.md` §3 makes engagement-responsive life required while the pending
`ASK-27` leaves ambient idle animation unauthorized. “MOVEMENT OF MOMENTUM” is
semantic mass: tracked gestures, velocity-bought overshoot, interruption from
the current frame, and a truthful settle. It is not a universal bounce token.

The iOS27 floor is therefore conjunctive:

1. A spatial event has one geometry authority and one trajectory.
2. The event begins at its natural source: pointer, thumb, selected item,
   trigger, dock aperture, or the existing object itself.
3. Light leads geometry only where the event warrants it; text and data stay
   readable; held light is a state envelope, not an unrelated loop.
4. Geometry does not overshoot without measured velocity. Exit never overshoots.
5. Independent bodies overlap hard. Goo is reserved for one body.
6. Glass bends the backdrop. It does not blur its own copy, icon, or text to
   impersonate depth.
7. PRM is a distinct terminal rendering, not a global pause and not an absent
   feature.
8. One earned chroma event may punctuate the warm scientific-paper field. A
   second decorative gold/rainbow pulse is noise.
9. Static components owe stillness. Adding a clock to “complete” them would be
   a regression.

The admissible spines remain the motion canon's shared spring/keyframe clock
plus its specifically sanctioned pointer-velocity, lead/trail, and drag-morph
seams. A component may compose those mechanisms. It may not mint another
geometry clock, reset a live trajectory to a stale origin, or hide a raster
failure with blur.

## 3. Cross-cutting failures before family-by-family credit

### 3.1 Layout is still being animated as geometry

The current source contains direct motion-canon P5 violations:

- Card scroll condensing transitions `padding-block-start` and `font-size`
  (`src/components/card/card-scroll.css:4-8`, `:29-43`). This makes descendants
  reflow while the title changes size.
- Accordion and Collapsible share keyframes that animate `block-size` from zero
  to measured content height
  (`src/components/_shared/disclosure/disclosure.css:1-23`, `:90-113`).
- Drawer changes and transitions grip `width` while held/hovered
  (`src/components/drawer/styles.css:282-303`).
- Dock's layer indicator transitions `width` and `height` on a generic fast
  duration while claiming a spring-owned selected trajectory
  (`src/components/dock/styles/layer-group.css:257-290`).
- Timeline rails animate `width` and `left`
  (`src/components/timeline/ContinuousRail.vue:90-132`) and Segmented Timeline
  adds another width/transform clock
  (`src/components/timeline/SegmentedTimeline.vue:161-168`, `:200-203`).

PRM disabling a layout transition does not make the full-motion path lawful.

### 3.2 One event still has multiple clock owners

- Segmented Tabs retains separate CSS geometry, timeout-driven stretch/blob,
  and WAAPI press authorities. It also carries distinct pill and underline
  geometries. C36/C40 already rejected that split.
- Slider hides the semantic thumb at zero width while a visible proxy owns the
  gesture; the proxy uses generic duration/spring transitions and a different
  normal-duration cartoon-punch release
  (`src/components/slider/Slider.vue:352-444`). The first coarse touch and the
  current-frame release are not one proved trajectory.
- Dock claims one morph scalar but retains an own-pixel blur arm
  (`src/components/dock/styles/morph.css:66-93`) plus secondary selected-rail
  size clocks. C37's one-shell/one-state/one-optical-plane contract remains
  unsatisfied.
- Scroll Progress Rim uses a spatial clip-path clock, then gives an opacity
  effect a spring curve rather than the effects bezier
  (`src/components/scroll-progress-rim/styles.css:51-95`).

The correct preservation target is not “one CSS file.” It is one runtime
writer per event, with effects coupled but not promoted to geometry owners.

### 3.3 Cancellation often means “release,” not “abort”

- Drawer maps `pointercancel` to the normal pointer-up release path
  (`src/components/drawer/composables/useDrawerSnap.ts:390`). C41 requires cancel
  to restore the last committed detent, not buy a ballistic destination.
- Easing Picker captures the pointer at
  `src/components/easing/EasingPicker.vue:200-220`, but both pointer-up and
  pointer-cancel merely clear the drag index (`:228-230`, `:348-352`). No Browser
  evidence shows whether cancel commits the latest uncommitted handle or restores
  the previous curve.
- Constellation has a coherent release-well cleanup for up/cancel
  (`src/components/constellation/composables/useConstellation.ts:180-185`,
  `:225-266`), but the Browser corpus does not exercise it.

Pointer capture in source is not capture evidence. Required frames are down,
held after leaving bounds, release, cancel, and next interaction.

### 3.4 Autonomous movement exceeds current authority

- Watercolor Dot is static by default, which is the good identity to preserve.
  Its opt-in animate mode runs an unbounded five-channel rAF wobble
  (`src/components/watercolor-dot/useWatercolorBlob.ts:95-161`). It parks when
  hidden and under PRM, but no retained state proves a local pause/stop/hide path
  or an owner grant under pending `ASK-27`.
- Status Dot's `active` state defaults to a 1.8 s infinite pulse. Its semantic
  liveness and `motion="off"` are better than decoration, but Browser still must
  prove full/off/PRM and that the enclosing experience supplies the required
  control for a blink lasting beyond five seconds.
- Sortable List's drop indicator runs a 5 s linear gold shimmer forever and has
  no local PRM carve (`src/components/sortable-list/SortableList.vue:133-165`).
  Drag position is the information; the gold marquee is neither necessary nor
  the campaign's one earned chroma event.
- Typewriter Cursor blinks indefinitely
  (`src/components/typewriter/TypewriterText.vue:238-252`). PRM stops it, but no
  Browser state proves that the exposed pause stops the cursor as well as the
  character scheduler.
- Aurora, Blob, Constellation, and Fourier Field contain better lifecycle/park
  seams than these CSS loops. They still require visible pause and PRM proof;
  “GPU lifecycle exists” is not an ambient-animation owner ruling.

### 3.5 Material evidence is mostly reach, not refraction proof

Warm translucent paint against a near-uniform cream background cannot prove
backdrop blur, adaptive tint, refraction, or a non-opaque fill. Each glass tier
needs a diagnostic underlay crossing its aperture, light and dark, DPR 1 and 3,
with Safari included. Text and icons must remain crisp while only the background
is bent.

The current bright Slider fill and the shared reveal's self-blurred panels are
especially dangerous: both can read “glassy” in a still image while violating
the material model. The valid Motion Tempo frames now prove that this danger is
real.

### 3.6 Chroma is over-authored

Completion Seal's finite earned gold may serve as the one outcome accent. A
selected lens may carry the configured single accent. Sortable's separate gold
marquee, decorative metal shimmer, and any concurrent rainbow/rim event may not
all claim attention. The paper field remains warm cream, grain-visible, and
scientific; glass is a light peer, not a saturated brand slab.

## 5. What the retained Browser corpus does and does not prove

C48's 99 live screens and 396 raw rest cells, including the complete 64-screen
remainder, are valuable denominator evidence.
They prove route reach and catch catastrophic absence. They do not prove:

- an authored duration equals runtime duration;
- a spring reaches its terminal frame;
- the first pointer frame begins at the pointer/source geometry;
- a mid-flight retarget reads the current frame instead of replaying origin;
- hover survives travel from trigger to content;
- pointer capture survives leaving bounds;
- `pointercancel` differs from release;
- keyboard/focus and true coarse touch reach the same state;
- a panel bends a diagnostic underlay rather than painting opacity;
- text stays crisp at DPR 1 and 3 while the backdrop refracts;
- Safari paints the same layer ordering; or
- PRM lands an equivalent useful terminal state.

The valid Motion Tempo quartet/trio closes only one tiny portion of that list:
Dialog coarse open timing, one close/reopen attempt, and two raster samples. Its
quality result is negative. Assay A and Assay B still do not provide VoiceOver,
keyboard, PRM, Safari, backdrop-diagnostic, or focus-return proof.

The next Browser collection should be state-led, not route-led:

1. **Source and first frame:** trigger/pointer/selected geometry plus exact onset.
2. **Interior:** at least two mid frames that expose blur, deformation, and
   channel ordering.
3. **Terminal:** computed geometry/material after all clocks report rest.
4. **Interruption:** reverse from an interior frame; cancel separately from
   release; immediate next activation.
5. **Modality:** fine pointer, true coarse pointer, keyboard/focus, and AT.
6. **Optics:** crossing diagnostic underlay, light/dark, DPR 1/3, Chromium and
   Safari.
7. **PRM:** the same task completed with the intended reduced terminal state.

## 6. Fold/removal preservation law

Subtraction is correct only if it removes duplicate wrappers and engines while
retaining the useful mechanism exactly once.

- **Instrument Chassis:** remove atomically. Do not migrate its look, rename its
  shell, or use its historical Browser quality as retention evidence.
- **Confirm Dialog → Dialog:** retain Confirm's content/decision semantics and
  Dialog's one focus/overlay owner. Do not retain a second reveal recipe. The
  shared own-pixel blur must not survive the fold.
- **Motion Tempo → Springs:** retain the one tempo-reader mechanism and a real,
  reversible control. Do not keyed-remount specimens, copy durations into each
  child, or preserve a second overlay clock. The fresh Dialog evidence makes
  this a diagnostic teaching state only after its raster defect is removed.
- **Gate Pattern → existing Dialog evidence:** migrate the useful narrative and
  state controls; no Gate surface or animation owner survives.
- **Hover Card / hover popover → Popover:** retain hover-persistence content and
  tests as Popover states. Do not retain an alias component or a second hover
  timer.
- **Fuzzy Search → SearchBar composition:** retain the fuzzy engine as internal
  logic and the useful result-state specimen. Do not publish another input or
  result-motion component.
- **Carousel dots → PagerDots:** retain PagerDots' lead/trail worm and current
  target interruption. Remove any local dot geometry writer.
- **Timeline variants → GlassTimeline:** retain one mode dispatcher and each
  truly distinct semantic mode. Consolidate duplicated width/left/timeout
  clocks; internal leaves do not become five motion products.
- **EasingConfigurator → EasingPicker if owner folds it:** retain the picker,
  keyboard curve editor, and its one bounded playback. Do not copy the rAF or
  invent a wrapper animation to justify the name.
- **StoryPlayButton and one-off example wrappers:** inline the shared Button and
  local story data. Do not migrate presentation clocks into the library.
- **Blob duplicate specimen:** keep one live renderer and static/captured
  comparisons. A second mount is not a second mechanism and has no preservation
  claim.
- **Constellation overfit route:** keep one live Canvas2D lifecycle and make the
  other comparisons static. Remove the extra canvases/window-global listeners,
  not the public renderer's pointer/release semantics.
- **Compositions route:** migrate content to the owning primitive routes before
  deleting the shell. No composition-local clock graduates to public API.
- **Virtual list:** keep only if its benchmark is real and retained; otherwise
  remove it. Do not add shimmer or spring motion to create a visual reason to
  exist.
- **DataTable / Configurator / VizStudio / Fourier Field / Animated Digit /
  PagerDots:** owner survival decisions remain open where C48 says they are
  open. Motion polish is not survival evidence.

## 7. Formation verdict

**RED.** The campaign has a trustworthy leaf denominator and several mechanisms
worth preserving: one spring core, event-fed pointer physics, one lead/trail
worm, direct drag, finite earned completion, parked GPU/canvas lifecycles, and
static warm-paper primitives. That is necessary architecture, not universal
acceptance.

The current shared overlay recipe visibly blurs and ghosts its own content in
both valid coarse-mobile assays. HandMark replay destabilizes real text in both
assays while only decorative ink should change. Card, disclosure, Drawer, Dock,
Slider, Tabs, and Timeline still carry layout or split-authority motion. Cancellation,
hover-persistence, focus/touch parity, Safari material, DPR raster, and PRM
terminal evidence remain broadly absent. Autonomous loops exceed current owner
authority in several families. The one-chroma and warm scientific-paper identity
are therefore not yet protected through motion.

No family should receive implementation acceptance from rest coverage alone.
Formation may proceed only with the family/state ledger above, the owner-final
subtractions intact, and folds preserving one good mechanism without preserving
duplicated engines.
