## Material blockers and amendments

### A1 — Correct the census ontology; do not count Deck and `_shared` twice

C61 correctly records 63 immediate component directories and its matrix itself
contains 63 rows. Its terminal question nevertheless asks about “63 families,
Deck, and `_shared`,” which implies 65 owners.

Amend the canonical sentence everywhere it governs to:

> 61 Vue-bearing families + `_shared` + Deck = 63 immediate component
> directories/owners; the 174 Vue leaves belong to the 61 Vue-bearing families.

Formation remains RED if a later denominator becomes 63 + Deck + `_shared`, or
if either special owner is omitted from the 63.

### A2 — Return `data-table` to ASK-8 HOLD before any investment

The frozen envelope leaves the DataTable-versus-plain-Table comparison as a
branch gate. C61 assigns `KEEP / THIN` while also placing that comparison in a
later execution step. Atlas `SourceDataBrowser` proves that the receiver must be
preserved; it does not prove that DataTable is the lowest-complexity surviving
owner.

Amend the row to:

> `HOLD — ASK-8: KEEP / THIN vs REMOVE / FOLD`; preserve the Atlas receiver,
> run the frozen Table comparison before E2, and perform no DataTable investment
> until that branch is decided.

The branch detector must compare total owner complexity and distinct semantic
work, not merely import presence. Neither deletion of the live receiver nor
premature thinning earns formation credit.

### A3 — Remove Easing’s post-freeze conditional escape

The matrix says `KEEP PICKER / FOLD CONFIGURATOR` but permits a newly discovered
non-demo job before execution freeze, while E4 unconditionally folds the
configurator. A terminal formation cannot admit new evidence silently after its
authority envelope has frozen.

Freeze the current disposition:

> Keep `EasingPicker`; fold `EasingConfigurator` into it because the frozen
> envelope contains no distinct non-demo owner job.

Any later contrary evidence must reopen formation. It cannot bypass this record.
The fold must also prove no copied animation clock or request-animation-frame
loop survives.

### A4 — Make Dialog’s scrim a derived channel, not a second lifecycle clock

contrary to C61’s own one-owner law.

Amend the wording to:

> current semantic open/close generation; it is not a separate lifecycle clock
> or owner.

The row is RED if a stale scrim completion can act after close/reopen or diverge
from the generation governing focus and inert state.

### A5 — Align Drawer’s cancel disposition with its detector

C61 chooses “cancel restores committed detent,” but its detector only forbids
using canceled release velocity. Those are not equivalent. The frozen owner law
requires transaction retirement and no release-velocity reuse; the terminal
resting policy must either be adjudicated explicitly or remain policy-neutral.

Amend in one of two consistent ways:

1. state that C61 adjudicates rollback to the committed detent and add an exact
   born-RED detector for failure to restore that detent; or
2. retain the frozen neutral rule: cancel/loss discards release velocity and the
   existing Drawer owner deterministically restores or seats the surface.

Do not leave the stronger matrix promise paired with the weaker falsifier.

Amend the row to Card-role radius by default. If a larger radius remains
