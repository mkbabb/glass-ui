## Source-to-story-to-consumer closure law

No component receives terminal credit until one immutable chain proves:

```text
exact commit/tree
  -> one clean build
  -> one uniquely versioned tarball + SHA
  -> clean isolated install + exact lock
  -> typecheck root and every intended subpath
  -> verify both public CSS entries and asset reach
  -> serve the installed package, never @glass/src
  -> run the canonical story state
  -> run the exact authorized consumer on the same tarball
  -> retain JS/CSS/chunk/AX/focus/event/raster identities
```

Contract tests remain nearest the defining mechanism; Browser tests exercise
the natural rendered interaction; package tests install the artifact; consumer
tests use only documented props, slots, tokens and compositions. One layer may
not impersonate another. A source-bound story cannot prove an export. A strict
type import cannot prove runtime behavior. A final screenshot cannot prove
focus, cancellation or announcement. A stale downstream version cannot prove
current source.
