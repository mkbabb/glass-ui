   register — the WS3 unified blur/tint/specular + the WS8 iOS-27 Tier-0 bevel + the SOTA refraction
   ladder — at the right tier for its role (chrome=glass, content=paper per the Liquid-Glass fence).
   Every paper surface reads the SAME WS9 warm-lit tooth + handmark voice. No component using a stray
   blur radius, a different tint axis, an off-identity shadow, a non-warm hue. iOS-27 fidelity.
2. **Animation implementation + language congruence.** Every motion across every component + page
   speaks the SAME language: the motion-canon (P1 spring-iff-spatial / bezier-iff-effect), the 12 laws
   (anticipation/follow-through/arcs/secondary/overlapping universal), ONE spring family (no rogue
   `SpringProgress`/easing), liquid-weight/inertia/bounce everywhere, enter-bouncy/exit-no-overshoot,
   the per-spring duration clock, PRM-carved. No per-component motion fork, no flat-transition where a
   spring belongs, no jank-tail, no missing entrance.
3. **Congruence (the whole reads as ONE system).** Type (aristotelian √φ ladder), color (the section/
   viz ramp + warm identity), proportion, spacing (the φ padding ladder), the eyebrow/caption register,
   the icon register, the suffusion one-color-event rule — applied congruently. A fresh capture of any
   page sits beside any other and reads as the same system; a component pulled from one page into
