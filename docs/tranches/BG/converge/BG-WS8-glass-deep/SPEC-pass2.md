## 1 · GESTALT GOAL

**ONE glass material, every surface, every engine — that reads as a thick refractive lens of flowing structured light wherever it floats over the field.** An architectural transposition, not N bespoke shaders:

- The shell field (WS1) is procedural + script-readable. Refraction is a **second, displaced sample of the SAME field, inside the SAME GL context, with in-shader structured-light synthesis** — no DOM rasterize, no `html2canvas`, no second context, no staleness (PT1-proven). The DOM glass surface becomes a **transparent window carrying its CSS chrome (rim + bevel + specular + border + content) AND its in-shader dimming term** (the Apple-mandated legibility darken); the GL composite paints the lensed, light-bent field beneath it.
- **"Suffuse component-wide" = the MATERIAL, not the displacement.** The cheap material register (frost + warm-cream tint + bright lower bevel + moving specular) rides the EXISTING `.glass-material` comma-group on every surface and every engine — that alone "reads as glass" AT REST (apple.com proves the floor). The EXPENSIVE displacement is reserved for page glass floating over the field, painted by ONE shared compositor pass keyed off a panel-rect THUNK registry — the one-GL-context-per-route budget AND the Safari context-storm floor honored by construction.
- **The METAL FLOW read is delivered by OPTICS, not `saturate`.** Light-bending = rim-concentrated squircle displacement (lifted from the goo-blob dome-Z, DRY) + Fresnel + a directional specular streak refracting a field that carries IN-SHADER flowing structured light (`curlFBM` + caustics). WS3 cures C-GRAY by reverting `saturate`; WS8 NEVER re-introduces it to chase metal.
- **Liquid-weight is finally POSSIBLE on the refraction itself.** The displacement/specular/caustic magnitude is a GL uniform driven by a SECOND reader of the EXISTING `--glass-btn-press-t` press spring `.value` (zero new springs), PRM-snaps to settled. The press-swell RETURNS in the GL tier.

Every leg is compositor/uniform-only, PRM keeps-fade/drops-displacement, and paints in Chrome AND Safari (the floor never depends on a Chromium-only filter).

### 2.2 · The refraction pass — a SECOND compositing pass in WS1's ONE context (the keystone, PT1-PROVEN; the seam CORRECTED per P1)

The shell `<Aurora>` (WS1) owns the route's single GL context and renders the field fullscreen. WS8 adds a second pass over the SAME context, wired **in the backend's `setup`/`buildContext` closure (which owns the `gl`/device), NOT the agnostic scheduler**:

1. **Render-to-texture leaf (NEW `createRenderTarget.ts`, colocated).** A small leaf that allocates a color-attachment texture + FBO (WebGL2) / a texture binding (WebGPU), re-allocs on resize/DPR, and exposes `bindFieldTarget()` / `bindDefault()` / `fieldTexture`. The SHELL-AURORA consumer's `setupGL`/`setupWGPU` becomes a two-pass setup: **pass A** binds the field target + renders the field; **pass B** binds the default framebuffer + runs the glass-refract program sampling `fieldTexture` + the panel-rect array. No new context, no canvas move (the WebKit canvas-move-loses-context constraint never bites). `createCanvasLifecycle` is UNTOUCHED (P1).
2. **The glass pass** is `glass-refract.glsl.ts` (WebGL2 floor) / `glassShader.wgsl` (WGSL refine): for each pixel inside a registered panel rect → sample the field texture at the **rim-concentrated squircle-displaced** + chromatically-split UV (the squircle slope `f(x)=⁴√(1-(1-x)⁴)`, Snell n=1.5 — **lifted from the goo-blob dome-Z, BD.W-GOOBLOB-SQUIRCLE-REFRACT arm1, both backends — DRY, never re-derived**; replaces the pilot's flat `from_center * strength * 0.02` smear at `glassShader.wgsl:106`), blend the rim Fresnel + directional specular + the in-shader curlFBM caustic + the in-shader dimming term; else → pass the field texel through. The blur kernel is CHEAP (≤9-tap / mip-LOD — the field is low-frequency; the pilot's 17×17=289-tap Gaussian at `:114-126` is the R3 cost driver and **drops to ≤9 taps** — displacement + aberration + Fresnel + caustic carry the read, NOT blur).
3. **`glass_bounds` becomes an ARRAY** (the pilot ships a single `vec4f` at `:10`): the THUNK registry uploads N panel rects (rect + radius + accent + depth + the per-panel press-`t`) per frame; the pass iterates them. ONE pass, all panels, one context.
4. **The DOM glass becomes a transparent window WITH a retained dimming term (P2).** The panel's CSS `background`-PLATE + `backdrop-filter` blur are dropped where it floats over the field (a new `[data-glass-refract]` state zeroes them); it KEEPS the Tier-0 chrome (rim + bevel + specular + border + content) AND the GL pass paints the warm-cream tint + bright-bucket adaptive darken IN-SHADER (the Apple dimming layer), so caption/body stay AA over the worst-case bright field region.

**Honest lacuna (recorded, not a gap):** the refraction covers the FIELD. Glass over intervening DOM (a menu over an article) stays on the Tier-0 CSS floor. The `filter:url()`-over-cloned-CSS-background path (BE.W-LENS-SAFARI) is the BOOKED successor for glass-over-re-paintable-DOM — noted, not built (KISS).
