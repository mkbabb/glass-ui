# BF.W-FISSION-FILAMENT — make the goo neck SPAN the gap (the headline split-convincingness fix)

## The defect / the ask

The BE fission engine carves ONE pill into N free-floating glass pieces, but **the neck does not span the gap** — so a split reads as two discs that drift apart with a same-size capsule on each, NOT as Apple-Music / Dynamic-Island liquid that necks-then-snaps. The audit verdict (R3 FIDELITY GAP, R9 "union and split demos are useless and don't work — split renders the goo neck but finicky; fidelity gap") + DEFERRED-CENSUS **D14** + **D16** name four coupled gaps. Each is a real source fact:

1. **The neck is a same-size capsule INSET ON the piece, not a body-anchored spanning filament (D14).** Read `src/styles/dock/fission-bridge.css:291-327` — `.dock-fission-piece::before` is `inset: 0` (line 295) ON the piece element, a `border-radius: 999px` capsule the SAME size as the piece. Its only "neck" is the `clip-path: inset(var(--neck-inset) 0 var(--neck-inset) 0 round 999px)` (line 319) which THINS the capsule's own block extent toward its own centerline as `--neck-t` rises. It never reaches BACK toward the dock body centroid — the piece flies off on its `translate` (line 274-276) and its capsule flies WITH it, so the gap between piece and body is empty. There is no spanning gel throat; the metaball bridge has nothing to fuse across.

2. **The goo blur is a static prop, not gap-sized (D14).** Read `src/components/custom/dock/DockGooFilter.vue:38-56` — `blur` is a `withDefaults` prop (default 7), a SINGLE `feGaussianBlur stdDeviation`. It never reads the live `--dock-split-t`, so the alpha-bleed radius is constant across the whole split. At the mid-pinch (where the throat is thinnest and the two alphas are FARTHEST apart) the blur must be LARGER for the alphas to bleed across the throat and the `feColorMatrix` threshold to read one continuous metaball — a constant 7px cannot fuse a wide mid-split gap, so the throat reads as two disjoint discs exactly where the convincing pinch should be.

3. **The pinch has no legible duration; the per-signature `neckHold` is DEAD (D14 "neck too brief").** Read `src/components/custom/dock/composables/useDockFission.ts:299-351` (`writePieces`) — it phase-shifts each piece's `--neck-t` by `staggerStep * rank` (lines 323-328) so the necks break in sequence, but the per-signature **`neckHold`** field (`DOCK_SPLIT_SIGNATURES` lines 99/116/126: search 0.55 / media 0.4 / nav 0.35) is NEVER read anywhere in the file — it is dead substrate. The neck runs `(tValue - shift) / span` to 1 with no HOLD at the tense filament, so the pinch flashes past in one or two frames instead of dwelling at the thin throat (the reference's "stretch → tense filament → snap").

4. **The demo content/piece desync (D14 / R9 finicky).** Read `demo/stories/dock/examples/DynamicIslandCall.vue:171` — the `.ci-half` content translates by `--half-dir * --piece-reach * clamp(0, var(--dock-split-t, 0), 1)` — the RAW `--dock-split-t`. But the blob piece (`.dock-fission-piece` in `fission-bridge.css:264-276`) translates by `--piece-progress` = `clamp(0, calc(var(--dock-split-t) - var(--seam-tension)), 1)` × the staggered reach. So when the pointer pulls (seam-tension > 0) OR a piece's stagger delays its `--neck-t`, the crisp content layer and the goo blob it labels DRIFT APART — the avatar/text float off their blob (the "finicky" read). The spike's own content (`liquid-morph.css:603-608`) correctly mirrors `--piece-progress`; the shipped demo does not.

5. **n>2 UNPROVEN; `search`=radial / `nav`=inward-merge signatures DEAD (D16).** Every consumer registers exactly N=2 pieces (`DynamicIslandCall.vue:36-37` registers two). The `search` radial-burst and `nav` inward-merge `DOCK_SPLIT_SIGNATURES` are wired into the orchestrator (the `staggerRank` resolvers compute innermost-first / outside-in) but no surface exercises them at n>2 — so the descriptor-driven F3 "ONE recipe, any vector" claim is unproven, and the two dead signatures may be over-fit substrate.
