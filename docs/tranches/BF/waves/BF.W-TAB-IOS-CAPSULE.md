## The defect / the ask

The audit names the Band-3 tabs gap (§4 Band 6): "`W-TAB-IOS-CAPSULE` — the `DockTabBar` + SegmentedTabs iOS recessed-accent capsule fold." The iOS-27 segmented control is a RECESSED TRACK (a sunken well, an inset shadow groove) with a RAISED ACCENT CAPSULE riding inside it — the selected segment sits in a lit, forward-lifted lozenge over a recessed channel. Two registers in the library express the "selected tab" idea, and they are NOT yet ONE recipe:

1. **`SegmentedTabs` (`src/components/custom/tabs/SegmentedTabs.vue` + `src/styles/segmented-tabs.css`)** — the BC.W-TABS-IOS work raised the `.segmented-indicator` to a "distinct lifted plate" (`--glass-bg-floating-tinted` + the directional rim `--glass-rim-top`/`--glass-rim-bottom` + `--glass-shadow-floating`, `segmented-tabs.css:91-122`). But the TRACK is a FLAT quiet capsule (`background: var(--glass-bg-quiet)` + only the rim, `segmented-tabs.css:60-69`) — NOT a RECESSED well. The iOS gestalt is half-there: the pill lifts, but the channel it rides in does not sink. There is no recessed groove, so the lifted plate reads as floating on a flat strip, not seated in a sunken track.

2. **The dock-tab register (`DockTabButton.vue` + `src/styles/dock-controls/tab-button.css` + the `--dock-control-active-bg` "selected reads as glass" tier, W-REGISTER-IOS)** — the dock's selected control lifts onto `var(--glass-bg-floating)` (the same "selected reads as glass" tier the segmented pill uses) but expresses it through a SEPARATE per-control recipe (the `[data-tier]` arms + the dock-rail `--dock-layer-rail-active`). The `DockTabButton` is a per-control glass-hover button; there is no shared "selected capsule" recipe between it and `SegmentedTabs` — two dialects of the same iOS selected-accent idea.

The ask is the FOLD: ONE recessed-accent capsule recipe both the `SegmentedTabs` pill indicator AND the dock-tab selected register read, so the iOS-27 recessed-well-plus-raised-accent gestalt is minted ONCE and consumed by both — the substitution-over-redeclaration discipline (the `--invalid-ring` / `--focus-ring-shadow` precedent: one register, read everywhere). Part of D23 (the breadth — `DockTabBar` + tabs).

## The mechanism

Mint the iOS-27 recessed-accent capsule as ONE shared CSS register — the recessed TRACK groove + the raised ACCENT capsule, declared once, read by both `SegmentedTabs` and the dock-tab register. No new component, no second indicator engine; the existing `useTabIndicator` (the JS/anchor slider position) is UNTOUCHED — this is the SURFACE recipe under the indicator, not the position engine.

1. **The recessed-track register — `--tab-track-recess` (the sunken well, `src/styles/segmented-tabs.css` track rule).** The `.segmented-tabs` track gains the iOS recessed groove: an INSET shadow well over the quiet-glass plate — `box-shadow: var(--glass-rim-top), var(--glass-rim-bottom), inset 0 1px 2px var(--tab-track-recess-ink)` where `--tab-track-recess-ink` is a bounded `color-mix(in srgb, var(--foreground) N%, transparent)` (the recessed-channel ink, the Progress `IG-C1` frosted-meter-groove precedent — a recessed track reads SUNKEN, not flat). The recess is the plain per-mode pair idiom (light in `tokens/glass.css` beside `--glass-tint-*`, dark in `tokens/dark-arm.css` — the light-dark() inset-shadow-trap escape, since this IS an inset shadow). The track STAYS the warm-glass quiet capsule (the BA.W-TABS no-gray register — never a `--surface-tint` gray well); the recess is the inset depth ON it, not a re-color. **NOTE the inset-shadow trap (MEMORY):** the recess inset MUST be a plain per-mode arm, NEVER a `light-dark()` fragment (an inset-shadow fragment inside `light-dark()` computes the WHOLE box-shadow to `none`).

2. **The accent-capsule register — `.glass-tab-capsule` (the raised lifted lozenge, the FOLD).** The existing `.segmented-indicator` lifted-plate composite (`--glass-bg-floating-tinted` + the directional rim + `--glass-shadow-floating`, `segmented-tabs.css:91-122`) is factored into a SHARED `.glass-tab-capsule` recipe (`src/styles/glass/tab-capsule.css`, `@layer components`) — the iOS raised selected-accent lozenge. `.segmented-indicator` COMPOSES it (the pill IS the capsule riding the recessed track), and the dock-tab SELECTED register (`DockTabButton[data-tier]` selected arm + the dock-rail `--dock-layer-rail-active`) re-points its selected fill onto the SAME `.glass-tab-capsule` recipe — so a dock tab's selected accent and a SegmentedTabs pill are the SAME lifted lozenge over the SAME recessed register (the W-REGISTER-IOS "selected reads as glass" tier UNIFIED into the capsule, never a third fork). The capsule reads the SAME element-level `--glass-bg-floating-tinted` adaptive seam (W55 bright-bucket darken / calm-field warm-cream — the existing `surfaces.css :where(.btn-glass, .segmented-indicator)` mint widens to include `.glass-tab-capsule`). ONE recipe, two consumers, asserted as real `src/` call-sites.

3. **The capsule is compositor-only + rides the calibrated clock.** The capsule's travel (the indicator glide + the `--stretch` squish) is UNCHANGED — it rides `useTabIndicator`'s `--stretch` + the anchor/JS `inset`/`transform` on the `--tab-indicator-duration` clock (= `--spring-snappy-duration`, the W-GLASS-CAL register). The recess is a STATIC inset shadow on the track (never animated — a recessed well does not pulse; `proof:no-layout-animation` holds, the inset shadow is not a reflow property and is not a `@keyframes` target). The capsule's lift (rim + under-shadow) is static too; only its POSITION animates (the existing transform/inset path).

4. **The dock-tab fold — `DockTabButton` selected reads the capsule (the second consumer, the dock-tab register).** Read `DockTabButton.vue` (the `dock-tab-button` class, the `v-specular` tier-root gleam) + `src/styles/dock-controls/tab-button.css`. The `[data-tier]` selected arm + the dock-rail active indicator re-point their selected fill off the per-control `--dock-control-active-bg` redeclaration onto `.glass-tab-capsule` (the shared recipe) — a dock tab's selected state IS the iOS capsule. The dock-tab REST/hover register (the `v-specular` gleam, the de-red'd glass hover) is UNTOUCHED; only the SELECTED accent folds onto the capsule. This is the `DockTabBar` register the SEED names — the dock tab strip's selected accent is now the same iOS recessed-capsule as the content `SegmentedTabs`.
