# Tranche AR — Make the binding silent-no-op impossible (the platform-binding uniqueness gate + the modern-web leverage AQ left)

AR is glass-ui's post-AQ tranche. AQ swapped the hand-rolled JS substrate for the browser platform — `color-scheme`/`light-dark()`/`color-mix`, `:has()`, scroll-driven CSS, `@starting-style`, `useViewTransition`, anchor-positioned underlines, the dock VT swap — and folded into the published 3.0.0 + 3.1.0. The fan-out cleared the ≥2-consumer bar for every public AQ primitive and the overfitting audit came back clean. But AQ minted a whole class of platform-binding surface — `view-transition-name`, `anchor-name` — with no collision guard, and the A1 audit diagnosed a **live bug** in that class: `GlassDock` mints its `view-transition-name` from a module-level `let` counter that restarts per module-graph copy, so a lazy-chunked dock collides with the eager dock's name and the browser rejects the transition. vue-tsc passes; vitest passes; only fourier's console-error e2e catches it. This is the **binding-verification class** — the recurring glass-ui failure signature.

AR is the dual of AQ's headline. AQ's `color-mix` substrate made the `hsl(var())` paint-failure *structurally impossible*; AR's `proof:vt-names` gate makes the VT/anchor-name collision *structurally impossible*. AR also takes the modern-web *leverage* AQ left on the table — container style queries for density, scroll-state container queries for the carousel, cross-document View Transitions + types for route morphs, `scheduler.postTask` priority — and evaluates the deferred AS-GU design bundle at the ≥2-consumer-or-demo bar.

AR is in DEVELOPMENT now. W0-W1 formulate the tranche (re-run the modern-web baseline against HEAD + the design slices); W2-W6 are authored-now-run-later — the implementation phase opens only on explicit user authorization. The dev/impl boundary sits between W1 and W2.

## § Thesis

The A1 audit found two load-bearing facts. First, the **live GlassDock VT-name collision** (confirmed at HEAD, `GlassDock.vue:9` `let dockInstanceId = 0` + `:112` `++dockInstanceId` + `:183` the mint + `:173` a comment falsely asserting page-uniqueness): a module-level counter restarts at `1` per module-graph copy, so an eager dock and a lazy-chunked dock both mint `glass-dock-1`, two live elements share one `view-transition-name`, the browser rejects the transition and logs an error. The fix is already idiomatic and present one file over — `DockLayerGroup.vue:69` uses Vue's app-scoped `useId()`; the same pattern is the established idiom in 5 custom components (disco-glyph, hover-popover, labeled-field, configurator, DockLayerGroup). The deeper fact: AQ minted `view-transition-name`/`anchor-name` binding surface with **no uniqueness gate**, so the entire class — vue-tsc-green, vitest-green, runtime-broken — is unguarded. This is the AR headline.

Second, AQ took the *correctness* + *LOC-cut* modern-web levers but left the *elegance/architecture* levers on the table — each a documented guide with a real glass-ui site: container STYLE queries (`@container style(--density:…)` — the W7 no-show; density is 100% `[data-density]` attribute selectors), scroll-state container queries (`@container scroll-state(snapped)` + `scrollsnapchange` — the carousel runs on embla's JS observers), cross-document View Transitions + types (`useViewTransition` is same-document-only; route morphs want `@view-transition { navigation: auto }`), and `scheduler.postTask` priority (`useYieldToMain` wraps only the binary `scheduler.yield()`).

**AR makes the binding silent-no-op structurally impossible AND takes the leverage AQ left** — the gate is the headline; the leverage is the additive value; the AS-GU design bundle is gated at the ≥2-consumer bar.

## § Binding question

Can glass-ui (a) close the binding-verification class for platform-binding surface — a **`view-transition-name`/`anchor-name` uniqueness gate** (`proof:vt-names`, a static `src/` scan asserting every mint derives from `useId()` or a documented app-unique source, never a module-level counter) plus a unit pairwise-distinct assertion — fixing the diagnosed `GlassDock` collision via `useId()` (mirroring `DockLayerGroup`), correcting the stale comment, repairing the CI #177 node-pin/registry divergence so the republish CI greens, and shipping a fallback-preserving **3.1.1 patch** that re-bumps consumers and greens fourier CI; (b) take the modern-web *leverage* AQ left — **container style queries** for density (`:where()` flat-specificity over the kept `[data-density]` fallback), **scroll-state container queries** for the carousel highlight/pager (embla kept as the drag-physics fallback), **cross-document View Transitions + types/directional vocab** for route morphs (extending `useViewTransition`/`view-transition.css`), and **`scheduler.postTask` priority** (extending `useYieldToMain`) — each token-first, each Newly/Limited progressive over the kept path; and (c) evaluate the **AS-GU design bundle** (`deriveAurora`/OKLab aurora, `--spring-crisp`, whisper-heading, dock dark `--glass-opacity-dock` rung + `always-expanded` overflow fix, CompletionSeal, the standalone-`DockIconButton` coarse floor, `GlassNativeSelect`) at the **≥2-consumer-or-demo-or-not-shipped** bar — all gates green, no public-surface leak, the additive work folded as a **3.2.0 minor** atop the 3.1.1 patch?

## § Inherited invariants

All standing glass-ui invariants bind unchanged. Load-bearing for AR:

- **Token-first** (J inv) — every new visual axis (`--density` as a queryable property, `--spring-crisp`, `--glass-opacity-dock`, the whisper-heading rung) stays a CSS custom property; platform features resolve THROUGH tokens (`@container style(--density:…)` queries a *token*, not a markup convention).
- **No backwards-compat alias** (inv 47 / L inv 4) — a platform swap RETIRES the hand-rolled path OR keeps it as the SOLE feature-detected fallback, never both live. The container-query density layers over the kept `[data-density]` (the fallback, not a dead mirror); the scroll-state carousel keeps embla as the *drag-physics* fallback (a real role, not a shim).
- **Substrate-without-consumer is binary** (J inv 10 / L inv 8) — the AS-GU bundle is GATED, not assumed: each cluster clears ≥2 consumers OR a demo OR is not shipped. `GlassNativeSelect` stays demo-gated (no ≥2 real consumers); CompletionSeal ships only its token/keyframe layer (the component demo-gated). The standalone-`DockIconButton` floor clears the bar via speedtest + a converging 2nd.
- **The fallback is mandatory for Newly/Limited features** — the Baseline policy binds: Widely → native; Newly → ≤20-LOC feature-detected fallback, current path default; Limited → progressive-only with the current path the default. Container style queries (Newly→Limited), scroll-state queries (Newly), cross-document VT (Newly/Chromium), customizable-`<select>` (Limited) each ship the documented fallback.
- **The overfitting audit runs at close** — `docs/audits/overfitting-audit.md` against every AR artefact (the gate scripts, the composables, the tokens, the demo-gated pilots).
- **vueuse-/keyframes-FREE root barrel** (L/AP) — `usePrioritizedTask`/`postTaskSafe` lands on `/motion-core` (the dependency-free leaf, mirroring `useYieldToMain`); `deriveAurora` stays on `/aurora` (the heavy isolated chunk). No barrel-shape change.
- **The proof gate measures the live tree** (AO inv α / AP.W4) — `proof:vt-names` scans the live `src/` working tree (excluding `.claude`/worktrees per the AP.W4 `ignoredDirs` precedent), fail-closed, the way `proof:resolution`/`proof:theme` do for their classes.
- **bbnf tranche format** — `docs/tranches/AR/` + hard gates + FINAL.md; the V-tranche post-hoc precedent does not apply (AR is plan-first).

AR introduces:

- **AR inv η — every platform-binding mint derives from an app-unique source, statically proven.** A `view-transition-name`/`anchor-name` (or any future per-instance platform-binding token) is minted from `useId()` (per-instance, collision-free across module-graph copies) OR is a documented page-singleton literal — NEVER a module-level `let` counter (which restarts per chunk copy and silently no-ops the binding). `proof:vt-names` makes the violation structurally impossible: it is the substrate-level closure of the binding-verification class for platform-binding surface, the dual of AQ's `color-mix` closure of the `hsl(var())` paint-failure class.
