New primitive: `src/components/custom/dock/DockMobileToggle.vue`.

Specifications:
- Animated arrow button (chevron OR caret); rotates 180° on expand; arrow swaps direction on flip.
- Spring behavior: `--spring-bouncy` (ζ=0.45) + `--scale-press-btn` for squish/expand.
- Glass aesthetic: wrap in `.glass-wash` mini-button; match dock pill radius; compose with `<GlassDock orientation>` for top/bottom/side variants.
- Animation cadence: `--duration-normal` (300ms) + `--spring-bouncy` linear() approximation OR explicit `@keyframes` if needed.
- A11y: aria-expanded + aria-controls for the dock; focus-visible via `.focus-ring`.

Export from `src/components/custom/dock/index.ts` → reachable via `@mkbabb/glass-ui/dock`.

Optional: `--scale-squish: 0.92` token (Rε N8 G3 sub-gap) if existing `--scale-press*` insufficient for blob aesthetic.
