## §H4 — THE HINGE FORK (the bridge specced fully; the others recorded)

### Arm (a) — the metaball-bridge crossfade (RECOMMENDED; the fleet's Arch B — specced fully below)

Render BOTH a vertical AND a horizontal real DOM dock. During the morph, drive the existing one-axis `--dock-morph-t` spring on EACH — the vertical collapses its HEIGHT 0 while the horizontal grows its WIDTH 0→full, both off the ONE shared scalar (determinism). Paint a goo-blob / SVG-goo metaball bridge BEHIND them that `smin`-merges the two shrinking/growing plates into one amorphous TEARDROP that flows from vertical to horizontal. The DOM docks CROSSFADE (opacity off the same scalar) UNDER the goo veneer, so the topology jump-cut (column→row reflow) happens at the visually-HIDDEN midpoint where the goo blob fully occludes it. The faithful liquid-glass metaball-teardrop the user named — it sidesteps the topology-morph limit by HIDING the reflow inside the goo merge.

- **Determinism + bidirectionality (the DOM-dock axis):** ONE `--dock-morph-t` scalar (the existing `SpringProgress`, `DOCK_SPRING` response 0.32 / ζ 0.7) drives both DOM docks' size; the interruptible re-base (the velocity-continuity rebase, re-grep the rebase site at HEAD — `dockMorphContext.ts` §27/§294, NOT a hardcoded line) means a mid-flight toggle stays continuous. The `t=0` end is the vertical dock; `t=1` is the horizontal dock; the teardrop is the `t≈0.5` occluding midpoint. The DOM-dock size axis is deterministic because it is a pure function of the ONE scalar.
- **What makes the metaball BRIDGE deterministic — PINNED (the bridge has its OWN wall-clock animation that the scalar does NOT reach).** The goo-blob shader runs THREE independent `uTime`-driven channels — FBM body displacement (`metaball.frag.ts:130`, `uTime * uNoiseSpeed`), the color-noise field (`:278`, `uTime * uColorNoiseSpeed`), and the iridescence sweep (`:302`, `uTime * uIridSpeed`) — PLUS a pointer-VELOCITY-driven anisotropic squish (`:122`, `sa = 1 + tanh(speed*1.6)*uStretch`, which reads live pointer speed, NOT the morph scalar). None of these is bound to `--dock-morph-t`. So a goo-blob mounted as the bridge AS-SHIPPED is NON-deterministic + wall-clock-driven, and the captured frame-series (HG1, t=0/.25/.5/.75/1) would NOT be frame-reproducible. The bridge is made deterministic ONLY by binding its aspect/orientation AND its `uTime` to the morph scalar: the bridge composes a `uTime ← --dock-morph-t · uTimeSpan` reparametrization (the FBM/color/irid clocks advance with the scalar, not the wall clock) and drives the anisotropic squish from the scalar's derivative (`d(--dock-morph-t)/dt`), NOT the live pointer `speed`. The teardrop aspect (tall capsule → wide capsule through the amorphous midpoint) is `f(--dock-morph-t)` — the SDF is continuous, no topology jump. The bridge is DECORATIVE only (the contained-creature constraint — it does not host the dock children). The gate (M5) asserts this scalar-binding; an implementation that mounts the goo-blob on its free-running `uTime` REDs the determinism clause.
- **Perf (the NUMBER that gates arm-a-vs-arm-c, not a vibe):** one spring + one WebGL2 metaball pass (already offscreen-pause + PRM-aware via `useWebGLCanvas`), OR a cheaper CSS SVG-goo filter on Chromium. The **budget is the SHIPPED blob frame budget the sibling W-BLOB-STUDIO G-PERF arm binds — the M5-Max 4× CPU-throttle protocol, p50 ≤ ~12ms / 0% of morph frames over the 16.7ms 60fps cap** (the same `AY.W-BLOB-GLASS §2` protocol — the bridge is the SAME WebGL2 substrate, so it inherits the SAME budget). The morph runs ≤ ~600ms wall (the `DOCK_SPRING` settle), so the binding measure is the **p50 + the over-16.7ms frame fraction across the full morph window, captured under 4× throttle, both directions.** Bidirectional + deterministic because it is one 0→1 scalar both ways. If the throttled p50 clears ≤ ~12ms with 0% over-16.7ms frames, arm (a) ships; a regression past the cap falls to arm (c) per §7 (the number, not a judgement call).
- **The W-LIQUID fold:** the shared amorphous flex+squish primitive `useLiquidFlex({ from, to, axis })` is BORN here (the substrate the bridge consumes) — the squish math already lives in `useTabIndicator` (`scale: var(--stretch)` reciprocal) and the metaball shader; `useLiquidFlex` reconciles them into the named primitive the dock/blob/tabs-indicator share. A `useDockOrientationMorph` layered on `--dock-morph-t` drives the two-dock crossfade + the teardrop aspect.
- **The net-new piece:** the goo bridge needs EITHER the existing goo-blob mounted behind the docks (its SDF aspect bound to the scalar) OR a net-new CSS SVG-goo filter (`feGaussianBlur` + `feColorMatrix` threshold — the classic gooey-CSS trick, absent today). The fleet notes both paths; the implementation picks per perf/browser.
