## Findings

Per the CTX rule: speedtest must NOT bump to ^3.3.0; its consume path is 3.4.0. This is the gating edge for EVERY other AW adoption in this repo.

2. **Aurora is the headline adoption opportunity — speedtest is a power-user already starved for the AW.W4-8 painterly knobs.** `src/config/auroraConfig.ts:97-174` configures `AuroraConfig` with the full painterly axis set ALL pinned to inert: `flow: { pattern: "none", … }` (:136), `strokeAmount: 0` (:137), `impasto: 0` (:144), `granulation: 0` (:143), `wetEdge: 0` (:142), `brokenColor: 0` (:145), `canvasGrain: 0` (:146), `paperGrain: 0` (:173). The file has hand-tuned through ~8 tranches of chroma/warp/softmax thrash (AN-D10, AS-6 DDRs at :18-80) to fight "diagonal rainbow streaks" and "muddy pastels" via `softmaxBeta` + `warpAmount` + manual `paletteBias` gamut compression — exactly the problem the AW.W5 "derive-color front door (hand it ONE brand color → gamut-mapped palette)" and full in-shader OKLCh solve. The author EXPLICITLY names the AW supersede in-comment: "The GU root (`deriveAurora` + OKLab LUT) supersedes this stopgap at the next consume (DDR-AS-RC-2 / §8-H10)" (auroraConfig.ts:71-73) and "supersedes this stopgap at the next consume" (:51-52). This is a documented, repo-author-requested adoption — not speculative.

3. **Aurora's SHIPPED 3.3.0 offscreen-pause substrate already obsoletes speedtest's hand-rolled `useAuroraPolicy`.** `src/composables/useAuroraPolicy.ts` (whole file, 71 lines) hand-composes `useIntersectionPause` (`/motion-core`) + a manual `matchMedia("(prefers-reduced-motion: reduce)")` listener (:62) + a one-static-frame-then-pause path (`aurora.renderAt(3.7); auroraRuntime.pause()` at :53-54). Net: `useAuroraPolicy.ts` can shrink to ~0 (or to a thin `DockBackgroundToggle` wiring — see finding 4) once on 3.4.0.
