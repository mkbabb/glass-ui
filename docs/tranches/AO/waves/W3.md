## Scope

1. **D4 — re-base the ceiling against the real combined draw.** WHAT — set the CSS budget cap in `scripts/profile-bundle.mjs` to the measured combined `dist/styles/index.css` draw (~10.2 KiB gzip post-consolidation) plus the canonical ~10% headroom; retire the SFC-only 8650 ceiling and the N.W0→P.W0→P.W3→Q.W4 bump-at-every-close cadence the script's comment block documents. WHY — the budget must track what ships; the bump-chain was the gate chasing the SFC fragment while the real cascade bytes drifted untracked; a principled single re-base against reality makes future cascade regressions trip the gate.
2. **D5 — per-subpath cap enforcement.** WHAT — promote the reported `subpathEntries` table (written to `W4-subpath-sizes.md`) to enforced caps on the enforce path, starting with the heavy entries (`aurora` ~16.5 KiB-gzip, `dock`, `configurator`, `command`); prefer a drift-% threshold against the committed `W4-bundle-profile.json` baseline over absolute per-entry ceilings (so the gate flags relative regressions, not arbitrary caps). WHY — the 76-entry split exists precisely so a consumer pays only for what they import; a budget on the root barrel does not protect any individual subpath; per-subpath enforcement makes a regression NAME the offending chunk instead of regressing silently.
3. **D6 — cascade consolidation / `@theme`+`@utility` dedup.** WHAT — read all 18 `src/styles/*.css` files in full; dedup duplicated declarations, collapse overlapping/adjacent `@theme` + `@utility` recipes, retire any rung with zero consumers — each retire gated by the overfitting audit (`docs/audits/overfitting-audit.md`) confirming zero consumers before touching. The gain is in the cascade itself (the SFC/cascade token overlap is already minimal — 12 vars in the SFC bundle vs 405 in tokens.css). WHY — a design system whose identity is visual cannot run near its CSS ceiling indefinitely; consolidation is the gestalt-redesign answer (dedup against a true ceiling) over the patch-when-the-gate-trips reflex, reclaiming genuine headroom for the next N tranches.
