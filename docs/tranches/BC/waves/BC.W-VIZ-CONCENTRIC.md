## Target spec (grounded)
The fix is a RENDER change + a GENERATOR change — NOT a math rewrite (research/viz/concentric.md §0, §8). Extract the field's isolines as thin AA strokes (IQ gradient-normalized distance), and drop the Phillips ladder for a small set of CLEAN low-frequency beating ring families. KISS — the substrate, the lifecycle, the math vocabulary all stay.

### 1 — The line is the point: IQ gradient-normalized distance-to-isoline (the render fix)
The canonical primitive for turning an implicit field into thin constant-width AA lines is Inigo Quilez's *Distance Estimation* (iquilezles.org/articles/distance/): `de ≈ |f(x)| / |∇f(x)|` normalizes out the field's local slope so the stroke is the same pixel-width everywhere (research/viz/concentric.md §1.1). Because the ring field is a sum of sinusoids, its gradient is available **analytically in closed form** (a sum of cosines — no `fwidth`, no central-difference, no second eval), so the JS round-trip stays exact (research/viz/concentric.md §1.2 path (b) — PICK THIS):
```
phase(p)  = k · ‖p − c‖_e − ω·t + φ
∇phase(p) = k · ∇‖p − c‖_e = k · ( dx/a², dy/b² ) / ‖p − c‖_e
s = sin(phase);  de = |s| / max(|cos(phase)| · |∇phase|, ε);  line = 1 - smoothstep(lineW, lineW + aa, de)
```
Near a crest `cos ≈ ±1`, so `de ≈ |sin(phase)| / |∇phase|` — a constant-pixel-width ring at every crest, for free. The `fwidth` builtin (fully supported in WebGPU on every engine incl. Safari/Metal — only `fwidthFine` is excluded in Compatibility Mode; webgpufundamentals compat-mode) is the safety clamp on the final composite ONLY (research/viz/concentric.md §1.2).

### 2 — Distinct waves: clean low-frequency beating ring families (the generator fix)
DROP the 5-octave Phillips ladder (`buildRingLadder`, `ringField.ts:116`) — it is the noise. Replace with (research/viz/concentric.md §1.3):
- **2–4 ring FAMILIES** (one per center `cⱼ`), each a SINGLE clean radial frequency (1–2 harmonics max), with slightly different wavelengths so they BEAT — `λ₁ ≈ 0.18`, `λ₂ ≈ 0.21` → a low-frequency moiré envelope (`Δk` small) whose envelope wavelength `2π/Δk` reads as broad sweeping waves. This is literal wave interference — the cymatics/Chladni standing-wave aesthetic (modern-physics.org/cymatics; Chladni modal analysis) and the topographic-contour-line aesthetic (Dietcode "Topographic Line Art with WebGL").
- **The ring TRAVEL keeps the deep-water dispersion** `ω = √(g·k)` (Tessendorf — `ringField.ts:99` `Math.sqrt(RING_GRAVITY*k)*speed`; the suite's ONE dispersion law, shared with dot-flow). The math VOCABULARY stays; only the GENERATOR + the RENDER change.
- **Optional topographic-contour mode** (the elevation-map look): draw the isolines of the STATIC interference envelope at evenly-spaced levels — `de = |fract(f·N + 0.5) − 0.5| / |∇f·N|` (the contour-line operator, research/viz/concentric.md §1.3).

### 3 — Ellipsoid lines: per-family rotation (the "ellipsoid" + crossing fronts)
`ellipsoidalRadius` (`ringField.ts:68`, axis ratio `[1, 0.62]`) is KEPT. Add an optional per-family rotation `α` (research/viz/concentric.md §1.4): the `‖·‖_e` is computed in the family's rotated frame (`R(−α)·(p−c)` then the scaled norm), so two elliptical families at different tilts cross into rich moiré — the literal "ellipsoid lines that form distinct waves." Reuse the spare `centers[j].w` lane (currently `_pad`) → `rotAlpha` (ZERO byte-layout change; research/viz/concentric.md §2.4).

### 4 — The fragment kernel (per pixel; research/viz/concentric.md §2.2)
The kernel evaluates the field, derives the analytic gradient, extracts ring-crest isolines as strokes (brightest-wins `max` union so crossing families read as a bright moiré lattice), and tints the beat envelope through the warm-cream OKLCh ramp — the LINE carries the ink, the field is a faint wash or transparent behind it:
```
ink = max over families/rings of (1 - smoothstep(lineW, lineW+aa, de)) * weight * amp   // the lines
tint = Σ s * weight * amp                                                                  // the beat envelope → hue
rgb = linearToSrgb(samplePaletteLin(clamp(0.5 + tint*norm, 0, 1)));   alpha = clamp(ink, 0, 1)
return vec4(rgb * alpha, alpha)   // premultiplied; page reads through the troughs
```
`ringCount` drops 5 → 1–2 per family; `centerCount` 2–4. The analytic gradient is closed-form, so the round-trip gate stays exact.
