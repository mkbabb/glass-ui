### T1 — the 4 `@property` motion tokens (the seal's animated drives)
Four registered typed custom properties in `property-regs.css §18` (the house pattern — registered so they INTERPOLATE; safe `initial-value`s for the fallback):
1. **`--seal-draw <percentage>`** (`inherits: false`, `initial-value: 100%`) — the stroke-reveal extent (the `stroke-dashoffset`/`clip-path` wipe drive: 0% = undrawn, 100% = fully drawn; the `initial-value: 100%` is the safe resting fully-drawn seal on a non-supporting engine — a non-animating fallback shows the full seal, never a blank).
2. **`--seal-scale <number>`** (`inherits: false`, `initial-value: 1`) — the seal's settle scale (the draw-on settles with a small spring overshoot via the `--spring-snappy`/`--spring-bouncy` curve on the seal's own clock — the SPATIAL leg).
3. **`--seal-glint <number>`** (`inherits: false`, `initial-value: 0`) — the gold glint intensity (the catch-light sweep that fires once on settle — reads `--metal-glow-opacity` from `BC.W-AX-METAL-GLOW`; the glint is a one-pass on settle, not a loop).
4. **`--seal-ink <color>`** (`inherits: true`, `initial-value: oklch(0.751 0.147 84.2)`) — the seal stroke color. The `@property initial-value` MUST be a CONCRETE var-free `<color>` (the registration fallback cannot be a `var()` — the typed-property rule), so it is the LITERAL light-gold (`--gold`'s `scale-paper.css:139` value `oklch(0.751 0.147 84.2)`) — the engine fallback when no cascaded value exists. The runtime cascade default is the token form: the seal recipe sets `--seal-ink: var(--phase-complete-color, var(--color-gold))` (the earned-gold register; `inherits: true` so a consumer scope re-inks the seal).
