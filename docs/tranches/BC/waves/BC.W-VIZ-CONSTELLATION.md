### 1 — Crisp circles: WebGPU instanced billboard quads + a fragment SDF (THE headline fix; numbers pinned)
WebGPU's `point-list` primitive is hardwired to 1×1px (the Metal/Vulkan/DX/GL backends disagree on point size) — useless for sized dots (research/viz/constellation.md §3.2, webgpufundamentals). The SOTA shape is **instanced billboard quads**: draw `6 vertices × N` instances, one quad per node, corners selected by `vertex_index`, the per-node center/radius/dim read from a storage buffer by `instance_index`:

```wgsl
const QUAD = array<vec2f, 6>(
  vec2f(-1,-1), vec2f(1,-1), vec2f(-1,1),
  vec2f(-1, 1), vec2f(1,-1), vec2f( 1,1),
);
let corner = QUAD[vIdx];
let node   = nodes[iIdx];                                    // {pos, radius, dim} storage
let center = node.pos / uResolution * 2.0 - 1.0;             // clip space (y-flip as needed)
let half   = (node.radius * uKVis * uDpr) / uResolution;     // DPR-aware → crisp
out.pos    = vec4f(center + corner * half, 0.0, 1.0);
out.uv     = corner;                                          // [-1,1] → fragment SDF coord
out.dim    = node.dim;
```

The crispness comes from sizing `half` in REAL backing-store units (`· uDpr`) AND the fragment SDF edge — the node samples at full device resolution and is AA'd by the pixel-footprint derivative, never the CSS-upscaled soft blob Canvas2D paints. The fragment is the **`fwidth`-smoothstep** resolution-independent canon (research/viz/constellation.md §5.3; Red Blob Games SDF antialiasing; numb3r23 fwidth-based AA — the SAME AA discipline goo-blob's two `fwidth` sites + the concentric ring-line extraction use, ONE AA canon across the suite):

```wgsl
@fragment fn fs(in: VSOut) -> @location(0) vec4f {
  let d  = length(in.uv) - 1.0;                 // SDF: 0 at the circle edge, neg inside
  let aa = fwidth(d);                            // abs(dpdx(d)) + abs(dpdy(d)) — px footprint
  let coverage = 1.0 - smoothstep(-aa, aa, d);  // ~1px AA band at ANY DPR/zoom/size
  if (coverage <= 0.0) { discard; }
  let col = mix(uNode, uNodeDim, in.dim);
  return vec4f(col.rgb, col.a * coverage * uOpacityCeiling);  // premultiplied
}
```

An OPTIONAL soft inner-glow "star" register is a second `smoothstep` band on `d` (a faint core-to-rim falloff), warm-cream, OFF by default.

### 2 — The edges: WebGPU instanced segment quads (the second render pass)
WebGPU's `line-list` is, like points, 1px-only and join-less. The SOTA is **instanced line-segment quads**: for `edgeCount` edges, draw `6 verts × edgeCount` instances; the vertex shader loads the segment's two endpoints, projects to screen space, and offsets the quad corners by the ORTHOGONAL of the screen-space line direction × half the pixel width (research/viz/constellation.md §3.3; rreusser/webgpu-instanced-lines; m-schuetz thicklines; shone.dev):

```wgsl
let a = edges[iIdx].a; let b = edges[iIdx].b;          // node positions (px)
let dir = normalize(b - a);
let ortho = vec2f(-dir.y, dir.x);                       // screen-space normal
let alongQuad = QUAD[vIdx];                             // [-1,1]² corner
let p = mix(a, b, alongQuad.x * 0.5 + 0.5)              // lerp along the segment
        + ortho * (alongQuad.y * 0.5) * uLineWidth * uDpr;  // half-width, DPR-aware
out.pos       = vec4f(p / uResolution * 2.0 - 1.0, 0.0, 1.0);
out.alpha     = edges[iIdx].alpha;                      // distance-falloff weight
out.accent    = edges[iIdx].accent;                     // the flagged-node tether tint
out.lineCoord = alongQuad.y;                            // [-1,1] cross-line → fragment AA
```

A butt cap with no join is correct (the lattice is independent thin segments, not a continuous polyline) — the simplest 1-quad-per-segment expansion suffices; the rreusser join/cap machinery is overkill (booked if a heavier "glowing tether" register is later wanted). The fragment cross-line AA is a `smoothstep` on `lineCoord` (the rreusser radial-distance trick) so the hairline is itself crisp-edged. The accent edge (`accent > 0`) strokes `uAccent` at `uEdgeAccentAlpha` (the `drawEdges` G2 path preserved). **The pointer-web folds into the SAME line pass** (the cursor is an extra "virtual node" whose incident edges carry `uEdgeFocusAlpha` — `drawPointerWeb` retires onto this).

### 3 — The edge SET stays a CPU all-pairs scan (the default register; the compute path is BOOKED)
At the default count (`count=64`), the O(N²) all-pairs scan (`drawEdges`, joining nodes within `reach = link·k` with the distance-falloff alpha `t = 1 − d²/reach²`) is trivial — 64²/2 ≈ 2k pairs/frame (research/viz/constellation.md §3.4).
