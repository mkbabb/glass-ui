### 2 — WGSL-first: compute + instanced-line render (the migration; research/viz/fourier-field.md §3)
The fourier is geometry-driven (a curve + an epicycle chain), so it follows the FLOW-FIELD two-pass shape (compute → instanced-line render), NOT the aurora fullscreen-fragment shape:
- **Compute pass `fourier-field.compute.wgsl.ts`** (`@compute @workgroup_size(64)`): per invocation `i` computes the partial-sum curve point at `t_i = fract(head_t − trailArc·i/M)` truncated to N harmonics — the M trail/curve samples back along the period from the head (the comet body). `partialSumAt(t, n)` transcribes `math.ts:78-95` EXACTLY: `c += vec2(re·cos(2π·index·t) − im·sin, re·sin + im·cos)`. A second tiny pass (or the first K invocations) writes the epicycle CHAIN tips `positionsAt(spectrum, head_t, k)` for k=0..N into a `chainTips` buffer. Both are pure `f(coefficients, head_t, N)` — deterministic, `head_t` arrives as a uniform from the ONE keyframes.js clock (research/viz/fourier-field.md §3.2).
- **Render pass `fourier-field.render.wgsl.ts`** (instanced lines — the GPU thick-polyline SOTA, Ricky Reusser webgpu-instanced-lines / Matt DesLauriers "Drawing Lines is Hard"): the curve is M−1 segment instances reading `curveSamples`; each instance a quad with a `lineCoord` varying; the fragment SDF-antialiases (round caps/joins) and reads the per-sample AGE (`curveSamples[i].z`) for the comet-trail fade `peak·pow(age, fadeExp)` floored at `peak·trailFloor` — a per-FRAGMENT alpha, not a per-segment `globalAlpha`. A second instanced-line pass draws the epicycle arms; an instanced-quad ring-SDF pass draws the orbit circles + joint dots; a final instanced-quad radial-SDF pass draws the comet HEAD (halo + saturated core + white specular). Color rides the shared `procedural-color.wgsl.ts` OKLCh ramp (the rainbow chain a hue-sweep over it, NOT a second color path); premultiplied-alpha blend over the transparent clear — which KILLS the `lighter` additive hue-blowout the Canvas2D path fought (research/viz/fourier-field.md §2.4, §3.3). This gives the BOLD 3px stroke + glowing comet head with crisp GPU AA, far better than the Canvas2D `shadowBlur` hack.
- **The ONE math source** — `math.ts` stays the single source; the compute kernel transcribes `positionsAt`/`partialSumAt` line-for-line; the spectrum (`BasisComponent[]`) is CPU-minted (`makeEllipticSpectrum`/`dftFromPoints` run ONCE per source-swap, the coefficients upload as a uniform/storage table; the WGSL does the per-frame summation, never the spectrum mint). `proof:fourier-field` round-trips `positionsAt(spectrum, t, n)` (JS) vs the WGSL `epicycleChainTip(...)` at a fixed sample set — a numeric position-delta bar (research/viz/fourier-field.md §3.1).
- **The uniforms** — a `uniformBridgeWGPU.ts` (the concentric/flow-field precedent) packs ONE layout for both passes: `head_t`, `harmonicN`, `epicycleArmN`, `showEpicycles`, `sampleCount`, `trailArc`, `trailWidth`, `peakAlpha`, `headGlowAlpha`, `trailFadeExp`, `trailFloor`, `phasorCount`, `intensity`, `aspect`, the palette stops (≤4), the phasor table `(re, im, index, _pad)` (≤ MAX_PHASORS = 64 — the configurator N≤64 ceiling; >64 books a storage-buffer widen).
