## Target spec (grounded)
The viz is the composition of THREE cited techniques on the proven substrate (research/viz/paper-grid.md §3): (1) the Ben Golus derivative-AA grid distance function (the crisp-line fix — kills the blur), (2) the Iñigo Quílez domain warp of the UV before the grid eval (the "liquid" fix), (3) the Bridson divergence-free curl flow driving the warp coherently (WHY it's liquid not noise). ### 1 — The crisp line: Ben Golus derivative-AA grid distance (kills the "blurry mess")
The line coverage is computed from the screen-space DERIVATIVE of the (warped) UV, so a line is exactly N device-pixels wide at ANY DPR/zoom — never the CSS sub-pixel blur (Ben Golus, *The Best Darn Grid Shader (Yet)*; Evan Wallace, *Anti-Aliased Grid Shader* — research/viz/paper-grid.md §3.1):
```glsl
vec2 gridUV    = 1.0 - abs(fract(uv) * 2.0 - 1.0);          // triangle wave: 0 at line, 1 at cell center
vec2 uvDeriv   = vec2(length(vec2(dFdx(uv.x), dFdy(uv.x))), // length() (Golus: the right sharpness/aliasing balance)
                      length(vec2(dFdx(uv.y), dFdy(uv.y))));
vec2 drawWidth = clamp(vec2(targetWidth), uvDeriv, vec2(0.5));
vec2 lineAA    = uvDeriv * 1.5;
vec2 grid2     = smoothstep(drawWidth + lineAA, drawWidth - lineAA, gridUV);
grid2         *= clamp(targetWidth / drawWidth, 0.0, 1.0);                   // preserve thin-line intensity
grid2          = mix(grid2, vec2(targetWidth), clamp(uvDeriv * 2.0 - 1.0, 0.0, 1.0)); // Moiré suppression
float line     = max(grid2.x, grid2.y);                                     // line coverage [0..1]
```
WGSL carries the exact same primitives in the fragment stage — `fract`, `abs`, `smoothstep`, `clamp`, `dpdx`/`dpdy`/`fwidth` (the goo-blob `metaball.wgsl` already transcribes `fwidth()` to WGSL fragment-stage — `PROCEDURAL-SUITE.md` goo-blob row, the precedent; `fwidth` not `fwidthFine` so WebGPU Compatibility Mode is safe — research/viz/paper-grid.md §3.1, §4.1). The two-tier minor+major grid is two evals: at `g` and at `g / majorEvery` (Golus "major grid divisions" variant), composited brightest-wins.

### 2 — The "liquid": IQ domain warp of the UV before the grid eval
The grid is computed not at `uv` but at a **warped** coordinate `g(uv) = uv + warp(uv,t)` — the IQ domain-warp substitution `f(p) → f(g(p))`, `g(p) = p + h(p)` (iquilezles.org/articles/warp/ — research/viz/paper-grid.md §3.2). Because `h` is a smooth LOW-frequency field, adjacent cells warp TOGETHER — the whole sheet bows and flows (the "liquid" gestalt), never a per-line jitter. A SHALLOW warp (one level, low amplitude) keeps the lines a clearly-readable grid. The inverse-coherence lesson is binding (research/viz/dot-flow-field.md §3.2, cited in paper-grid.md §1.2): LARGE structures come from LOW spatial frequency — a high-frequency warp re-introduces the "noise" the user hates.

### 3 — The warp IS the divergence-free curl flow (the SHARED chunk — WHY liquid not noise)
The warp field is `curlFBM(g·warpScale + t·warpSpeed) · amplitude` — the 2D curl of an fbm potential (Bridson 2007: `∇×ψ = (∂ψ/∂y, −∂ψ/∂x)`, divergence-free BY CONSTRUCTION — `flow.glsl.ts:46-56`). The curl preserves the sheet's local area, so the grid "folds and stretches like real fluid advection rather than the source-y bulge a raw fbm gradient produces" (`flow.glsl.ts:5-8`) — a raw fbm gradient would pinch and bulge unevenly (visibly source-y, the "noise"). A SECOND counter-flowing curl term at a different scale/speed prevents a visible loop (Alex Harri counter-flow — research/viz/paper-grid.md §3.2, §5.2 step 3):
```wgsl
g += curlFBM(g * uWarpScale  + uTime * uWarpSpeed ) * uAmplitude;        // the liquid wave
g += curlFBM(g * uWarpScale2 - uTime * uWarpSpeed2) * (uAmplitude * 0.5); // counter-flow, never loops
```
This viz is the FIRST WGSL curl consumer, so it MINTS `flow.wgsl.ts` (the WGSL twin of `flow.glsl.ts`, the booked procedural-tail chunk — research/viz/paper-grid.md §3.3, §10). The host owns the noise basis (`potentialFBM`); the chunk owns only the basis-agnostic curl operator (the `flow.glsl.ts:18-25` dependency contract, transcribed to WGSL).

### 4 — The pointer bulge: a LOCAL Gaussian warp added on top (the interaction)
A SECOND, local warp term presses the grid toward/away from the cursor (research/viz/paper-grid.md §3.4, §8):
```wgsl
let toC = g - uCursor; let d = length(toC);                               // uCursor in grid space
let bulge = uBulgeStrength * exp(-(d*d) / (2.0 * uBulgeRadius * uBulgeRadius)); // Gaussian falloff
g += normalize(toC) * bulge;                                              // repel (attract: negate)
```
This is LOCAL — the grid stays coherent everywhere except where the cursor presses, so it reads as "the cursor pushing a bulge through a calm liquid grid" (the iOS-control-centre feel). Velocity scales `bulgeStrength` + adds a directional lead offset (the smear wake); acceleration fires a transient `sin(d·k − decayT)` ripple burst decaying on a `decayRest`-projected spring (§8). The push magnitude reads `usePointerVelocityField`'s position/velocity/acceleration/burst (§8).

### 5 — The fragment kernel (per pixel; research/viz/paper-grid.md §5.2)
```wgsl
var g = uv * uGridScale;                                  // uGridScale = view / minorPitch (LARGER cells = smaller scale)
g += curlFBM(g * uWarpScale  + uTime * uWarpSpeed ) * uAmplitude;          // §3 global liquid warp
g += curlFBM(g * uWarpScale2 - uTime * uWarpSpeed2) * (uAmplitude * 0.5);  // §3 counter-flow
let toC = g - uCursor; let d = length(toC);                               // §4 local pointer bulge
g += normalize(toC) * uBulgeStrength * exp(-(d*d) / (2.0 * uBulgeRadius * uBulgeRadius));
let dv    = vec2f(length(vec2f(dpdx(g.x), dpdy(g.x))), length(vec2f(dpdx(g.y), dpdy(g.y))));
let minor = gridCoverage(g,               uTargetWidth,      dv);          // §1 Golus AA, minor tier
let major = gridCoverage(g / uMajorEvery, uTargetWidthMajor, dv / uMajorEvery); // major tier
let line  = max(minor * uMinorAlpha, major * uMajorAlpha);                // two-tier weights
var col   = uLineColor.rgb;                                               // warm --foreground ink
let a     = line * uFieldAlpha;                                           // GLOBAL subtlety knob (suffusion → tiny)
return vec4f(col * a, a);                                                 // premultiplied over transparent
```
NO compute pass, NO storage buffers — ≤8 noise taps (the two curl terms) + the Golus AA, well under the ≤4ms compute the booking names (research/viz/paper-grid.md §5.2). The two scalar `Alpha` knobs map to the kf 3%/11% minor/major weights so the DEFAULT reads as the calm kf engineering grid (`grid-simple`'s rhythm), the warp adding the life.
