### A — The async adapter-real picker (the D8 close, cited shape: procedural-refs.md §0)
`createGpuSubstrate` (`useGpuSubstrate.ts`) STOPS committing the backend synchronously off a presence check. The robust **try-WebGPU-then-rebuild-WebGL2** shape (procedural-refs.md §0 form 2, the more robust of the two — it also catches a device that creates then immediately loses, the Safari device-lost-at-birth class, aurora.md [S5]):
1. The picker attempts the WebGPU leaf's `armAsync()` inside a `try`. `armAsync()` already does the async `requestAdapter()` → `requestDevice()` → `context.configure()` prelude (`useWebGPUCanvas.ts:148-324`).
2. On ANY init failure — `requestAdapter()` returns null, `requestDevice()` rejects, a `device.lost` fires at birth, a validation throw via the `pushErrorScope`/`uncapturederror` bracket — the picker **disposes the WebGPU leaf + rebuilds on the WebGL2 leaf** (`setupGL`). This is the documented-but-undelivered graceful degrade.
3. The committed-once construction model is REPLACED by an async-resolved backend: the handle surface (`arm/armAsync/suspend/resume/wake/renderAt/dispose/reducedMotion`, `useGpuSubstrate.ts:67-80`) is byte-identical to consumers — only the INTERNAL backend resolution becomes async + fall-through.
4. `useWebGPUCanvas.ts:243-245` STOPS throwing on no-adapter; it returns a recognizable init-failure signal the picker catches (a `null` handle / a rejected `armAsync` the picker's `try` handles), NOT an uncaught `throw` that spews to the console (D8'). The `onInitError` contract is PRESERVED for genuine shader/OOM violations (a no-adapter fall is a recognized substrate decision, not a contract violation — the W-AURORA-SWRASTER precedent, CLAUDE.md `#### The software-raster guard`).
5. The SHARED `createCanvasLifecycle` leaf is byte-untouched (the demand-gate, the three-reason suspend Set, the offscreen-park, the live-PRM re-monitor are sound — viz-codebase.md §0). The fix is exclusively the PICKER. **NO per-viz fork of the lifecycle** (the ONE-leaf discipline).

The alternative async-probe shape (`supportsWebGPUReal()` = `navigator.gpu != null && (await navigator.gpu.requestAdapter()) != null`, cached one-per-page) is the SIMPLER form (procedural-refs.md §0 form 1); the try-then-rebuild is chosen because it ALSO catches device-lost-at-birth (the Safari flash class). The executor picks the try-then-rebuild; the cached `supportsWebGPUReal` is an acceptable interim IFF it also covers device-lost (it does not, so try-then-rebuild is the spec).

### E — The WGSL-compile floor (the var-target source bug the picker can never catch)
The picker fix (§A) makes a no-adapter host degrade silently — but a host WITH an adapter can still paint black if the WGSL primary's SOURCE does not compile, because the try-then-rebuild (§A.2) catches a compile/validation throw and falls to WebGL2 FOREVER, undetected. The BB viz suite SHIPPED exactly this: GooBlob's `metaball.wgsl` used `var target` (`var` is a reserved WGSL keyword) → `device.createShaderModule()` emits an `error`-severity `getCompilationInfo()` message → the render pipeline is invalid → 250 invalid-pipeline errors/frame → 0 pixels from the WGSL primary, the WebGL2 net silently carrying every Safari/Chrome session that should have run WGSL. An adapter probe CANNOT catch this (the adapter is fine; the SHADER is broken). So the substrate-everywhere wave owns a real WGSL COMPILE assert over every `*.wgsl.ts` string: a headless `device.createShaderModule({code}) + await getCompilationInfo()` (on an adapter-bearing host) AND a native-validator (naga/tint) pass device-free in CI, each asserting ZERO `error`-severity message on every ASSEMBLED shader string (the chunks spliced as they ship, so a splice-boundary keyword collision is caught too). This is the floor the DEFERRAL-LEDGER's `bb-wgsl-gooblob-compile-error`/`mem-wgsl-gooblob-compile` rows promise and the WAVE-INDEX title names — it lives HERE, beside the picker, because the picker's silent fall is precisely what hides the source bug. The per-viz waves keep their shader BODIES; this wave owns the cross-cutting compile gate (W7) over all of them.
