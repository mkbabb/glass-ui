## Goal (the gestalt)
Open ANY route on `:5199` and you read the SAME confident page idiom: a LARGE audacious display title sitting over a live procedural field, a quiet mono eyebrow above it carrying the route's explicit import subpath in Fira Code (`@mkbabb/glass-ui/aurora`), a one-line subtitle beneath, and the whole page body in exactly ONE warm-cream glass card floating over that field — never two cards, never a grid-card-inside-a-page-card, never a header buried inside the body card.
