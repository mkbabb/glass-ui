## Goal (the gestalt)
Open any route and the body reads as cleanly DELIMITED sections — each named section carries the SAME canonical heading rung (the √φ 20.4px section `<h2>`), and consecutive sections are separated by a visible hairline rule (or sit in their own sub-card), so the page is never an undelimited gap-stack where every block blurs into the next. The hierarchy is consistent + recognizable: ONE chassis hero (the dominant display title, sized by page-DEPTH — a section landing's title out-sizes a main's, which out-sizes a sub-page's) → the body's section headings (the secondary rung) → the supporting mono eyebrows + blurbs (the tertiary rung), every page the same shape. The 41 pages that hid a SECOND `border-l-[3px]` IconChip header INSIDE the body card no longer double-describe — that identity is the chassis hero's icon ON TOP of the card; the body holds only delimited sections. EVERY PAGE is standardized.

- **R1 — the chassis hero `<h1>`, DEPTH-KEYED** (display register, `BC.W-PAGE-CHASSIS` `heroScale`/`depth`). The DOMINANT rung, ON TOP of the card, ONE per page.
