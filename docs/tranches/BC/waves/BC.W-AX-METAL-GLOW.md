## Target spec (grounded)
Two tokens + the catch-light layer on the metal family.

### T1 — `--metal-glow-blur` / `--metal-glow-opacity` (the catch-light parameters)
Two knobs on the metal recipe (`metal.css`):
- **`--metal-glow-blur`** (a length, default ~`0.5em` — a soft halo proportional to the text size; the glow radius scales with the metal size).
- **`--metal-glow-opacity`** (a number, default ~`0.35` — the halo strength; a warm whisper, not a neon bloom — the warm-cream identity bounds it).
The glow color reads the metal's OWN base (`--metal-stop-base` — gold's base for `.metal-gold`, silver's for `.metal-silver`, etc.) so the catch-light is the metal's hue, never a fixed gold-on-silver mismatch. The gold glow is the earned-gold (`--color-gold` via the gold quad's `--metal-stop-base`) — Q2.

### T2 — the catch-light layer (the lit-metal glow, shared)
The metal text-clip gains a glow LAYER — a `drop-shadow`/`text-shadow`-class halo of the metal base color at `--metal-glow-blur` radius + `--metal-glow-opacity` strength, painted BEHIND the gradient text-clip (so the gold gradient reads over its own warm halo — lit metal). The mechanism: since `background-clip: text` makes the text transparent (the gradient shows through), the glow is a `filter: drop-shadow(0 0 var(--metal-glow-blur) color-mix(in srgb, var(--metal-stop-base) calc(var(--metal-glow-opacity) * 100%), transparent))` on the metal element (a drop-shadow follows the clipped text shape — the halo hugs the glyphs). The glow is on the SHARED metal selector group (`.metal-gold, .metal-silver, .metal-bronze`) — ONE recipe, every metal lit. The glow is PRM-STATIC (it paints at rest — the lit metal reads for PRM users; the sweep motion is the only gated thing, the existing bracket unchanged).

- **The warm-cream identity bounds the glow.** `--metal-glow-opacity` defaults to a warm whisper (~0.35), not a neon bloom — the glow is a soft catch-light, not a disco glow (the §6 calm register; the disco family stays gone).
