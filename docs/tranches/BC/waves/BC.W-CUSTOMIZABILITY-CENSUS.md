## Goal (the gestalt)
A consumer reaches for ANY published glass-ui component and finds the SAME three-layer customization surface: **props** for the semantic per-instance choices (variant / size / tier / tone), **`--token` `:root` overrides** for the visual magnitudes (padding / blur / glyph / alpha / hue / duration), and **slots** for content — AND the bare component already reads as a proportioned √φ-typography / warm-cream-glass / spring-clocked design that AFFORDS hierarchy out of the box (a primary CTA can be bigger + glassier than a secondary with one prop, no per-site hand-tuning). The library already SET this bar inside itself — Card (7 `tier` rungs + the golden sqrt-φ/φ/φ² padding ladder), Button (13 variants + 6 size rungs reading `--control-h-*`), GlassDock (12 axes). This wave makes that bar BINDING + MACHINE-LOCKED so the gap (21 of 42 `ui/` dirs have ZERO customization axis; ~31 files hardcode `text-sm` off the √φ ladder; the overlay band is internally inconsistent) cannot be smuggled past a close, and a NEW component cannot land un-audited. It is the Band-12 census + gate; it does NOT do the per-component threads (those are the consumer waves).

## Fences / invariants (must NOT regress)
- **DON'T over-prop (binding).** A TOKEN beats a prop where a `:root` override suffices: magnitudes (padding/blur/glyph/alpha/hue/duration) → tokens; semantic per-instance choices (variant/size/tier/tone) → props. The gate does NOT demand a prop for a magnitude a `:root` token already covers (a wave that adds a `padding` prop where `--overlay-pad-inline` suffices is the anti-pattern, recorded as a gate note).
- **No contrivance.** A size/variant/tier axis is added ONLY where the hierarchy choice is REAL: the input register (Input/Switch/Textarea) gets a `size` axis (control-size hierarchy is real); Separator/Label/Skeleton do NOT (a hairline/label has no size hierarchy — forcing one is contrivance). The census records the no-contrivance verdict per dir (`token-only-correct` for the surfaces a `:root` token fully serves).
- **DRY — thread the EXISTING register, ZERO new register.** The `--control-*` cohort, the `Surface` axis, the φ overlay-pad ladder, the √φ type ladder all have ≥2 consumers. This band threads them onto the gap surfaces; a wave that mints a parallel size/surface/pad register instead reds (the de-shadcn KISS discipline).
- **The gate scopes the customization-SURFACE axis, NOT the paint axis.** `BC.W-DESHADCN`/`proof:no-shadcn-default` owns "is the default paint ours?" (the shadcn-neutral token vocabulary); `proof:glass-cohesion` owns the bg-opacity axis. `proof:customizability-census` owns "can a consumer express hierarchy via the right knobs?" — the three are disjoint by clause. Where a fix overlaps (e.g. the Switch thumb `bg-background` is `BC.W-DESHADCN`'s paint AND the Switch `size` axis is this band's), the two gates assert DIFFERENT facts on the same file and never contradict.
- **The `file:`-modifier-scoped literal is distinguished (C1 clause).** Input's `file:text-sm file:text-medium` modifier-scoped classes style the file-upload pseudo-element, NOT the input's own type register (which the `.input-pill` recipe pins to `font-size: var(--control-text)`). The gate flags the BARE unscoped `text-sm` on the control root (the forbidden literal), NOT a `file:`/`placeholder:`/`[&_…]:`-modifier-scoped one (a distinct sub-element register). The self-test proves the distinguishing bite (a bare `text-sm` reds, a `file:text-sm` does not).
- **No public-prop break from the THREADS.** The size/surface axes the consumer waves add are ADDITIVE default-`"default"`/default-`"glass"` (byte-near-identical at HEAD), so a bare component is unchanged and no MIGRATION row is owed for the additive axes (only a deliberate paint change in a consumer wave gets one). The gate asserts the bare default is golden, not that every component sprouts new props.
- **`proof:ba-gestalt` is the per-consumer-wave verdict, not this wave's.** Each consumer wave (CONTROL-CUSTOM/OVERLAY-UNIFORM/SEARCH-CUSTOM/HERO-AUDACIOUS) re-earns its own `proof:ba-gestalt` band verdict on its threaded surfaces. This wave owns the structural gate + census + π enrollment; it does not double-own the per-band paint sign-off.
