## Goal (the gestalt)
Open the storybook at `:5199` and walk EVERY route — foundations → substrates → forms → display → containers → navigation → dock → data → feedback → motion → compositions. It reads as ONE coherent, professional, awwwards-grade design system demo: consistent generous padding on every card and page, a steady rhythm of whitespace between sections, the audacious type ladder applied with restraint, no element clipped or occluded by the fixed dock chrome, no text too small to read, no stray off-brand hue, no double-header, no orphan dead route. Every pane obeys the SAME idiom — the glass material, the warm-cream identity, the √φ type ladder, the Fira-Code code register, the section-color POPs within proportion. A designer scrolling it cannot find the seam where one author's page ends and another begins. What the user finally sees: the proof surface they judged "destroyed" now reads as the reference implementation.
