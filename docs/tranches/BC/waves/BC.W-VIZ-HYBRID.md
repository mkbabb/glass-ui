## Goal (the gestalt)
Open `/substrates/goo-dot` (or the `variant="dot-matrix"` register on `/substrates/blob`) and the merging metaball reads as a FIELD OF DOTS that flow and merge. A regular grid of small warm-cream dots fills the card; where the gooey blob is — its core, its satellites, the liquid neck stretching between them — the dots are DENSE, BIG, and BRIGHT; out at the rim and beyond they thin to small and dim, then vanish. As a satellite orbits in and meatballs into the body, the band of dots between them THICKENS into a connected bridge, then snaps back when it absorbs — the gooey form drawn entirely in dots, breathing and merging. A second register dithers the field into a halftone (dots appear denser toward the core, sparser at the rim, the classic dotted-tone read). A third register lays the dots on an explicit lattice that FLOWS toward the merging core (the surrounding dots lean inward as the blob necks in, then relax to their anchors). Move your cursor and the whole dot-cloud tilts toward it (the field lean), the dots near the cursor brighten and swell, and a fast flick fires a one-shot bloom (the accel burst). It works identically on Safari 26 (WGSL/Metal primary, no flash). The library default is warm-cream; the teal-on-navy is nowhere.

## Target spec (grounded)
The hybrid is **a new viz that re-uses two SOTA primitives the codebase already owns, joined by ONE new idea**: render the metaball SDF FIELD as a dot matrix — a grid of small dots whose size + brightness are driven by the field value at each dot's cell, so the dots are dense+big+bright INSIDE the merged metaball and sparse+small+dim outside. This is conceptually **tixy.land applied to an SDF** — tixy's `(t,i,x,y) ⇒ v` drives a dot grid's size+color; the hybrid's `v = thickness(sceneDistG(cellCenter))` is exactly that per-cell scalar, but the function IS the gooey metaball field. Two render registers, ONE field, ONE substrate. All numbers pinned from research/viz/hybrid.md.

### T1 — Register A: the FRAGMENT dot-stamp (the fullscreen-triangle path; the DEFAULT — research/viz/hybrid.md §2.1)
A pure fragment swap of the metaball pass — the SAME `vs_main` full-screen triangle, the SAME uniform struct + ONE new lane, the SAME `procedural-color.wgsl.ts` ramp. Per fragment:
```wgsl
// 1. the field at THIS pixel (the goo half — byte-identical to metaball.wgsl)
let scene     = sceneDistG(uv);
let bodyR     = uBodyRadius + breath(uPulsePhase) * uPulseAmp;
// 2. quantize fragCoord to a dot grid (cell = uDotPixelSize device px)
let cell      = floor(fragCoord / uDotPixelSize);
let cellCtr   = (cell + 0.5) * uDotPixelSize;
let cellCtrUv = (cellCtr / uResolution - 0.5);
// 3. the field AT THE CELL CENTER (so every fragment in a cell agrees on the dot)
let fCell     = clamp(-sceneDistG(cellCtrUv).x / max(bodyR,1e-4), 0.0, 1.0);
// 4. dot radius = field-driven (dense+big inside, small outside); 0 outside the field
let dotR      = uDotMin + (uDotMax - uDotMin) * smoothstep(uFieldFloor, 1.0, fCell);
// 5. antialiased circle at the cell center (the fwidth-feathered Book-of-Shaders dot)
let pd        = length(fragCoord - cellCtr);
let aa        = fwidth(pd);
let dot       = 1.0 - smoothstep(dotR - aa, dotR + aa, pd);
// 6. brightness/color also reads fCell (dim outside, bright inside) — the SAME OKLCh ramp
let bright    = uDotBrightFloor + (1.0 - uDotBrightFloor) * fCell;
let alpha     = dot * bright * step(uFieldFloor, fCell);   // no dot where field < floor
```
**Why CELL-CENTER sampling (step 3, the second `sceneDistG`):** a per-FRAGMENT field value would make the dot's radius vary continuously WITHIN the cell — the dot would smear, not read as a discrete dot. Sampling the field at the cell center gives every fragment in the cell ONE agreed dot radius — the discrete tixy/Metal dot. The cost is a SECOND `sceneDistG` eval per pixel (the field is cheap — a handful of smins + one FBM octave; the metaball pass already runs it once per pixel). This is `uDotMode == 0` — the smooth field-driven dot, the DEFAULT.

### T2 — Register A's Bayer-dither halftone (`uDotMode == 1` — research/viz/hybrid.md §2.2)
Instead of a smooth radius ramp per cell, ORDERED-DITHER the field thickness into on/off dots — denser dots toward the core, sparser at the rim (the classic halftone). The Codrops Bayer macros (verbatim):
```glsl
float Bayer2(vec2 a){ a = floor(a); return fract(a.x/2.0 + a.y*a.y*0.75); }
#define Bayer4(a)  (Bayer2(0.5*(a))*0.25 + Bayer2(a))
#define Bayer8(a)  (Bayer4(0.5*(a))*0.25 + Bayer2(a))
```
The dot-from-field: `mask = step(0.5, thickness + Bayer8(cell) - 0.5)`. The Codrops guidance: **Bayer8** ("beyond 8×8 the perceptual gain is minimal"), `PIXEL_SIZE = 8–10px`, combine with fbm for "more organic" — and the metaball field ALREADY has the warped-FBM membrane (`fbmWarpedG`), so the dither inherits the organic edge for free (research/viz/hybrid.md §2.2). Both Register-A modes are the fullscreen fragment, parity-clean.

### T3 — Register B: the INSTANCED dot-lattice (the depth/flow look; opt-in — research/viz/hybrid.md §2.3)
A FIXED lattice of instanced billboard quads (the `BC.W-VIZ-DOTMATRIX` rasterizer + the `flow-field.render.wgsl.ts:98-153` shape). Each dot reads the field at its anchor for size+brightness, with an OPT-IN sub-cell displacement TOWARD the field gradient so the dots FLOW toward the merging core:
```wgsl
let o      = gridOrigin(ii, uCols, uPitch);    // deterministic lattice anchor
let scene  = sceneDistG(o);
let fCell  = clamp(-scene.x / bodyR, 0.0, 1.0);
let grad   = scene.yz;                          // the SDF gradient (toward the surface)
let disp   = -normalize(grad + 1e-6) * uFlowAmt * fCell * uPitch;  // capped < 0.5 pitch
let pos    = o + disp;                          // OFFSET from anchor, never advect (the anchored-grid discipline)
let size   = uDotBaseSize * (uDotMin + (1.0 - uDotMin) * fCell);
let bright = uDotBrightFloor + (1.0 - uDotBrightFloor) * fCell;
```
The dots flow toward the core (the gradient points outward from the surface, so `-grad` points inward) — a satellite necking in pulls the surrounding dots toward the merge, then they relax to their anchors when it absorbs. The displacement is capped LOW (< 0.5 pitch) so the lattice stays coherent (the dot-flow-field anchored-grid discipline). Register B also HOSTS the Fibonacci dot-SPHERE (`variant="dot-sphere"`) — the SAME instanced pipeline, the per-instance position the phyllotaxis lattice instead of a screen grid — reusing `BC.W-VIZ-DOTMATRIX`'s rasterizer wholesale (one instanced pipeline, two position sources: screen grid OR sphere lattice).

### T4 — Which register is the default (the SOTA decision — research/viz/hybrid.md §2.4)
**Register A (`uDotMode==0`, the smooth field-driven dot) is the DEFAULT.** It is the literal "metaball rendered as a dot matrix," it inherits the metaball pass's WGSL/GLSL parity for free (a fragment swap, not a new pipeline), it has no per-frame buffer cost, and it is the cheapest path that reads as the hybrid. Register A's dither (`uDotMode==1`) is the halftone alternative. Register B (instanced lattice) is the OPT-IN depth/flow look + the dot-sphere host — a second pipeline (the `flow-field.render.wgsl` shape), gated behind `variant="dot-lattice"` / `variant="dot-sphere"`. The `variant` axis: `dot-field | dot-dither | dot-lattice | dot-sphere`, default `dot-field`.
