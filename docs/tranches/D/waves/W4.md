# D.W4 — Velocity Foundation

**Opens after**: D.W3
**Agents**: 4 parallel (A: tsconfig.src + iter-check, B: vite.iter + iter-build, C: Vitest harness + ~120 smoke tests, D: three-tier scripts + ay-close)
**Hard gate**: `npm run iter` < 10 s wall; ~120-160 Vitest tests green; `scripts/ay-close.sh` exists and runs end-to-end
**Status**: planned

## Scope

A4 measured: typecheck 11.8 s warm, build 6.5 s warm (65% spent in dts plugin), zero tests. D.W4 ships the three-tier surface (routine / profile / proof) per A4's proposal and the Vitest harness. After W4, every subsequent tranche pays a 10 s iter cost instead of a 30 s one, and a smoke-test suite gates regressions before they ship.

1. Add `tsconfig.src.json` (src-only typecheck path) + `iter-check` script.
2. Add `vite.iter.config.ts` (no-dts iter build) + `iter-build` script.
3. Install Vitest + author ~120-160 smoke tests covering ui + surviving custom + composables.
4. Add three-tier scripts (`iter`, `profile-bundle`, `profile-consumers`, `ay-close`, `validate-consumers`) + orchestration shell scripts.

## Phase sub-items

### D.W4.A — `tsconfig.src.json` + `iter-check` script

**Mechanism**:

1. Author `tsconfig.src.json` extending `tsconfig.json` with `include: ["src/"]` (exclude demo/):

```json
{
  "extends": "./tsconfig.json",
  "include": ["src/"]
}
```

2. Add to `package.json` scripts:

```json
"iter-check": "vue-tsc --noEmit --project tsconfig.src.json"
```

**Sub-gate**: `time npm run iter-check` warm < 8 s wall (reduced from 11.8 s warm full).

### D.W4.B — `vite.iter.config.ts` + `iter-build` + `emit-types`

**Mechanism**:

1. Author `vite.iter.config.ts` cloning `vite.config.ts` but **omitting `dts()` from `plugins`**:

```ts
import { defineConfig, mergeConfig } from "vite";
import baseConfig from "./vite.config";

export default mergeConfig(
    baseConfig,
    defineConfig({
        plugins: [/* dts plugin omitted */],
        build: { sourcemap: false },
    }),
);
```

(The `mergeConfig` approach keeps duplication minimal; alternative: full clone if `mergeConfig` doesn't selectively drop `dts` cleanly. Sub-agent picks whichever works first.)

2. Add to `package.json` scripts:

```json
"iter-build": "vite build --config vite.iter.config.ts",
"emit-types": "vue-tsc --emitDeclarationOnly --outDir dist/types --project tsconfig.json"
```

(`emit-types` is the explicit type-emission path used by full proof builds. `npm run build` continues to emit types via dts plugin per the existing config.)

**Sub-gate**: `time npm run iter-build` warm < 3 s wall (reduced from 6.5 s warm full); `dist/glass-ui.js` + `dist/glass-ui.css` emit but no `index.d.ts`.

### D.W4.C — Vitest harness + smoke tests

**Mechanism**:

1. Install Vitest + companions (orchestrator runs `npm install` once on master after sub-agent commits):

```json
"devDependencies": {
    "vitest": "^3.x",
    "@vitest/browser": "^3.x" or "happy-dom": "^15.x",
    "@vue/test-utils": "^2.x"
}
```

(Pick `happy-dom` for headless speed, `@vitest/browser` if real-browser DOM fidelity is required for any test.)

2. Author `vitest.config.ts`:

```ts
import { defineConfig } from "vitest/config";
import vue from "@vitejs/plugin-vue";
import path from "path";

export default defineConfig({
    plugins: [vue()],
    test: {
        environment: "happy-dom",
        globals: true,
    },
    resolve: {
        alias: {
            "@": path.resolve(__dirname, "src"),
        },
    },
});
```

3. Add to `package.json`:

```json
"iter-test": "vitest run --reporter=verbose",
"iter-test-watch": "vitest --watch"
```

4. Author smoke tests at `tests/<area>/<component>.spec.ts`:

- `tests/ui/button.spec.ts`, `card.spec.ts`, `input.spec.ts`, `label.spec.ts`, `badge.spec.ts`, `separator.spec.ts`, `tooltip.spec.ts`, `dialog.spec.ts`, `select.spec.ts`, `sheet.spec.ts`, `drawer.spec.ts`, `popover.spec.ts`, `dropdown-menu.spec.ts`, `accordion.spec.ts`, `alert.spec.ts`, `avatar.spec.ts`, `checkbox.spec.ts`, `collapsible.spec.ts`, `command.spec.ts`, `context-menu.spec.ts`, `hover-card.spec.ts`, `number-field.spec.ts`, `progress.spec.ts`, `radio-group.spec.ts`, `skeleton.spec.ts`, `slider.spec.ts`, `switch.spec.ts`, `table.spec.ts`, `tabs.spec.ts`, `tags-input.spec.ts`, `textarea.spec.ts`, `toggle.spec.ts`, `toggle-group.spec.ts` — **32 ui tests × 2-3 each = ~70-90**.

- `tests/custom/<component>.spec.ts` per surviving custom (post-W2 delete) — exact list determined at W4.C dispatch from `find src/components/custom/ -maxdepth 1 -type d`. Expected: ~15-20 components × 2 each = ~30-40 tests.

- `tests/composables/<name>.spec.ts` per composable — `useDockState`, `useDockTransition`, `useLayerTransition`, `usePopupMutex`, `useGlobalDark`, `useKeyboardShortcuts`, `useClipboard`, `useWatercolorBlob`, `useHeightTransition`, `useHoverPopover`, `useHoverToggle`, `useTouchGate`, `useLeaveTimer`, `useSortable`, `useGlassCarousel`, `useFuzzySearch`, `useSidebarState`, `useSidebarFollow`, `useScrollTracker`, `useTreeIndex`, `useAnimatedNumber`, `useScrollProgress`, `useSpringOrchestrator`, `useStaggerReveal`, `useVirtualSectionWindow`, `useWindowedStore`, `useOffsetPagination`, `useInfiniteScroll`, etc. — **18+ composables × 2 each = ~36+**.

Per-test smoke shape (Button example):

```ts
import { describe, it, expect } from "vitest";
import { mount } from "@vue/test-utils";
import Button from "@/components/ui/button/Button.vue";

describe("Button", () => {
    it("renders text content", () => {
        const wrapper = mount(Button, { slots: { default: "Click me" } });
        expect(wrapper.text()).toBe("Click me");
    });
    it("emits click event", async () => {
        const wrapper = mount(Button, { slots: { default: "Submit" } });
        await wrapper.trigger("click");
        expect(wrapper.emitted("click")).toBeDefined();
    });
    it("applies variant class via buttonVariants", () => {
        const wrapper = mount(Button, {
            props: { variant: "destructive" },
            slots: { default: "Delete" },
        });
        expect(wrapper.classes()).toContain("bg-destructive");
    });
    it("respects disabled prop", () => {
        const wrapper = mount(Button, {
            props: { disabled: true },
            slots: { default: "X" },
        });
        expect(wrapper.attributes("disabled")).toBeDefined();
    });
});
```

**Test-coverage demands**:
- Each ui component: ≥ 2 tests covering props + slots/emits + variant if applicable.
- Each composable: ≥ 2 tests covering basic invocation + at least one edge case.
- No snapshot tests (brittle for styled components).
- No E2E in this harness (Playwright already covers stories).
- Total test count target: 120-160.

**Sub-gate**: `time npm run iter-test` warm < 5 s wall; full suite green; per-spec at least the 4 documented test patterns.

### D.W4.D — Three-tier scripts + consumer validation + ay-close orchestration

**Mechanism**:

1. Add to `package.json` scripts (compose the routine cycle + introduce profile + proof tiers):

```json
"iter": "npm run iter-check && npm run iter-build && npm run iter-test",
"profile-bundle": "vite build --config vite.config.ts",
"profile-consumers": "scripts/validate-consumers.sh",
"ay-close": "scripts/ay-close.sh",
"validate-consumers": "scripts/validate-consumers.sh"
```

(`profile-bundle` adds rollup-plugin-visualizer in a follow-on; for W4 the script just runs the standard production build with stats logged. The visualizer plugin is W4.D-optional and lands as an installed devDep with the script wired.)

2. Author `scripts/validate-consumers.sh`:

```bash
#!/usr/bin/env bash
set -e
ROOT=$(git rev-parse --show-toplevel)
PARENT=$(dirname "$ROOT")
echo "Consumer build validation"
echo "========================="
for consumer in "$PARENT/fourier-analysis/web" "$PARENT/words/frontend" "$PARENT/bbnf-lang/playground"; do
    name=$(basename "$consumer")
    echo "-> $name"
    if [ -d "$consumer" ]; then
        ( cd "$consumer" && time npm run build ) 2>&1 | tail -5
    else
        echo "   MISSING $consumer"
    fi
    echo
done
```

3. Author `scripts/ay-close.sh`:

```bash
#!/usr/bin/env bash
set -e
ROOT=$(git rev-parse --show-toplevel)
cd "$ROOT"

echo "ay-close — proof ceremony for tranche close"
echo "=============================================="

echo "[1/5] Clean dist + vite cache"
rm -rf dist/ node_modules/.vite

echo "[2/5] Full typecheck (cold)"
time npm run typecheck

echo "[3/5] Full build (with dts)"
time npm run build

echo "[4/5] Full Vitest"
time npm run iter-test

echo "[5/5] Three consumer builds"
"$ROOT/scripts/validate-consumers.sh"

echo "ay-close complete"
du -sh dist/glass-ui.js dist/glass-ui.css
```

(Both shell scripts marked executable: `chmod +x scripts/validate-consumers.sh scripts/ay-close.sh`.)

**Sub-gate**: `time npm run iter` warm < 10 s wall (combined check + build + test); `scripts/validate-consumers.sh` exits 0 on green build; `scripts/ay-close.sh` end-to-end exits 0; package.json scripts present.
