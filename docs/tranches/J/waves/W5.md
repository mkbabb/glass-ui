Lane A re-cast as **"build CVA from scratch"** rather than "extend existing CVA".

Per R3 §C:

1. Build `sliderVariants` CVA at `src/components/ui/slider/index.ts` covering: existing `standard | spectrum | timeline` baseline + new `glass-pill` (pill-shape track) + `glass-cartoon` (composes `cartoon-surface` track + cartoon-shadow thumb) + size axis: `sm` (24px track / 12px thumb), `md` default (32px / 16px), `lg` (48px / 24px). Tactile feedback scales by size.
2. Refactor `Slider.vue` to consume `cn(sliderVariants({ variant, size }))` instead of in-template string-prop branching; collapse the scoped-CSS branches into the CVA recipe.
3. Refine the prior-named `glass-track` substrate (now landing via `glass-pill` recipe) per R3.C "weak diagnosis":
   - thumb halo on hover (consumes new `--surface-tint-N` from W1)
   - track gradient density refinement (denser sample points, smoother grad stops)
   - active-state animation (thumb scale via `--scale-press`)
4. Replace bespoke `:focus-visible` outline strip with `.focus-ring` consumption (R5 axis 7 a11y row).

## Lane C — Drag-keep-open visual feedback

Per R3 §D + R6 cornerstone-3 contract WIRE:

1. `useDockState` exposes `isHeld: ComputedRef<boolean>` (true when ≥ 1 token alive in the dock keep-open sink).
2. Substrate keys tier-shade off `data-held="true"` attribute on the dock root (W3 lane A dock element). E.g., dock background `--glass-bg-default` lifts to `--glass-bg-medium` when `data-held`; ambient ripple animates.
3. Slider thumb halo intensifies when `dockSink.isHeld` (subscribe via the existing sink-acquire return value).
4. Per-frame timing: feedback transitions on `--duration-fast` (180ms) so it tracks pointer movement without lag.

This contract WIRE proves the W3.γ dock-keep-open API surface beyond Slider — making it a 2-consumer mature substrate per `feedback_overfitting_audit` ≥ 2 bar.
