- ≥ 3 viewports (e.g., 375×667, 1280×800, 1440×900) for layout/clipping defects;
- animation-timing samples (≥ 5 frames spanning the named duration) on every state-toggle transition the tranche introduced or modified;
- contrast-vs-background measurement for every interactive surface the tranche introduced (≥ WCAG AA 4.5:1 for body text, ≥ 3:1 for large text and UI graphics);
