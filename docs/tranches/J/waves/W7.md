## Steps

### A. Pre-close orchestrator pass

- Verify build / typecheck / test green at HEAD.
- Re-run β-style overfitting audit at HEAD with **visual-load-bearing-ness** probe; confirm zero remaining library-orphans + zero quantitatively-wired-but-visually-unmade artefacts.
- Re-run γ-style doc-drift audit at HEAD.
- Re-run δ-style idiomatic-gestalt audit at HEAD with **per-story consumption sweep** — for every CVA / utility / token introduced or migrated by J, grep demo/ to confirm canonical consumption.
- Re-run recovery-diary canonical grep against src/ + demo/; confirm zero hits (CI guard should also fail otherwise).
- Re-run Playwright probe at **≥ 3 viewports** (375×667, 1024×768, 1440×900) over canonical surfaces + every J-modified surface; capture animation-timing samples on every state-toggle the tranche introduced/modified; capture contrast-vs-bg measurements on every interactive surface introduced.
- Verify per-wave commits landed.
- Verify PROGRESS.md status entries match reality.
- Stage `audit/J-pre-close.md` listing every artefact's final disposition + commit hash.

### B. 6-agent post-close audit (strengthened, parallel)

Per the W0 precept update:

- **Lane α — plan-vs-actual**: walk every wave spec line-by-line against PROGRESS.md + close docs.
- **Lane β — substrate-without-consumer (visual-load-bearing-ness)**: re-run overfitting audit with rendered-state probe; flag any artefact passing quantitatively but failing visually.
- **Lane γ — doc-drift**: walk DESIGN.md + CLAUDE.md + README.md + PROGRESS.md + each wave-spec status line + J.md against current source.
- **Lane δ — idiomatic gestalt + per-story consumption sweep**: walk every J-introduced CVA/utility/token; grep demo/ for canonical consumption; flag bypasses.
- **Lane ε — performance**: re-run bundle audit; verify dts emission; re-measure stress baseline; verify subpath cohort still consumed (cross-repo speedtest).
- **Lane π — visual-runtime (multi-viewport)**: 3 viewports × every J-modified surface + canonical baseline; animation-timing samples; contrast measurements.

Each lane writes `docs/tranches/J/audit/J-audit-{α,β,γ,δ,ε,π}-*.md`.

### C. Findings absorb

For every accepted finding:
- **Doc-only fix**: orchestrator applies the fix in W7 (within-wave absorb).
- **Source fix**: open a residual entry in `audit/J-residuals.md` with named destination.
- **Gestalt fix**: same as source-fix.

If absorb requires substantive code changes, the wave splits.

### D. FINAL.md authoring

After clean audit returns, write `docs/tranches/J/FINAL.md`:
- Tranche thesis, opening + closing date.
- Wave-by-wave table with status + commit hash + close evidence.
- Substrate convergence stats: tokens shipped (W1 vocab.γ); drift rows eliminated (W2 vocab.α+β); architectural transpositions executed (W3 DockPopover→Popover, W4 Configurator unification, W5 StoryChassis); refinements landed (W3 dock cornerstone, W4 aurora/blob, W5 form primitives, W6 data/composition).
- Process hardening stats: precept files updated (strengthened 6-agent close pattern; 3 new lessons-learned entries).
- Cross-tranche debt + named-destination residuals (J residue list — should be clean since J directly absorbed user findings).
- Brittleness windows (likely none; if W6 FuzzySearch rewrite required a window, declare it here as restored).
- Authority — J closes clean.

### E. Lessons-learned reconciliation

Append any new process-failure incidents to `docs/precepts/instructions/LESSONS-LEARNED.md`. Otherwise mark J as a clean tranche close.

### F. Final commit

`feat(tranche-j/w7): close ceremony + strengthened 6-agent post-close audit (canonical)`.
