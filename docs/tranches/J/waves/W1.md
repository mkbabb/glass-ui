### W1.5 — `cssVar()` composable utility (R5 gap row 8)

Add `src/composables/utils/cssVar.ts`:

```ts
/** Read a CSS custom property at runtime — for WAAPI consumers needing literal values. */
export function cssVar(name: string, root?: HTMLElement | null): string {
    const el = root ?? document.documentElement;
    return getComputedStyle(el).getPropertyValue(name).trim();
}
```

Re-export from `src/composables/utils/index.ts` and `src/composables/index.ts`.
