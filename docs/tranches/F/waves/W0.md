## Purpose

Turn the planning prelude into exact implementation bounds. W0 is read-only for product/source/config/consumer files and write-only for F audit/research/progress docs.

## Scope

Included:

- Audit current `HEAD`, dirty state, and consumer imports.
- Classify public exports, private/internal barrels, consumer drift, unsafe HTML, large components, composable/state risks, style/theme tokens, dock behavior/style authority, Aurora runtime/shader/studio drift, story substrate, and proof scripts.
- Update the W0 challenge with accepted/rejected claims.
- Amend W1-W5 with exact files, symbols, commands, and owner lanes.

Excluded:

- No implementation changes to source, styles, scripts, tests, package exports, demos, or consumers.
- No plugin extraction.
- No compatibility shim design.
- No Aurora visual expansion.
