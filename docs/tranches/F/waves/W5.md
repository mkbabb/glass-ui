# F.W5 - Aurora Runtime, Shader, And Studio Hardening

**Opens after**: F.W4 style authority proof passes
**Agents**: 4 lanes on disjoint Aurora library/studio responsibilities
**Hard gate**: public config matches live shader behavior; capture/live modes, oil flow, thumbnails, and studio splits are proved with runtime and benchmark evidence
**Status**: planned

## Purpose

Bring the Aurora background and oil-painting facility from "ported and impressive" to "small, correct, benchmarked, and extensible." F.W5 preserves the one-component/single-pass WebGL2 design unless evidence proves a different runtime is necessary.

## Scope

Included:

- Classify every public config field and uniform as live, intentionally inert, or delete.
- Fix or remove `brokenColor`, `uDpr`, `hueShift`, `mediumSmooth`, and aspect-path drift according to W0.
- Correct oil crosshatch/stroke flow so alternate flow inputs are actually consumed.
- Split live rendering from capture/thumbnail rendering if profiling supports avoiding `preserveDrawingBuffer` in live runtimes.
- Make `renderAt()` deterministic and side-effect-safe relative to the RAF loop.
- Keep the shared offscreen thumbnail context behavior if W0/W5 evidence confirms it is still needed.
- Split Aurora studio editor pieces into colocated subcomponents/composables only where it reduces coupling.
- Update stale Aurora docs and route paths.
- Benchmark smooth, pastel, watercolor, and oil media at W0-approved DPR/viewport settings.

Excluded:

- No WebGPU rewrite.
- No worker/OffscreenCanvas migration unless W5 proves live main-thread rendering is the bottleneck and support tradeoffs are acceptable.
- No new medium family before current modes are correct.
- No shader variant explosion unless benchmark evidence justifies it.

## Candidate Ownership

W0 must replace these candidates with exact files:

- Runtime lane: `src/components/custom/aurora/composables/runtime.ts`, `useAurora.ts`, capture/thumbnail runtime utilities.

- Studio lane: `demo/stories/aurora/**` editor, stage, picker, thumbnails, overlay.
- Docs/proof lane: `src/components/custom/aurora/DESIGN.md`, W5 benchmark/runtime artifacts.

## Required Artifacts

- `docs/tranches/F/audit/W5-aurora-runtime-proof.md`
- benchmark JSON for each W0-approved medium/DPR case
- nonblank canvas/runtime smoke artifacts for `/aurora`
- updated Aurora design docs
- updated `docs/tranches/F/PROGRESS.md`

## Hard Gate

- No public Aurora config field or uniform is silently dead.
- Oil `strokeLayers` behavior consumes the intended flow inputs.
- Live runtime does not pay capture-only costs unless W5 benchmark documents the tradeoff.
- Thumbnail capture remains deterministic and does not exhaust browser WebGL context limits.
- Aurora route has zero console/page errors and nonblank canvas proof.
