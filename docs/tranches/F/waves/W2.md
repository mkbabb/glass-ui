# F.W2 - Dock, Rail, Layering, And Navigation Substrate

**Opens after**: F.W1 proof substrate passes
**Agents**: 3-4 implementation lanes with orchestrator-owned shared style tokens
**Hard gate**: dock, rail, and dock-layer routes prove orientation, blur, layering, animation cleanup, and owned portals
**Status**: planned

## Purpose

Make the dock family robust as one substrate. The vertical rail remains a `GlassDock` variant, while `DockLayerGroup`, popovers, triggers, stories, blur tiers, and animation cleanup all consume one scoped contract.

## Scope

Included:

- Ensure `GlassDock variant="rail"` is the true vertical dock variant.
- Make `DockLayerGroup` inherit orientation from dock context unless a consumer explicitly overrides it.
- Replace arithmetic popover z-index with named token tiers.
- Replace hard-coded transition cleanup timing with CSS/runtime-derived duration and cancellation.
- Make click-away transition state real or remove the dead guard.
- Mark owned teleported portals with explicit data attributes instead of relying on Reka internals, roles, or broad class selectors.
- Prove the reduced dock blur token and rail visual tier.
- Update navigation stories that rebuild raw dock buttons instead of consuming the substrate.

Excluded:

- No broad navigation redesign.
- No heavy blur restoration.
- No global style consolidation beyond dock-owned requirements; broader style authority is W4.

## Candidate Ownership

W0 must replace these candidates with exact files:

- Dock runtime lane: `src/components/custom/dock/GlassDock.vue`, dock composables, context/registry files.
- Layer lane: `src/components/custom/dock/DockLayerGroup.vue`, `DockPopover.vue`, trigger/button files.
- Story lane: `demo/stories/navigation/**`.
- Token/style lane: dock token definitions and one W0-approved dock CSS authority.

## Hard Gate

- Runtime smoke has zero console/page errors on dock routes.
- Vertical rail and vertical layer groups remain vertical under interaction.
- Popovers layer by named tokens, not arithmetic inline constants.
- Transition cleanup has no stale timers or stuck interaction state.
- The reduced dock blur tier is named, consumed, and visually present in both horizontal and rail variants.
