# F.W3 - Component Contracts And Vue Idioms

**Opens after**: F.W2 dock substrate proof passes
**Agents**: 4-5 lanes on disjoint component families
**Hard gate**: unsafe HTML, stale search cache, row identity, lifecycle cleanup, and approved large splits are fixed and tested
**Status**: complete

## Purpose

Repair correctness and ownership issues in components and composables without broad API churn. F.W3 favors small, local, consumed refactors over a design-system rewrite.

## Scope

Included:

- Replace or explicitly trust/sanitize consumer-provided `v-html` boundaries.
- Make fuzzy search cache instance-scoped or source-version keyed; clean debounce/timer state on disposal.
- Split `FuzzySearch.vue` into input, results, modal, focus, and highlight units if W0 confirms the split reduces coupling.
- Require stable row identity in `DataTable.vue` through `getRowId`, explicit row key, or a deliberate development warning/fallback contract.
- Remove unused pagination/state props or wire them to real behavior.
- Ref-count body scroll lock and clean typewriter/timer effects.
- Split `AuroraConfigDock.vue` only as far as needed to make W5 studio hardening tractable.
- Remove empty custom directories or give them real consumed ownership.

Excluded:

- No mechanical split of every large component.
- No broad prop API unification across the library.
- No style restyling except where required by component ownership or safety.
