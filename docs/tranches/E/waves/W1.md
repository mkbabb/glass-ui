## Implementation Rules

- No permanent deprecation barrels, warning shims, fallback exports, or duplicate style paths.
- Root `@mkbabb/glass-ui` exports only the W0 core allowlist.
- Every public non-core symbol has exactly one package subpath.
- Every declared export has emitted JS and declaration targets.
- `@utils` is either supported as internal build infrastructure across configs or removed as leakage; W0 decides.
- `vite.iter.config.ts` must prove the same package-contract shape as the real build, minus expensive declaration work if W0 allows that distinction.
