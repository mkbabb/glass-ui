**Status**: complete

## Purpose

Migrate every known consumer to the E package contract in the same tranche. Consumer migration is not follow-up work; it is the proof that the publication contract is usable.

## Blocking Preconditions

- W1 package exports and style entry are implemented.
- W1 generated package artifacts and packed-package probe pass.
- `W0-consumer-imports.md` and `W0-style-ledger.md` name every import to migrate.

## Ownership

Use three parallel worker lanes with disjoint worktrees/directories:

| Lane | Consumer | Ownership |
|---|---|---|
| W2.A | `../fourier-analysis/web` | imports, styles, local build proof for this consumer |
| W2.B | `../words/frontend` | imports, styles, local build proof for this consumer |

## Implementation Rules

- Rewrite non-core root imports to the W0-approved subpaths.
- Rewrite glass-ui CSS imports to `@mkbabb/glass-ui/styles`.
- Remove retired imports; do not add aliases, local compatibility wrappers, or fallback imports.
- Preserve consumer-local behavior and formatting patterns.
- Any consumer import not in W0 ledgers is scope reveal; pause that lane and amend W0/W2 docs before editing it.

## Required Artifacts

- Updated consumer source files in the three owned directories.
- `docs/tranches/E/audit/W2-consumer-proof.md` recording commands and import grep results.
