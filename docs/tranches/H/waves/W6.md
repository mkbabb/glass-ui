# H.W6 — Close Ceremony + Post-Close Audit

**Opens after**: W2 + W3 + W4 + W5 close (W2/W3/W4/W5 run in parallel after W1).
**Agents**: 1 orchestrator + 4 audit lanes (post-close 4-agent pattern).
**Hard gate**: post-close audit returns; FINAL.md authored AFTER findings absorbed; LESSONS-LEARNED entries reconciled; orchestrator commits W6 close.
**Status**: in progress (4-agent post-close audit returned 2026-05-05; absorb in flight).

## Purpose

Honest close. Per H invariant 4: post-close audit runs BEFORE FINAL.md is final. This wave is the canonical instance of the new pattern (now binding per the W0 precept update).

## Steps

### A. Pre-close orchestrator pass

- Verify build / typecheck green at HEAD.
- Re-run β-style overfitting audit at HEAD; confirm zero remaining library-orphans.
- Re-run γ-style doc-drift audit at HEAD; confirm DESIGN.md has zero open W0.β rows.
- Verify every wave's commit landed (`git log --oneline tranche-h/w0..tranche-h/w5`).
- Verify every wave's PROGRESS.md status entry matches reality.
- Stage the close: write `audit/H-pre-close.md` listing every artefact's final disposition + commit hash + evidence-doc reference.

### B. Post-close audit (4 parallel lanes)

Per the binding precept (now in `tranche/SPEC.md`'s close criteria), run 4 read-only audit agents:

- **Lane α — plan-vs-actual**: walk every wave spec line-by-line against PROGRESS.md + close docs. Findings: silent additions, silent narrowing, hard-gate violations.
- **Lane β — substrate-without-consumer**: re-run the overfitting audit at HEAD post-W4. Findings: library-orphans that survived W1; new orphans introduced by W2-W5.
- **Lane γ — doc-drift**: walk DESIGN.md + PROGRESS.md + each wave-spec status line + CLAUDE.md against current source. Findings: misalignments, stale claims, undeclared brittleness windows.
- **Lane δ — idiomatic gestalt**: walk every refactor + new addition for KISS / one-path / single-authority violations. Findings: shim-like patterns, duplicate authority, recovery-diary leaks.

Each lane writes `docs/tranches/H/audit/H-audit-{α,β,γ,δ}-*.md`.

### C. Findings absorb

For every accepted finding from the 4 audits:

- **Doc-only fix**: orchestrator applies the fix in W6 (within-wave absorb).
- **Source fix**: open a residual entry in `audit/H-residuals.md` with named destination (most likely a small W6-residual pass before FINAL.md is final).
- **Gestalt fix**: same as source-fix.

If absorb requires substantive code changes, the wave splits: the absorb work becomes W6.W6-pre-close-fix, and FINAL.md is delayed until those changes land + the audit re-runs clean.

Per H invariant 4: FINAL.md is authored ONLY when the audit returns clean.

### D. FINAL.md authoring

After the 4-lane audit returns clean (or after absorb closes any open findings), write `docs/tranches/H/FINAL.md`:

- Tranche thesis, opening + closing date.
- Wave-by-wave table with status + commit hash + close evidence.
- Substrate convergence stats: how many G artefacts wired, retired, evidence-doc'd.
- Process hardening stats: precept files updated; lessons-learned entries added.
- Cross-tranche debt + named-destination residuals.
- Brittleness windows (none for H, expected).
- Authority — H closes clean.

### E. Lessons-learned reconciliation

If H surfaces any new process-failure incidents (e.g., a CI workflow failure in W5; a regression in W3's dock-keep-open refactor), append to `docs/precepts/instructions/LESSONS-LEARNED.md` per the format. Otherwise mark H as a clean tranche close (the four G lessons remain the latest entries).

### F. Final commit

Orchestrator commits W6 close: `feat(tranche-h/w6): close ceremony + post-close audit`. The commit includes FINAL.md + the 4 audit reports + any absorb fixes + the LESSONS-LEARNED reconciliation.
