# H.W1 — Wire-or-Retire Surface Trim

**Opens after**: W0 close.
**Agents**: 4-5 parallel lanes split by artefact category.
**Hard gate**: every library-orphan from `audit/W0-reconciliation.md` reaches a wire / retire / evidence-doc verdict; typecheck + build green; zero remaining library-orphans by H close; orchestrator commits W1 close.
**Status**: closed (commit `68e4097`).

## Purpose

Drive the substrate to honesty. Every G-shipped artefact must clear the `feedback_overfitting_audit` ≥2-call-site bar with **in-repo** evidence (story site + same-tranche consumer or two stories that exercise distinct shapes), OR carry a `docs/consumer-evidence/<artefact>.md` evidence doc, OR retire cleanly.

Per H invariant 2: **wire-or-retire is binary**. No projection-only keeps.

## Lane decomposition

The W0 reconciliation ledger groups artefacts into five disjoint families. Each lane owns its family's wire-or-retire decisions.

### Lane A — Custom components (orchestrator-coordinated triage)

For each of the 17 G custom packages, decide:

- **Wire**: ensure ≥1 in-repo story site exists AND a same-tranche or W4 second site exists. Authoring missing stories is in W4 scope; this lane only WIRES via existing artefacts (e.g., compose `<TierBadge>` inside an existing story like `containers/cream-card.vue`).
- **Retire**: delete the package directory + remove from `src/index.ts` + remove from `demo/stories/manifest.ts`. Audit does the same in lane B for composables, lane C for CVA branches, etc.
- **Evidence-doc**: create `docs/consumer-evidence/<artefact>.md` citing the consumer file:line + the `rg` invocation that confirms freshness. Only when the consumer's follow-up tranche is in progress.

Critical decisions per the G audit β findings:
- `<KeyboardShortcutsModal>` — single live consumer (E keyframes adjacency); β called it library-orphan. **Default**: retire unless a fresh evidence doc lands. Speedtest's prior `<KeyboardShortcutsModal>` equivalent is the second-site projection.
- `<TierBadge>` — fourier-analysis ledger projects 4 sites. **Default**: evidence-doc cite-fourier-ledger if fourier follow-up tranche has opened by W0 close; else retire.
- `<LikeButton>` — fourier-analysis ledger projects 2 sites. Same evaluation.
- `<PipelineFlow>` — bbnf-lang ledger projects 4 internal slots; W2 (G) added the missing CSS in pass-2. **Default**: evidence-doc cite-bbnf if bbnf follow-up has opened.
- `<LiveSnippet>` — bbnf-lang ledger projects 4 internal slots. Same.
- `<KeyframeTimeline>` family (4 components) — keyframes.js ledger projects 3 sites + math-paper composition consumes BezierCurveCanvas. The composition story IS a second site. **Default**: keep (in-repo evidence cleared).
- `<BezierCurveCanvas>` — same family; W4 motion/bezier-canvas story is the in-repo site. **Default**: keep.
- `<MathSurface>` / `<MathFormula>` / `<MathGlyph>` — math-paper composition consumes all three; foundations/golden-ratio + foundations/typography stories also consume. **Default**: keep (in-repo evidence cleared).
- `<CreamSurface>` / `<DisplayHero>` / `<FlourishDivider>` / `<IconStamp>` — foundations stories + audacious-hero composition + multiple ledger projections. **Default**: keep.
