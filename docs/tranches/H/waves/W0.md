## Purpose

Produce the load-bearing input for W1 (wire-or-retire) by running an honest β-style overfitting audit at HEAD, with consumer-evidence-doc evaluation per `feedback_overfitting_audit`'s Refined-D verdict precedence. Simultaneously promote G's four lessons-learned (no destructive git as recovery; commit at wave close; post-close audit before FINAL.md is final; run typecheck earlier in agent workflows) into the binding precept tree.

## Lane I — Reconciliation audit (read-only)

Re-run `docs/audits/overfitting-audit.md` against every G-shipped artefact. For each artefact:

1. Re-grep call sites in `src/` + `demo/` (the in-repo evidence path).
2. Check for a `docs/consumer-evidence/<artefact>.md` file. If present, run the file's cited proof grep against the named consumer to confirm freshness.
3. Apply the Refined-D verdict precedence:
   - `delete-unused` > `library-orphan` > `inline-and-remove` > `keep-current` > `demo-only-private` > `keep`
   - For `keep-current`: requires fresh consumer-evidence proof.
   - For `library-orphan`: zero in-repo + no fresh evidence doc.
4. Record verdict + W1 disposition (wire / retire / evidence-doc-required) per artefact.
