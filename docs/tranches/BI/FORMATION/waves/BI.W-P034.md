# BI.W-P034 — Dock public anatomy

Status: **done, pruned**.

The supported anatomy is `GlassDock`, `DockControl`, `DockTrigger`, `DockSeparator`,
`DockLayerGroup`, `DockLayer`, `DockCrossfade`, and `DockBackgroundToggle`.
`DockSection` and `DockStack` were demo-only concepts with no tracked consumers and are
removed. Semantic groups use ordinary DOM; facet selection composes the existing
dropdown family.
