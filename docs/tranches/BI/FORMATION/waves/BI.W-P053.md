# BI.W-P053 — Cross-engine perceptual parity matrix

**Status:** DECLINED
**Topological stratum:** BI.S18
**Terminal owner:** glass-ui

## Disposition

A persistent cross-browser parity matrix, evidence store, and mutation framework is not
authorized. Earlier authored-zero parity records demonstrated that such machinery can
certify its own prose without exercising the rendered product.

## Retained policy

- Shared CPU/color/math leaves keep focused analytic tests where a numeric contract is
  real and inexpensive.
- A dual-engine scene must keep one semantic configuration and honest runtime engine
  identity.
- Engine-specific setup failures remain explicit through P045.
- After a major renderer change, inspect the affected scene on the available engines
  using the native in-app browser. Record a concise human finding in the change
  handoff; do not create a permanent screenshot oracle.
- Constellation remains excluded because it is intentionally Canvas2D-only.

## Explicit non-work

- No Safari/Chrome evidence warehouse.
- No screenshot equality, hash, authored delta, generated parity JSON, mutation bite,
  capture receipt, or visual-runner expansion.
- No synthetic second renderer for a single-renderer component.
- No source changes are authorized by this declined wave.

## Reopening condition

Open a bounded scene-specific defect only when a real engine divergence is reproduced.
The reproduction must name the scene, config, engines, and visible or numeric defect;
it does not reopen a global matrix.
