# BI.W-P132 — refraction runtime

**Status:** DECLINED — ORPHANS PRUNED

No public `RefractionRoot`, renderer selector, frame graph, or dual-backend product is being created without a real consumer. The unimported `glass-refract.glsl.ts` and `glassShader.wgsl` shader authorities are deleted.

The existing `.glass-lens` CSS enhancement remains public and independent: it is a self-contained, progressively enhanced SVG-filter recipe over the ordinary blur material. Its baked displacement scale requires no shader runtime and unsupported engines retain the base glass material.
