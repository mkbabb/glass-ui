## 3 · The method — the convergent multiagent design loop (woven, binding)

Resolve the stated design problem completely: a specification and wave set at 100% convergence
that survives adversarial audit. Track partial progress; it counts only when it implies exactly
the resolution.

**Round zero — the portfolio.** A Fable agent mints genuinely orthogonal formulations of the
tranche (different architectural centers, decompositions, sequencing philosophies). Reject
rewordings posing as alternatives. Maintain an explicit registry of approach families; two
routes sharing a mechanism share a family.

**The pass** (each pass its own workflow; dissect and synthesize on each):
1. **RESEARCH** — up to 8 agents (batched 3 concurrent) across the tranche corpus, the codebase,
   the constellation, and the web. Early-round researchers get the task + family charter alone.
2. **SYNTHESIZE** — one agent distills into a cogent spec/plan; one spec per family while routes
   remain incompatible.
3. **PROTOTYPE** — a fleet test-implements against the spec (a prototype RUNS or is marked
   spec-only). For THIS tranche the crux prototype is the **DAG probe**: the full wave graph
   topologically sorted by a script that RUNS, emitting strata widths + the critical path.
4. **CRITIQUE** — an adversarial fleet against the failure-mode checklist: vacuous convergence,
   spec-cites-itself circularity, gates that cannot fail, the elegant-reduction trap, legacy
   aliases, masked fallbacks, unverified gestalt, consumer-less substrate, **and the two BI-local
   modes: the contrived wave (subject or acceptance not real) and the tail wave (an edge that
   exists only to sequence something last)**. Each item returns an earned convergence % + exact
   open gaps.
5. **AGGLOMERATE** — fold into the registry; advance/bank/block/retire each route; begin again.

**Portfolio management**: keep incompatible routes alive through multiple passes; cross-pollinate
only after independent development; blocked families reopen only on a genuinely new mechanism;
require concrete artifacts (running probes, measured numbers, named counterexamples).
