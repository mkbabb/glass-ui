## The defect / charge

The liquid-glass audit's convergent finding #1 (10 lanes agree, R1/R2 both [high]): glass-ui's 5-rung ladder is `blur()` + `saturate()` + oklab-tint + a uniform rim + a static centered specular disc — it never DISPLACES the backdrop, and the catch-light only tracks the cursor at the plate center. iOS-26's defining move — the single technique that separates "frosted glass" from "Liquid Glass" — is edge-**LENSING** (light bends + concentrates at the rim) UNIFIED with a motion-reactive edge GLINT (the rim brightens where light grazes). This wave closes both: the refractive DEPTH and the rim LIFE.

**§0 CORRECTION (re-grounded at HEAD — the audit's "no refraction" is half-stale).** HEAD already ships a refraction GARNISH (`src/styles/glass-refract.css`, AW.W23) — an `@supports (backdrop-filter: url(#glass-refract))`-gated `feImage → feDisplacementMap → feImage specular → feBlend screen` graph, data-URI-inline, re-homed onto `.glass-material.glass-refract` (`glass-refract.css:54-59`). So the AXIS exists and the `@supports` degrade-floor is correct. But it is HALF-built and the audit's spirit holds — three real gaps:

**(1) the displacement map is the CRUDE radial, not the squircle bevel-profile.** `glass-refract.css:46` bakes the map as a single `radialGradient` (`rgb(128,128,128)` center → `rgb(255,255,128)` at 100%) — a uniform radial bend, NOT Apple's edge-concentrated convex-squircle surface profile `⁴√(1-(1-x)⁴)` the file's OWN header comment (`:11-16`) documents as the intended recipe. The comment describes the squircle-via-Snell map; the baked asset is the placeholder radial. The lens reads as a soft uniform bulge, not the THIN-interior / STRONG-rim edge-concentrated refraction iOS uses (the cheapest convincing read — R1 "edge-concentrated refraction is the cheapest convincing read").

**(2) the lens `scale` is a HARDCODED literal — no `--glass-refract` axis, no press/morph swell.** `glass-refract.css:46` hardcodes `scale='28'` inside the data-URI; the AW.W23 header (`:36`) names the intent ("only the `scale` attr animates without rebuilding the map") but there is no `--glass-refract` token to drive it and nothing animates it. The audit's headline animation target — the `:active` lens-SWELL (the backdrop pinches under the press) coupled with the edge-specular brightening on ONE `--press-t` drive (R1 low-finding, "fold into W-LENSING") — is unbuilt.

**(3) the specular is a static centered DISC, not the motion-reactive EDGE glint; and the position write is a per-consumer opt-in.** `src/styles/glass/material.css:108-124` paints ONE `radial-gradient` catch-light at `(--specular-x, --specular-y)` — a tasteful CENTERED disc (R1 [high] finding 3). iOS-27's specular is an EDGE-RING that brightens where light grazes the rim, reading as glass THICKNESS; the current rim (`--glass-edge-light` uniform inset) and the disc are DECOUPLED. And the position write lives only in `useSpecularTracking` (`src/composables/glass/useSpecularTracking.ts`), hand-wired at exactly two call sites (`Card.vue`, `DockIconButton.vue`) — a bare glass `<Button>` hovers DEAD-CENTER (the same dead-gleam W-LIQUIDHOVER fixes at the tier root). This wave mints `useSpecularPointer` — the SHARED leaf that adds the EDGE-anchored glint (the angle-keyed rim sweep) on top of the position write — the leaf W-LIQUIDHOVER auto-arms at the tier root and W-BUTTON-GLASS wires onto the lit button register.

The fix is gestalt + idiomatic + non-fence-crossing: EVOLVE the existing `--glass-refract` garnish onto the real squircle bevel-profile + a typed `--glass-refract` axis driving the animatable `scale` (the press/morph swell), and MINT the edge-glint as a second specular `::after` layer riding the EXISTING `--specular-intensity` cohort + `plus-lighter` blend. The lens is an SVG filter (the GL-shader fence HOLDS — zero `aurora.frag`/`metaball.frag` edit); the refraction is DEPTH not hue (the warm-cream identity HOLDS — the displacement map carries no color, the specular core stays warm-cream `hsl(40 35% 92%)`); off-Chromium degrades to today's blur+tint (the no-workaround floor).
