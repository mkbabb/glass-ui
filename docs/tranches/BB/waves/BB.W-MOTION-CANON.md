The canon's PRINCIPLES are right; what is MISSING is three structural things the audit's animation-canon lane (R3) names:

**(1) the doctrine is SCATTERED — it lives in a token-file comment (`scheme-motion.css:153-180`), `transitions.css` recipes, and CLAUDE.md prose, but there is NO single artifact a wave can CITE as "the canon."** Every BB liquid-glass wave re-derives "which easing where" from first principles (the W-LIQUID dialect re-reconcile, every time). **(2) the compositor-only ban is a PRECEPT with no enforcement on the TRANSITION surface.** CLAUDE.md names the A'-3 layout-animation lesson (no animating width/padding/font-size) + the 60/120fps floor as house fences. **(3) `useLiquidFlex.sizeStyle` is a LATENT layout-animating path the doctrine must NAME.** `useLiquidFlex.sizeStyle` (`src/composables/motion/useLiquidFlex.ts:95`) writes a literal `width`/`height` px style object (`{ width: "Npx" }`).
