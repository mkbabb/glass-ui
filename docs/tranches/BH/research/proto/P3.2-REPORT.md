# BH P3.2 — FAIL-CLOSED REGEN GATE + SYMBOL-FIDELITY CHECK

Closes the C2 fail-OPEN blocker (open-item §4.1.2) that gated B2.1. The Pass-2 regen
prototype (`regen-exports.mjs`) defaulted any unclassified `ui`/`custom` dir to PUBLIC
via an INTERNAL deny-list — so a BG-added dir during the interleave would silently
auto-publish onto the 5.0.0 semver surface. This prototype makes the gate fail-CLOSED,
adds a symbol-fidelity existence check, and specs the re-baseline discipline.

Deliverable: `regen-exports-failclosed.mjs` (RAN — three cases) + `P3.2-REPORT.md`.
Artifacts: `failclosed-real-report.json`, `failclosed-inject-report.json`.

---

## 1. FAIL-CLOSED CLASSIFICATION — RAN, both cases

### The flaw (fail-OPEN)
`regen-exports.mjs:globComponentSubpaths()` walks every `ui`/`custom` dir and publishes
each one NOT in `INTERNAL_UI`/`INTERNAL_CUSTOM`. The default for a stranger dir is
PUBLIC. For a semver-bearing export surface the default must be the opposite: a dir the
classification has never seen is an ERROR, not a publish.

### The fix
Every dir is named in EXACTLY one bucket: **PUBLISH** | **INTERNAL** | **CURATED**.
The check walks disk and flags any dir absent from its tier's classification map
(`classifyTier` → `unclassified[]`). A non-empty `unclassified[]` is a HARD ERROR
(exit 1). Symmetric stale-detection (`stale[]`) reports a classified dir that vanished.

| tier        | disk | PUBLISH | INTERNAL | CURATED | unclassified | stale |
|-------------|------|---------|----------|---------|--------------|-------|
| ui          | 43   | 25      | 18       | 0       | 0            | 0     |
| custom      | 50   | 47      | 3        | 0       | 0            | 0     |
| composable  | 11   | 4       | 3        | 4       | 0            | 0     |

- **CURATED** is needed only on composables: `dark`/`keyboard`/`motion`/`sidebar` publish
  through the hand-curated `src/<name>.ts` flat barrel (the SCC-trap surfaces), NOT
  through their `composables/<name>/index.ts`. They are named so they are not flagged
  unclassified, but their dir-index does NOT become a subpath.
- The regen is now driven by the explicit **PUBLISH** set (25 ui + 47 custom = 72
  component dirs), NOT a deny-list.

### RUN evidence
| run | command | result | exit |
|-----|---------|--------|------|
| REAL | `node regen-exports-failclosed.mjs` | every dir classified; 90 sources fidelity-OK; regen 96/96 keys, 89 subpaths, **EXACT REPRODUCTION YES** | **0** |
| INJECT | `… --inject-unclassified` | phantom `ui/zzz-bg-added-unclassified` (an emulated BG-added dir) → `FAIL-CLOSED CHECK: FAIL`, **HARD ERROR** | **1** |
| BITE | `… --break-fidelity` | a vanished hand-mapped source flagged ABSENT | **1** |

The INJECT phantom is appended to the in-memory dir list — **no real dir created**
(read-only on the repo, honoring the foreign-tree fence). It proves the exact interleave
threat: a dir that appears mid-tranche cannot ride onto the public surface unseen.

The fail-closed PASS still reproduces `package.json` byte-for-byte
(`drops:0 adds:0 targetMismatch:0 tvDrops:0 tvAdds:0`), proving the explicit
classification is a faithful re-expression of the proven deny-list surface — a safety
change, not a behaviour change.

## 2. SYMBOL-FIDELITY EXISTENCE CHECK — RAN

P1 proved export **KEYS** (96/96) + chunk **TARGETS** (`./dist/<name>.js`). It did NOT
prove each colocated `index.ts` re-exports the **identical symbol set** the deleted
`src/subpaths/` mirror did. The gate now closes the EXISTENCE half:

- For all **18 hand-mapped sources** (11 CURATED + 7 COMPOSABLE_SUBPATHS) AND every
  **72 globbed PUBLISH barrel** — assert the file EXISTS and is NON-EMPTY (`statSync`
  size > 0). Total 90 sources checked, 0 failed on the real tree.
- The `--break-fidelity` bite points one hand-mapped source at a deleted path and the
  check ERRORs (exit 1) — the teeth are demonstrated, not asserted.

### The two-layer fidelity contract (existence-gate vs symbol-set-build)
The existence gate is necessary-but-not-sufficient. A barrel that EXISTS but re-exports
the WRONG symbol set (e.g. a carve renamed `useFoo`→`useFooBar` and the colocated index
forgot to re-export the old name, OR a `export type *` lost a symbol) passes the gate and
**FAILS the build**. The BINDING symbol-set proof is **`verify-export-types` post-BUILD**:

1. `npm run build` → `vite build` emits `dist/<name>.js` + per-subpath dts; `emit-types`
   (`vue-tsc --project tsconfig.build.json`) emits the colocated dts; the re-authored
   `flatten-subpath-types.mjs` (B2.1 / §3.4) flattens the NEW colocated emit map to flat
   `dist/<name>.d.ts`.
2. `npm run verify-export-types` resolves EVERY published subpath (`import("@mkbabb/glass-ui/<sp>")`
   + a `tsc` consumer-probe per the L.W0 Lane III clause). A colocated barrel that dropped
   a symbol the consumer-probe imports REDs HERE — this is where the symbol SET is proven,
   on the actually-built artifact, not a static read.
3. `tests/public-surface.spec.ts` (rewritten in B2.1 as the export-reshape binding test —
   §3.2) hard-imports the new colocated surface and asserts the enumerated symbol set
   present — the no-silent-vanish proof at the source level.

**Division of labor (recorded fence):** the gate proves the barrel is THERE (cheap,
static, fail-fast, concurrent-safe); the build proves the SYMBOL SET is faithful (binding,
post-build, on the real dist). Neither alone is sufficient; the gate fails fast on a
deleted barrel before the ~7s build, the build catches a symbol-set drift the static
existence check structurally cannot see.

## 3. RE-BASELINE DISCIPLINE — the spec

The fail-closed classification and the `proof:subpath-enumeration` baseline are
**snapshots of a surface**. The surface MOVES during the BG interleave. Re-baselining
against the 4.2.0 surface (what P1 reproduced) would bake in a stale set and re-open the
exact fail-OPEN class for the BG deltas. The discipline:

### 3.1 Re-baseline AFTER WS12, never against 4.2.0
- **WS6 adds +2 siri subpaths** (the siri glob-add in `vite.library.ts`, SYNTHESIS §1.7 /
  B2.1). Two new PUBLISH dirs land → two new classification entries owed.
- **WS5 deletes/renames viz subpaths** (the viz-subpath deletes/renames, SYNTHESIS §1.7 /
  B2.1). Deleted dirs must move PUBLISH→(absent) and drop from the classification; renamed
  dirs change their PUBLISH key.
- The classification maps + the `proof:subpath-enumeration` baseline therefore re-run in
  the **single post-WS12 gates pass** (SYNTHESIS §2 B2.1: "the GLOB-SWAP runs after WS12
  … the LANDED surface, not the 4.2.0 surface P1 reproduced"). WS12 = BG full close
  (SYNTHESIS §1.8) — the first point the surface is final.

### 3.2 The re-baseline procedure (mechanical)
1. Re-run `regen-exports-failclosed.mjs` against the post-WS12 tree. Any BG-added dir
   surfaces as `unclassified` → the wave-author CLASSIFIES it (PUBLISH for the 2 siri
   subpaths; absent for the WS5-deleted viz dirs) — the fail-closed gate FORCES the
   decision, it cannot be skipped.
2. Re-run with `--inject-unclassified` to confirm the bite still fires on the new tree.
3. Regen `package.json` exports/typesVersions from the new PUBLISH set; the diff vs the
   pre-reshape `package.json` is the **5.0.0 export delta** — the +2 siri adds, the WS5
   viz drops/renames, and the one deliberate `./api` fold (B2.2). Every non-`./api` delta
   must be a BG-landed surface change (cross-checked against the WS5/WS6 wave specs), not a
   classification slip.
4. Re-pin `proof:subpath-enumeration` baseline to the new count (89 → 89+2 siri − N viz
   ± renames − 1 api). The gate's stale prose figure ("72-76") is superseded by the
   machine count (SYNTHESIS §1.1).
5. Re-emit `ci.yml` (`npm run gates:emit-ci`) + assert `proof:gen-ci-fresh` GREEN (§3.3) —
   the count change touches the gate roster.

### 3.3 Fail-closed as a STANDING gate, not a one-shot
The classification check becomes a registered gate (`proof:subpath-classify` or folded
into `proof:subpath-enumeration`), `["ci","release"]`-tagged, so that AFTER the 5.0.0 cut
a future agent adding a `ui`/`custom` dir without classifying it REDs the build — the
fail-OPEN class is closed permanently, not just for the interleave. The self-test bite
(the synthetic unclassified phantom + the missing-source phantom) lands with it.
