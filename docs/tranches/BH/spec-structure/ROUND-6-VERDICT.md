The camel-segment form was proto-3's proposed fix.

2. **G9 audits the wrong tree for a polyglot repo.** Verified live: sci-report root has BOTH `pyproject.toml` + `package.json`; no `src/` → first-manifest `detectLang`=python, `sourceRoot`=`app/` (the Vue FE) → G9 flags `app/views/{DashboardView,GalleryView}.vue` as Python backend scatter, condemning the exact `app/views/` layer §4P.2 sanctifies, while the real 400-file `tools/` Python backend goes unaudited.
