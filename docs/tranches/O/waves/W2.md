## Purpose

Per Rδ dock-subsystem audit + invariant 25 (NEW @ O):

The dock subsystem currently uses 6 provide/inject keys with 3 different idioms:
- Some are typed `InjectionKey<T>` (1 of 6).
- Some are string-keyed (5 of 6).
- The "throw vs silent default" pattern inconsistent.

5 consumer sites reach into the inject tree directly without the canonical-helper shape: Slider, HoverPopover, PopoverContent, SelectContent, DropdownMenuContent.

Rδ proposes:

- Consolidate 6 keys → 1 typed context (`InjectionKey<DockContext>`) + module-local `keys.ts` / `context.ts`.
- Paired helpers `useDockContext()` (strict—throws when used outside `<GlassDock>`) AND `useOptionalDockContext()` (befitting silent default for primitives that may render OUTSIDE a dock).
- Retire `dockExpanded` (zero consumers per Rδ + speedtest verification at O11/f).
- Dedup `glassDockId` with `glassDockContext.id`.

## Lane A—Dock typed-context + helper-pair canonicalization

Author `src/components/custom/dock/context.ts` (or `keys.ts`):

```ts
import type { InjectionKey, ComputedRef } from "vue";

export interface DockContext {
    id: string;
    keepOpen: () => void;
    release: () => void;
    held: ComputedRef<boolean>;
    // ... other current dock-state fields surfaced as needed
}

export const DOCK_CONTEXT_KEY: InjectionKey<DockContext> = Symbol("dock-context");

export function useDockContext(): DockContext {
    const ctx = inject(DOCK_CONTEXT_KEY);
    if (!ctx) throw new Error("[glass-ui:dock] useDockContext() called outside <GlassDock>");
    return ctx;
}

export function useOptionalDockContext(): DockContext | null {
    return inject(DOCK_CONTEXT_KEY, null);
}
```

Update `GlassDock.vue` to `provide(DOCK_CONTEXT_KEY, ctx)`—single provide call replacing 6 prior keys.
