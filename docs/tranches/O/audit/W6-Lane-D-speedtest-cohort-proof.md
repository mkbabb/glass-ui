### Q3—`--chart-jitter-label` (orchestrator decision)

AC.W6c.T2 only spec'd 3 companion tokens (`--chart-ping-label`,
`--chart-download-label`, `--chart-upload-label`). Lane D shipped a 4th
(`--chart-jitter-label`) for symmetry—every `--chart-{phase}` rung
gets a label companion, no holes in the surface. Orchestrator decides
if this is over-shipping or correct surface symmetry. **Recommendation:
keep—F1.V-04 audit cites `--chart-jitter` as having less stringent
contrast asks, but the symmetry win is worth ~1 LOC and downstream
consumers using `jitter` for labels get the same WCAG floor.**

### Q4—OKLCH values for label tokens

Lane D picked OKLCH coordinates that approximate L≈0.40 (light) /
L≈0.85 (dark) at hue-rotations matching the canvas-side tokens:

- ping ≈ chebyshev blue (h=230)
- download ≈ fourier red (h=22)
- upload ≈ legendre purple (h=305)
- jitter ≈ amber (h=55)

The exact OKLCH calibration to clear WCAG 4.5:1 against `--background`
needs Playwright + a contrast-tool verification at integration. **The
values are reasonable approximations; the orchestrator may tune at AC
W6c close per the actual WCAG measurement step.** This is the explicit
AC.W6c soft-halt: "If T2 WCAG calculation surfaces a phase color that
CAN'T reach AA-body contrast at any reasonable L, escalate."

### Q5—`--dock-touch-target` naming

Lane D introduced `--dock-touch-target` as the dedicated knob for the
`@media (pointer: coarse)` lift. AC.W6d.T2 spec'd `--dock-control-size`
directly. The Lane D shape uses both: the media query sets
`--dock-control-size: var(--dock-touch-target, 2.75rem)`. This adds an
indirection but preserves the canonical `--dock-control-size` knob's
flexibility (consumers can still override per-instance). Orchestrator
decides if the indirection stays or collapses to direct
`--dock-control-size: 44px`.
