### L08-07 / L08-08 / L08-09 / L08-24 — contrast by paint

Method (`contrast.mjs`): for each visible text run, parse the computed ink through a detached 2D canvas (never a live GL canvas); screenshot the page with `*{color:transparent!important;…}`; take the median background pixel under the run's client rects; blend the ink alpha (including ancestor opacity); score against 4.5 (3.0 at ≥24 px, or ≥18.66 px bold). Disabled, `sr-only`, `code`/`pre` and svg text excluded. Three scroll pages of `<main>` per route.
```
checked 9671 fails 1501
 716 routes=76 light fg(124,102,80) median cr 4.35 min 1.33        <- --neutral-5 page-muted
 344 routes=41 light fg(112,89,66) median cr 4.05 min 1.75         <- --on-glass-muted
 103 routes=15 dark fg(172,160,145) median cr 2.41 min 1.7         <- dark page-muted where the on-glass re-point never reaches
routes with >=1 non-hidden fail: light 86 dark 24
```
Ground truth versus token (`bgtok.mjs`, `/foundations/colors`, a bare-page pixel):
```
light token --background = (light-dark() expression) | rendered ground sample @(1190,310) = 246,231,224
dark  token --background = 11,10,9  | --muted-foreground = 172,160,145 | rendered ground sample @(1190,310) = 25,17,15
```
`--neutral-0` = `hsl(40 30% 98%)` = rgb(251,250,248), so rgb(124,102,80) scores 5.20:1 against it, matching the comment's 5.21. Against the painted ground rgb(246,231,214) it scores 4.47:1. The page-chrome breadcrumb ("← Section", `text-small text-muted-foreground`) fails on 69 routes at 4.35-4.47. The gate's §5 table checks `claim: "5.21:1 vs page", surface: "var(--background)"` (`contrast-computed.test.ts:632-638`), and its header concedes a backdrop-filtered plate "is a paint measurement" it does not perform (line 28).
