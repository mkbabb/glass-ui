## Classification rule (N-1 applied)

- **GLOBAL**: transitive src importers span 2 or more unrelated families, OR the module is a public entry with import-statement evidence of an external consumer (module API).
- **OWNED**: exactly one component or one family reaches it. An OWNED module under `src/composables/` violates N-1 where it sits, whether or not it also has a public door.
- **PUBLIC-no-reader**: public door, zero src importers, zero sibling import statements. N-1 cannot place it without a consumer; see L13-14.
- Stylesheets: TOKEN/THEME (custom properties, `@theme`, `@property`), AGGREGATOR (thin `@import` roots), GLOBAL register/utility (2+ families, or consumer-used public classes), FAMILY-OWNED (one family, no family dir), COMPONENT-OWNED (one component), MIXED (a global file carrying a component-owned section).
- Caveat on sibling evidence: only chicago pins `^10.0.1` (and chicago imports zero composables). The others pin 3.x–8.x (speedtest `^4.0.1`, keyframes.js `7.0.0`, value.js `^7.0.0`, atlas `6.0.0`, fourier-analysis/web `^8.0.0`, muster/frontend `^3.1.0`, bbnf-lang/playground `^3.0.0`, sci-report/dashboards `7.0.0`, slides `3.13.0`).
