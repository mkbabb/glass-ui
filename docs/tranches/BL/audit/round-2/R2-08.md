## Evidence

### R2-08-01—reduced transparency lifts the field

The a11y arm, `src/components/aurora/Aurora.vue:251-255` and `:333-341`:

```css
.aurora-root { opacity: var(--aurora-ceiling-a11y, var(--aurora-ceiling, 1)); … }
/* … Honest scope: a default aurora already presents opaque, so this bites only where
   a consumer set `opacityCeiling < 1`. */
@media (prefers-reduced-transparency: reduce) {
    .aurora-root { --aurora-ceiling-a11y: 1; }
}
```

The repo's own consumer sets a ceiling below 1 on every route: the shell field `demo/shell/AppShell.vue:229` `:opacity-ceiling="0.5"` ("recedes it behind the page glass", `:223`), the dock stages `demo/stories/dock/_frame/DockStage.vue:47` `opacityCeiling: 0.55`, and every hero `demo/chassis/hero/StoryHero.vue:64` (default 0.6). A user who asks for less transparency, to read better, gets the chromatic field at double presence under the page text.
