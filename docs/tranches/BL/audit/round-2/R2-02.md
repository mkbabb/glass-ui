- **Lens**: motion over time. Targets F-16, F-43, F-44, F-45, F-46; O-60 (33 rows); N-8; N-10.
- **Model**: `claude-opus-5-5` (asserted from system identity).

- **Instrument**: Playwright 1.61.1 Chromium, `--use-gl=angle --use-angle=metal --enable-unsafe-webgpu --ignore-gpu-blocklist` (renderer `ANGLE Metal Renderer: Apple M5 Max`). Headless rAF runs at **120 Hz** (median 8.3 ms); headed runs at **60 Hz** (median 16.7 ms), so every "60 Hz" leg below is a headed run. - **Load caveat**: load average about 90 through the whole run. Frame-gap claims were re-run (3x) before being kept; screencast strips are sparse under this load, so geometry claims rest on the per-rAF logger and on seeks, with the strips as the visual record.
- **Examined**: all 33 O-60 rows; dock first expand, expand, collapse, vertical morph, layer swap, seat hover/press; Select, DropdownMenu, Sheet (right, bottom), Dialog open/close; route push, popstate back/forward; dark-mode swap; segmented-tab indicator; deck slide; skeleton; scroll chrome; the six `--spring-*` `linear()` tails. ### Wave shapes

- **W-DOCK-EXTENT** (F-16's wave; R2-02-01, -02, -03, -05, -06, -07). Measure the expanded endpoint from the row's intrinsic extent, never from an out-of-flow layer. Morph the real extent (the plate's `clip-path: inset()` with a true radius, or the inline size of one wrapper) in place of the `scale: s 1` squash and its counter-scale. Anchor both faces to the plate (its centre or one edge) and clip the layers to the live plate. Clear `data-morphing` when the extent lands (|1 − t| < ε), not when the spring's numeric settle fires. - **W-SHEET-BLEED** (R2-02-10, after W-SURFACE-GEOMETRY lands R2-02-12). The overshoot stays attached to the anchored edge: stretch from that edge, or give the panel an off-edge bleed of at least the peak overshoot.

## Evidence

### R2-02-01: the poisoned first expand

Mechanism, at the bytes. `GlassDock.vue:195-202` registers `useDockExpandedSize` before the orchestrator (`:218`), so its `watch(expanded, () => capture("flip"))` (`dockMorphMeasure.ts:132`) runs first on the flip, before `data-morphing` is set and before the DOM updates. At that moment the full layer is inactive, and `layers.css:233-236` makes an inactive layer `position: absolute; inset: 0`, so `offsetWidth` of the full layer is the root's padding box, not the row. With `expandedPx` still 0 (never laid out expanded), `dockMorphMeasure.ts:92-101` computes `chrome = rootSize − fullSize = 0` and `expandedEndpoint = 0 || chrome + fullSize = rootSize`, and writes `--dock-expanded-px` equal to `--dock-collapsed-px`. The spring then interpolates between two equal endpoints. The comment at `dockMorphMeasure.ts:82-83` states the premise the cure rests on ("the inactive pane stays laid out under `visibility`"); `layers.css:233-236` makes it false. The pre-flip value is the same fallback at mount: the demo summary is empty (0 px), so chrome = 56 and epx = 112; the harness summary is 40 px, so epx = 72.

```
dock                       pre-flip epx  flip epx  morph extents  settled  morph ms
demo "Starts compact"      112px         56px      [56]           227      546 (light 120) / 540 (dark 120) / 547 (light 60)
demo "Consumer-driven"     164px         102px     [102]          227      539 (light) / 578 (dark)
demo vertical compact      186px         110px     [110]          321      539 (light) / 545 (dark)
harness chrome (556 row)   72px          56px      [56]           556      591
```

Per-rAF trace, demo light 120 Hz (`dock_overview__Starts-light-120/trace.json`): rows 10-70 `EM w=56 epx=56px`, `mt` 0 → 1.0030 → 1.00002; row 71 `E w=227 x=339.5`. The same shape in dark 120 Hz (rows 9-71) and headed 60 Hz (rows 4-37), each a 171 px jump in one frame. The visible frames: the pill holds with only the persistent Home for ~550 ms, then the full dock appears in one frame (`strip-first-expand.jpg`). Every dock mounted collapsed has this on its first expand. The code comment at `GlassDock.vue:191-194` records an "endpoint-poisoning cure" in `dockMorphMeasure`; the flip branch is still poisoned.
