## 2 · The defect at HEAD

`seedField(rng, count, w, h, speed)` (`constellationField.ts:49-73`) draws, for each node, `a`, `x`, `y`, `r`, `dim` and then `z`: six draws where 3.13.0 drew five (`v3.13.0:src/components/custom/constellation/constellationField.ts:426-433`). Every node after the first therefore reads its values from a shifted position in the stream. The caller's `rng` is the seed's `mulberry32` (`composables/useConstellation.ts:112-115`), and the same stream then feeds `stepField`'s wander and pinned-drift draws (`:390-399`), so the shift carries into the motion as well. slides lays its ambient field with `seedField` and its own seeded `mulberry32` for a byte-stable capture (`slides/src/decks/til-briefing/constellation.ts:30-31,79-83`), which is how the drift was seen.

## 3 · The cure

`seedField` draws the five main values in the 3.13.0 order and nothing else. It then seeds a depth stream from the bits of its own last main draw, and fills `z` from that stream:

```ts
const nodes: ConstellationNode[] = [];
let last = 0;
for (let i = 0; i < count; i++) {
    const a = rng() * Math.PI * 2;
    const x = rng() * w;
    const y = rng() * h;
    const r = NODE_R_MIN + rng() * NODE_R_SPREAD;
    last = rng();
    nodes.push({ x, y, vx: Math.cos(a) * speed, vy: Math.sin(a) * speed, r, dim: last < 0.45, z: 0 });
}
const depth = mulberry32(Math.floor(last * 4294967296));
for (const p of nodes) p.z = depth();
```

- **Why a derived stream.** `seedField` receives an opaque `() => number` and no seed, so it cannot fork the caller's stream without drawing from it. Seeding the depth stream from a value the 3.13.0 sequence already drew costs no draw. It is deterministic under a seed, since the same seed gives the same last draw, and it varies between seeds. With `Math.random` as `rng` it is random, as before. The caller's stream then continues exactly where 3.13.0's did, so `stepField`'s wander and pinned-drift draws line up again too.
- **No signature change.** `seedField` is exported (`constellation/index.ts:4`). Adding a depth-`rng` parameter would change a published signature, and a defaulted one would be a second path. The derived stream needs neither.
- **The PRNG leaf.** `mulberry32` comes from the one leaf (`composables/glass/procedural/prng.ts:7`), as `useConstellation.ts:12` already imports it. No second generator is minted.
- **`r`.** `NODE_R_MIN + rng() * NODE_R_SPREAD` is `1.6 + rng() * 1.6` (`constants.ts:124-125`), the 3.13.0 expression, so the radius band is unchanged.

A prototype of exactly this change was built in the scratch worktree. The gate file passes 4 of 4, and the existing constellation tests still pass (3 files, 48 tests).

## Appendix A · the gate file

`tests/components/custom/constellation/seedField.draw-order.test.ts`:

```ts
// The seeded layout contract: seedField draws a, x, y, r, dim per node from the caller's
// rng, in that order and nothing else (the 3.13.0 sequence), so a seed lays out the same
// field it laid out then. Parallax depth z comes from its own stream.
import { describe, expect, it } from "vitest";
import { seedField } from "@glass/components/constellation/constellationField";
import { NODE_R_MIN, NODE_R_SPREAD } from "@glass/components/constellation/constants";
import { mulberry32 } from "@glass/composables/glass/procedural/prng";

const N = 12, W = 1000, H = 600, SPEED = 0.16;

function recording(seed: number) {
    const src = mulberry32(seed);
    const draws: number[] = [];
    return { draws, rng: () => { const v = src(); draws.push(v); return v; } };
}

describe("seedField draw order (the seeded layout contract)", () => {
    it("draws exactly five main values per node", () => {
        const { draws, rng } = recording(42);
        seedField(rng, N, W, H, SPEED);
        expect(draws.length).toBe(5 * N);
    });

    it("maps draw 5i..5i+4 onto node i as a, x, y, r, dim", () => {
        const { draws, rng } = recording(42);
        const nodes = seedField(rng, N, W, H, SPEED);
        nodes.forEach((p, i) => {
            const [a, x, y, r, d] = draws.slice(5 * i, 5 * i + 5);
            expect(p.vx).toBeCloseTo(Math.cos(a * Math.PI * 2) * SPEED, 12);
            expect(p.vy).toBeCloseTo(Math.sin(a * Math.PI * 2) * SPEED, 12);
            expect(p.x).toBe(x * W);
            expect(p.y).toBe(y * H);
            expect(p.r).toBe(NODE_R_MIN + r * NODE_R_SPREAD);
            expect(p.dim).toBe(d < 0.45);
        });
    });

    it("pins the first three nodes of seed 42", () => {
        const nodes = seedField(mulberry32(42), N, W, H, SPEED);
        const g = mulberry32(42);
        for (let i = 0; i < 3; i++) {
            g(); const x = g() * W, y = g() * H; g(); g();
            expect([nodes[i].x, nodes[i].y]).toEqual([x, y]);
        }
    });

    it("gives z its own seeded stream in [0, 1)", () => {
        const a = seedField(mulberry32(42), N, W, H, SPEED).map((p) => p.z);
        const b = seedField(mulberry32(42), N, W, H, SPEED).map((p) => p.z);
        const c = seedField(mulberry32(43), N, W, H, SPEED).map((p) => p.z);
        expect(a).toEqual(b);
        expect(a).not.toEqual(c);
        expect(a.every((z) => z >= 0 && z < 1)).toBe(true);
        expect(new Set(a).size).toBe(N);
    });
});
```
