## 2 · The defect at HEAD

`.toggle-group__item[data-state="on"]` paints `color-mix(in oklab, var(--foreground) 12%, transparent)`, ink `var(--foreground)` and weight 600, with a 16 % hover (`src/components/toggle-group/styles.css:116-124`). Its edge is `.glass-control-edge`'s box-shadow stack, read from `--control-edge-ring` (`src/styles/glass/control-edge.css:53-59`). No rule reads a per-item colour, so a consumer can restore the pressed fill and ink through `class` (fourier does, `BasisSelector.vue:222-227`) but not the edge, which glass owns. `grep -rn "toggle-tint" src` returns nothing.

## 3 · The cure

The pressed rule reads one optional per-item input, `--toggle-tint`, through three `color-mix()` sites. The neutral state is that input's default:

```css
.toggle-group__item[data-state="on"] {
    --control-edge-ring: 0 0 0 1px color-mix(in oklab, var(--toggle-tint, var(--foreground)) 40%, transparent);
    background-color: color-mix(in oklab, var(--toggle-tint, var(--foreground)) 12%, transparent);
    color: color-mix(in oklab, var(--toggle-tint, var(--foreground)) 60%, var(--foreground));
    font-weight: 600;
}
.toggle-group__item[data-state="on"]:hover:not(:disabled) {
    background-color: color-mix(in oklab, var(--toggle-tint, var(--foreground)) 16%, transparent);
}
```

- **One path.** With no tint set, `var(--toggle-tint, var(--foreground))` resolves every mix to today's value. The fill and hover are byte-identical to HEAD, the ink is `--foreground`, and the edge gains a 40 % foreground ring. That fallback is a token default for an optional input, not a literal fallback masking a dead primary (E-2, F-64), so there is no second code path.
- **Where the tint lives.** It is set per item (inline style or a consumer class on the item). It is not declared on `.toggle-group__item`, so a consumer may also set it once on the group and the items inherit it.
- **Where the edge lives.** The edge is the one slot `.glass-control-edge` already reads (`--control-edge-ring`), so no new shadow layer is minted and the focus ring's precedence is unchanged.
- **The numbers.** The ink mix is 60 % tint over the foreground, and the edge is a 1 px ring at 40 %, which is fourier's own pressed border. Both are held by G1's contrast floor, not by eye. The 12 % and 16 % fills are HEAD's own neutral values, kept so the neutral state does not move.
- **The forced-colours arm** (`styles.css:151-155`) is unchanged: `Highlight` wins, and a tint is not a system colour.

A prototype of exactly this rule was built in a scratch worktree. G1 then read PASS on 11 of 12 rows over HEAD's grey plate. The one FAIL is chebyshev in Chromium light, with a fill shift of 0.0099 against the 0.01 floor: the warm grey plate cancels the blue tint, which is O-62's grey again. That is why this wave is measured on W-0.1's plate and rides only if W-0.1 has converged. If G1 is not green on W-0.1's plate, W-0.2 does not ship in 10.2.0. It then lands with W-H.1 at 11.0.0 under the same gate, and no second mix is minted for it.
