# W-0.13: the demo site at glass.babb.dev

The source is the owner's order of 2026-11-09, verbatim: "we should plan to deploy the site to glass.babb.dev, too. Mark." (INBOUND O-192.)

glass-ui's demo has no public home today. `npm run demo:dist:build` writes `dist-demo/` (base `/`, deep SPA routes), and nothing ships it. `docs/precepts/infra/domains.md` and `deploy.md` describe sudoku.babb.dev rather than glass, which is a stray copy, so this wave rewrites both for glass.

## Scope

- **Host.** A Cloudflare Pages project `glass` serves `dist-demo/`, and `glass.babb.dev` is a proxied CNAME to it on the babb.dev zone, covered by Universal SSL. An SPA fallback (`_redirects`: `/* /index.html 200`) keeps deep routes working, and `_headers` sets a CSP built from what `dist-demo/` actually requests.
- **When it ships.** The site tracks the published package. The release workflow deploys the demo after a successful `npm publish` on a `v*` tag, so the site never shows unpublished work. A prerelease or a `--tag v10` maintenance publish does not deploy. The token is a repo secret `CLOUDFLARE_API_TOKEN` scoped to Pages edit on the babb.dev account; until the secret exists, the owner-side `npm run deploy:demo` (`npm run demo:dist:build && wrangler pages deploy dist-demo --project-name glass --branch main`) is the path.
- **Records.** `docs/precepts/infra/domains.md` and `deploy.md` become glass's: the host, the project, the deploy trigger, the rollback (redeploy the prior tag's tree), and the secret's scope.

## Gates

- `https://glass.babb.dev/` and one deep route each return 200 with the built index, and every asset they request resolves (no 404 in the network log), in headless Chromium and WebKit at 390 and 1440.
- The served build's version string equals the npm `latest`.
- `git grep -n sudoku -- docs/precepts/infra` returns nothing.
