## 3 · The cure

### 3.1 The cap rest is a length

`dockMorphMeasure` (`dock/composables/dockMorphMeasure.ts:98`, which already publishes `--dock-collapsed-px`) publishes the plate's measured cross size beside it, `--dock-plate-cross-px` (block size for a horizontal dock, inline size for a vertical one). The pill's rest reads it:

```css
.glass-dock { --dock-cap-rest: calc(var(--dock-plate-cross-px) / 2); }
```

The rounded and card shapes keep their named rests (`run.css:471-479`), which are lengths already. The keyframes (`run.css:557-598`) are unchanged: they read `--dock-cap-rest` and `--dock-cap-cut`, both lengths now, so every corner stays circular at every point of the run. The `run.css:448-452` comment is rewritten to state the length.

### 3.2 The two rulings

- **Engagement.** The cap keeps HEAD's engagement: it runs whenever the run overflows. A threshold of one pitch changes when the cut appears, which is a D2 subject (the cut cap itself is under D2's Q-1, and W-I.1 G11 deletes it if Q-1 (a) converges). This wave fixes only the shape.
- **Collapsed.** A collapsed dock renders the summary, not the run, so the cap does not apply. G1 gains a collapsed row that holds all four corners circular.

### 3.3 The summary keeps its floor and loses its square

In `morph.css:180-198`, `.glass-dock .dock-layer--summary` keeps `min-width` and `min-block-size` at `--dock-collapsed-summary-min-size` and drops `block-size`, `height` and `aspect-ratio: 1`. An icon-only summary is still the floor square (the floor is the size); wider content widens the plate. The comment block at `:170-179` is rewritten.

### 3.4 The metric value is content-sized

`.metric__value` drops `min-inline-size: 3ch` and `overflow-wrap: anywhere`; `.metric__label` (`:42`) drops `overflow-wrap: anywhere` for `overflow-wrap: break-word`, which breaks only a word longer than its line. `tabular-nums lining-nums` (`:72`, `:100`) stay, so a changing value keeps its digit advance.
