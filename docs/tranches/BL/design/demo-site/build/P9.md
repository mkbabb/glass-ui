## Library faults met (none patched)

- **F3, muted ink in light.** `TableCaption` ("Recent invoices") and Metric's labels and units are `--muted-foreground` by the library. DataTable's card-projection field names ("Author", "Year") read muted too. The empty Metric value is muted by `[data-empty]`.
- **New: DataTable paints the wrong projection on its first frame** (Patch). `rootWidth` starts at 0 and `isCard` waits for the first ResizeObserver measure (`src/components/data-table/DataTable.vue:70-88`, `composables/useDataTableResponsive.ts:30-41`). A responsive table mounted in a narrow container therefore renders the table projection first and then flips to cards: an instant change in height and shape. Any remount shows it, and the demo's State switch remounts. The demo now holds the swap box's height at narrow widths, so only the cross-fade shows. The cure is to measure before the first paint (a synchronous read in `onMounted`, or a container query), so the first frame is the right projection.
- **New: SortableHandle has no default glyph** (Patch). It renders an empty `<button>` with only its slot (`src/components/sortable-list/SortableHandle.vue:24-34`), while the README's own example writes `<SortableHandle />`. Mounted as documented, the handle is invisible. Either the handle ships a default grip, or the README shows the slot filled.
- **New, against the motion law** (Patch):
  - InfiniteScroll's end line mounts by `v-if` with no transition (`InfiniteScroll.vue:77-82`).
  - Timeline's `#detail` pane is re-keyed per segment with no transition (`Timeline.vue:373`), so the detail swaps in one frame on hover or select.
  - The demo does not wrap either one to hide it.
- **Metric posture spacing, observed.** At `size="xl"` the stacked readout's value (line-height 1) overlaps its label's box, and the unit sits far from an empty value because of `min-inline-size: 3ch` (`src/components/metric/styles.css`). The page uses `lg`, where nothing overlaps. Reported, not filed as a row.
- `src/composables/sidebar/types.ts:12` still names `demo/composables/virtual` in a comment. The file is under `src/`, so I left it.

## Scaffolding notes (not patched)

1. **Checker B2** counts text clipped by a scroll port (the two failures above).
2. **Card fit is measured only on a resize.** `SectionPreviewCard.vue` re-measures when the plate or specimen box resizes. A specimen whose content grows wider while its own box keeps its size (the metric grid, centred, overflowing on both sides) is never re-measured, and overflow to the left never counts in `scrollWidth`. I worked around it in my stage (one column under 20rem) rather than in the card.
3. **Card height for scrolling stages.** A `tall` stage that fills its box with `block-size: 100%` gets no height on a card. I used `[data-card-specimen]` from my own stage files. A card-height custom property from the scaffolding would be the cleaner hook for P13.
4. **The spacing scale stops at `--sp-6`.** A stray `--sp-8` silently invalidates a whole `gap` declaration.
