### Where I read ROUTES.md loosely

Each of these follows FORM.md's "a row never repeats what the stage already shows".

- **Slider.** ROUTES.md names one row, "Standard · Spectrum". The stage is the standard slider, so the row is "Kinds": range and spectrum.
- **Toggle.** ROUTES.md names one row, "Single · Multiple". The stage is the single group, so the rows are "Multiple" and "States".
- **Labeled Field.** ROUTES.md names one row, "Input · Slider · Switch". The stage is the Input anatomy, so the row is "Controls": Slider and Switch. A separate Label row would have repeated the stage's required and optional marks, so I left it out.
- **Select.** ROUTES.md names "Short list · Long list". The switch's options read "Short" and "Long" under the label "List".

### Motion

Every state the pages author is tweened:

- **Select's switch** is P1's `StageSwap`. Per frame (`shots/P7/select-swap-frames.txt`), opacity runs 1 → 0 → 1 over about 330 ms at 1440 and at 390, with intermediate frames on both legs. The stage height does not change.
- **Removing the Draft chip** fades it out in place (opacity and scale, the fast duration). Its seat is kept, so nothing beside it moves. It fades back after 1.6 s. Sampled: largest step per frame 0.14 to 0.16 of the travel, in all cells.
- **The code disclosure** opens monotone on all nine pages in all three cells. The largest step per frame is 0.08 to 0.17 of the travel.
- **The field states** (invalid, focus) are the library's own control transition.

## Not done, and why

1. **`demo/stories/compositions/form-validation.vue` is not deleted.** PACKETS rule 4 has P7 delete it. Its row is still in `compositions/routes.ts`, which is P12's, and `makeLazy` throws on a row whose module is missing, so deleting it here would take down the whole site. `tests/demo/skip-link.a11y.test.ts` also reads it. It goes once P12 removes the row, or in P13.
2. **No error line on the Inputs stage.** FORM.md allows no authored text in a stage, and `Input` has no error slot. The invalid state is shown by the field's own invalid edge and `aria-invalid`. The error line with its message is on Labeled Field, where it is the component's own slot.
3. **Slider stands on the plain plate.** The old page put each slider in a static aurora raster. FORM.md lets a glass subject have a field, but `StoryStage field` mounts a live Aurora, and the shell would then start a second canvas (P3's focal.ts gap). The plate reads clearly in both themes (crops).
4. **No WebKit**, by machine law. The checker only measures contrast on header and label runs, so library runs in light (F3) were not measured here.

## Library faults met

- **F3** (muted ink in light). Chip's resting ink is `text-muted-foreground` (`src/components/chip/chipVariants.ts`, BASE), and so are LabeledField's description and the Slider's marks. The page leaves them as they are.
- **F4a** (disabled ink). The disabled instances on Inputs, Textarea, Select, Checks, Toggle, Number Field and Chip are painted at the library's disabled opacity. WCAG exempts them; they are left.
- **New, against the motion law (Patch).**
  - `LabeledField`'s error line mounts and unmounts by `v-if` with no tween (`src/components/labeled-field/LabeledField.vue:64-71`).
  - On `/forms/labeled-field`, fixing the email makes the error line vanish and the field's height drop in one frame.
  - The demo does not wrap it to hide this. The cure is a height-and-opacity tween on the error row in the library.
- **New, observed (Patch or 11.2.0).**
  - At 390, Select's long list opens as a panel the full viewport wide and 812 px tall, with its right edge on the screen edge.
  - At 1440 the same list is a 288×565 floating panel.
  - The narrow placement is the library's (`SelectContent` positioning). A release seat should judge it against the form's 16 px gutter.
