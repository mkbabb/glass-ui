## Library faults met, not yet measured

These are read from source. A release seat confirms each by measurement.

- **New: Dialog has no scrim weight.** The scrim is always `bg-overlay-scrim` (`src/components/dialog/ModalOverlay.vue:80`). The Scrim switch therefore sets the public token `--overlay-scrim` on `body` (the portal's parent) while the stage is mounted, and removes it on unmount. This is the demo's one token write outside the pager's F6 rule. A `scrim` prop on `DialogContent` would remove it.
- **New, motion law (likely): ExpandableContainer's exit is not tweened.** The birth has a keyframe (`expandable-container/styles.css`, `expandable-container-birth`). Collapse switches `data-state` with no exit leg. The probe's `expand-exit` sample is written to confirm this.
- **F3:** muted ink in light, inside the menu and command rows and the dialog description. Not measured.
