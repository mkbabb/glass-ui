## 4 · Next-pass defect classes (no row added)

1. **A placement written in the wrong unit frame.** `placeLens` reads painted px (`getBoundingClientRect`, `paintedScale`) and writes CSS px on an element whose CSS px are scaled by an inherited `zoom`. `paintedScale` walks `transform` and `scale`, not `zoom`, and `offsetHeight` is unzoomed. Placed: CK-20 (§0 item 5); the cure is E's. The witness gap is H11's: E-10's `loupe side` and E-13's clock cells carry `none | translate | scale`, never `zoom`, so the candidate passes every gating cell while failing under `zoom`.
