## 1 · What changed in the read

H7 counted a write only when the value was the literal `flush` or `plated` (`sheet.mjs:37,56,61` at H7). The pass-7 critic found three spellings that write a tile and passed both static halves (`D′c7` §3.1):

| spelling | where the critic planted it | why H7 missed it |
|---|---|---|
| `crit-var-writer` | `.card > .toggle-group { --selection-tile: var(--card-tile, flush) }` in `base.css` | the value is not the literal |
| `crit-static-style` | `style="--selection-tile: plated"` on `ToggleGroup.vue`'s root | the regex wanted a quote before the value |
| `crit-ts-ternary` | `el.style.setProperty("--selection-tile", on ? "flush" : "none")` in `shape.ts` | the regex wanted a quoted literal after the comma |

H8 counts **any `--selection-tile` write outside the route's one rule whose value is not `none` or `inherit`** (quotes and `!important` aside), as L-1 specifies:
- **Sheets** (`.css`, `.vue` `<style>`; postcss): a declaration whose value is anything but `none` or `inherit` is a write.
- **Code** (`.vue` outside `<style>`, `.ts`): comments are blanked first, keeping line numbers (`<!-- -->`, `/* */`, `//` not preceded by `:`). The property name in a writing position, followed by `:` or `,`, is a write. That covers a binding key, a static declaration, a `setProperty` first argument and a utility. Its value is read to the declaration's end, so `on ? "flush" : "none"` is one value and counts. A read is not a write: `getPropertyValue("--selection-tile")` and `var(--selection-tile)` are followed by `)`, and `style(--selection-tile: …)` is excluded by lookbehind.
