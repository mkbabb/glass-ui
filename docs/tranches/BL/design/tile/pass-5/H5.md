### H5-1 · CANON sees the cascade (row R-7; M-14)

`canon.mjs` keeps H3-4's 48 twins and its walk of every sheet, and changes what it decides:

- **Containers.** Each rule's enclosing `@container [name] <condition>` is evaluated against the twin's own query container: an unnamed style query's container is the subject's parent (every element is a style container), a named one the nearest ancestor whose `container-name` lists it. The evaluator reads `style(--p: v)`, `style(--p)`, `not`, `and`, `or` and parentheses against the container's *computed* value, so the engine's own cascade decides the fact (an unlayered reset after the layer is seen as it paints). Any other condition is UNEVALUATED, which fails the `unmatched` law; it is never "no reach". This is F3-1's cure.
- **Cascade.** The corner a twin wears is the winner among the rules that reach it, ranked by importance, then cascade layer (unlayered above every layer for a normal declaration and below every layer for `!important`; a later layer above an earlier one, reversed for `!important`; a declaration directly in a layer above that layer's sublayers), then specificity (Selectors 4: `:is`/`:not`/`:has` the max of their arguments, `:where` zero), then order. `@media` and `@supports` are evaluated on the page; `@scope` is read with its root and limit. This is `D′p` N-2's cure.
- **Reach.** Every rule that sets `border-radius` or a corner longhand and reaches an item counts, whatever its selector names (`D′c` §5.2 `foreign`). A rule whose subject is a pseudo-element sets that pseudo-element's corner and is listed, not ranked. Twins carry `pill-row` (floor v3's item class).
- **States.** The winner is read at rest (state pseudo-classes as written, which match nothing on an idle twin) and engaged (stripped, as the pass-2 unit did).
- **Law.** (1) exactly one rule reaches a tile and not its pill twin, on `var(--radius-field)`; (2) every tile twin wears `var(--radius-field)` at rest and the field corner or `inherit` engaged; (3) every pill twin wears `var(--radius-pill)` at rest and the stadium or `inherit` engaged; (4) nothing unmatched or unevaluated.

The fixture's sheet is now floor v3's shape: the registered fact, `.toggle-group { none }`, a declaration writing `flush`, the stadium, and the field corner as a layered `!important` under `@container not style(--selection-tile: none)`. Its clean read passes all four laws only because the container condition is evaluated. The plants are spelled on the route's `canon.sel` on a build:

| plant | what it is | the cell it fails |
|---|---|---|
| `a`, `s` | H3-4's: a second tile corner, unlayered; a `sm` arm on `--radius-panel` | tile corner |

| **`layer`** | `D′c` §5.2: an unlayered `.toggle-group { --selection-tile: none }` after the layer | tile corner and tile winner ("no rule declares the tile"; container facts `none/none`) |

### H5-2 · FACT reads the write-site × read-site matrix (rows R-10, R-2)

A new composition, `matrix`, in `attack-route/migrated.mjs`, mounts as `matrix-migrated` on every attack build. `scenes.mjs` now renders a route site that is no consumer site as `<site>-migrated` as written, and gives the template `mx(site)`, the inline write `?w=<site>&v=<value>` asks for **at mount**, so a development name sees it. The composition carries both routes' declarations, like the rest of the attack set: a **tile group** (`shape="cell"` and a filled `#meta` on every option) and a **pill group**. Each has a direct option, an option behind a wrapper `div`, and an option that holds a nested group of the other kind (a pill group inside a tile option, a tile group inside a pill option). Every option's content is two block rows (`[data-mx-content]`), which the pill's one-row law runs inline, so a reader that splits the fact shows in the rows.

The seven write sites are `ancestor`, `group`, `wrapper`, `option` (the direct option), `content` (the direct option's content span), `nested-group` (the root of the group inside the third option) and `nested-option` (that group's first option). The values are `none`, `flush` and `plated`. Light reads the 6 references and 7 × 3 × 2 = 42 written cells; dark reads the 6 references and the two option cells. That is 56 cells, beside FACT's 12 H4 cells.

Each cell is judged by **paint**: the used corner (CSS Backgrounds §5.5), the box against that option's unwritten reference, the text rows, the rows inside the option's content, the children the pill's label rule clips, and content cut past the box. On a development flavour the names the read option draws also gate. A name on a correct option is a false name or a split. **The item's computed fact is never read**, since a pinned value would print as agreement (`D′c` §4). What each site must read:
