### H6-4 · FACT reports `none!` at `option` (row E-3; reported, not gating)

- **Write.** `?w=option&v=none!` writes `--selection-tile: none !important` inline on the tile group's direct option, at mount and before ready, through `style.setProperty(…, "important")` (`scenes.mjs`). Vue cannot do it: its style binding hands a custom property's value to `setProperty()` whole, and a string style on a component is parsed into the same object. The CSSOM then drops a value that carries `!important`. This seat's first read found it so: the write did not land, and the cell read "the write did not land" (an exploration run, superseded; §2.1).
- **Read.** Light only. The cell is printed `info-pass` when the paint is the split FV5-3 states, and `info-fail` otherwise:
  - the geometry follows the group: the field corner ±0.5 px and a column;
  - the option's own readers take the write: more children clipped than the reference, or its content's rows changed.
- **Fixture and plants.** The fixture writes the same `!important` inline. **Plant `atk-bang-soft`** drops the `!important`, so the pin refuses the write and the option reads unchanged: info-fail. **Control `atk-bang-ref`** is the clean page, which must exit 0 with the line `info-pass`. `selftest.mjs` learns `expect: "info-fail"`: exit 0, and the planted cell printed `info-fail`.
