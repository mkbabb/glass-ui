### 5.2 · Limits (also in `HARNESS.md` §4)

- **M-1x has no hue term.** A plate transmitting a coloured ground passes the colour clause (HEAD over the deep canvas). Its paper clause reds a cream card 0.001 under the L floor, as M-1 does. Q-11's ruling may sharpen both.
- **M-2h's halo leg reads any thinning of the held dock**, the grasp's designed shed included. It becomes a halo witness when the veil is held on the carriers (FL-7, FL-14), which is floor v2. N-3 decides cured or attributed on floor v2's reading.
- **The declared-graspable test** reads the host's own formers, not ancestors' (the library arm's slice).
- **W-S is inert at HEAD and floor v2.** It discriminates only on a route with a thinning arm (C″).
- **W-C's loud arm** counts console errors and warnings against the base cell, so an unrelated warning in the retuned cell would pass it.
- **GLANCE `--story-claim`** needs a claimed element with a painted box of at least 8 × 8 px.
- **Drift frames** are a screenshot every 2 s, so a dip shorter than 2 s between samples is not seen. The motion and step legs cover short dips.

## 6 · H3-11, the unit arm for the floor v2 seat

The A′ arm (`D3-Ap-proto.patch`, `tests/styles/glass-subtlety.test.ts`, "seats every PLATE host as a stacking context") passes any `z-index` digit. The floor v2 seat lands this replacement in place of it. STACK is its paint-side counterpart, and the arm is the static one:

```ts
it("seats every PLATE host as a stacking context, so its carriers' veil stays under its content", () => {
    // A z-index forms a stacking context only on a positioned box or a flex/grid item; a host whose parent
    // display is unknown here must be positioned, or form one by isolation, contain, or a transform.
    const FORMS = [
        /(?:^|[;{\s])isolation\s*:\s*isolate/,
        /(?:^|[;{\s])contain\s*:\s*[^;]*\b(?:paint|layout|strict|content)\b/,
        /(?:^|[;{\s])transform\s*:\s*(?!none)/,
    ];
    const positioned = (b: string) => /(?:^|[;{\s])position\s*:\s*(?:relative|absolute|fixed|sticky)/.test(b);
    const zIndexed = (b: string) => /(?:^|[;{\s])z-index\s*:\s*-?\d/.test(b);
    for (const host of graspHosts) {
        const bodies = hostRules(host.classes).map((r) => r.body);
        if (!bodies.some((b) => /@apply[^;]*\bglass-plate\b/.test(b))) continue;
        const all = bodies.join(";");
        expect(
            (zIndexed(all) && positioned(all)) || FORMS.some((re) => re.test(all)),
            `${host.file}: ${host.classes.join("/")} mounts the carriers but forms no stacking context (a z-index alone is not one)`,
        ).toBe(true);
    }
});
```

Its plant is the counterexample from A′ critique §3.4: a host rule with `z-index: 1` and no `position`. It reds there, and the old arm passes it.
