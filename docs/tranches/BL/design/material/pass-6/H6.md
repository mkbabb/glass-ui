## 6 · Known limits this seat leaves

- **The cited exception is narrow by construction.** Only `capture.mjs`'s live, motion and drift windows take `CHROMIUM_FIELD_ARGS`. Every cell, glance and probe runs on the shell's default. A new witness that wants the moving field must read those windows or carry its own citation.
- **DEL reads names, not meaning.** A deleted mechanism described in new words passes it. The declaration is the patch's, so each patch's seat writes it. The minor split declares none: it deletes no mechanism (the clamp lives in the minor), and its light-law rewording is R-13's, read by its own `grep`.
- **LAW reads code lines, not comments**, so prose may name a flag. A launch assembled at runtime from fragments (as the self-test's plants are) is not seen. The machine guard's own process watch is the backstop.
- **The pass-3 record `pass-3/D3-Cpp-proto-computed.mjs:24`** carries the old GPU arguments uncited (`LAW --root material` reads it, `static.log`). It is a record, not a tool any pass now runs, so LAW's default roots exclude it.
