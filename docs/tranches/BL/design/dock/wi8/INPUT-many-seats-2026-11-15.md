# Input to the dock loop: many seats on a phone (O-358, 2026-11-15)

A consumer (a Home Assistant dashboard) has a dock with five tabs plus two avatar seats. At 360 to 390 wide it shows the current tab, one more and a sliver; the rest is reached by scrolling the run. It asks whether there is an intended compact form: icon-only seats, or an overflow seat. Speedtest and gaggle reported the same class (controls clipped at 360 to 430). The design should say what a dock does when its seats do not fit: one rule, not a per-site choice.
