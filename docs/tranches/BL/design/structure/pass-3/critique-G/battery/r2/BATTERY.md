Two instruments, both in this directory:

- `probes.mjs --tree T [--base B.json] [--out O.json]`: measurements over a tree, using the tree's own floor (`T/scripts/structure/lib`, else the checkout's `floor/lib`). `--snapshot` writes the base numbers that a later run compares against.

A plant is CAUGHT when the gate exits 0 on the unplanted tree and non-zero on the planted one. If the unplanted gate already exits non-zero, a plant is CAUGHT only when a new output line names the planted path. A legal probe (L*) must leave the exit and the output unchanged.
