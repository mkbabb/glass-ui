## Lane III — Subpath typing-gap P0 + v0.9.4 release

**The K.WS subpath typing-publication gap** (Rα P0-1; Rε A2; Rβ L17): vue-tsc resolves `dist/composables/{dark,keyboard}.d.ts` via a broken `'../src/...'` re-export. Consumer `vue-tsc` raises `TS2305: Module has no exported member`.

### Step 1 — Diagnose the dts emission

Inspect `dist/composables/dark.d.ts` + `dist/composables/keyboard.d.ts` at HEAD (post-K-close, v0.9.3). Confirm: they contain `export * from '../src/composables/dark'` (or similar broken re-export). Glass-ui does NOT ship `dist/src/`.

Inspect `vite.library.ts` + `vite-plugin-dts` config. The dts plugin is treating the subpath barrels as re-exports of the source tree rather than self-contained dts emissions.

### Step 2 — Fix the dts emission

Two strategies:

- **Strategy A (preferred)**: re-author `src/composables/dark.ts` + `src/composables/keyboard.ts` so they re-export their canonical implementations directly (`export { useGlobalDark } from "./useGlobalDark"; export type { ... }`). Verify the dts plugin emits self-contained `dist/composables/{dark,keyboard}.d.ts` (no `'../src/...'` references).
- **Strategy B**: configure vite-plugin-dts to inline the cross-file types into each subpath dts. May require `rollupTypes: true` or similar plugin option.

Pick Strategy A (KISS).

### Step 3 — Synthetic-consumer typecheck probe

Author a scratch test in a temporary directory simulating a consumer:

```ts
// /tmp/glass-ui-subpath-probe/index.ts
import { useGlobalDark } from "@mkbabb/glass-ui/composables/dark";
import { useRegisteredShortcuts } from "@mkbabb/glass-ui/composables/keyboard";
import { Input, Textarea, Combobox } from "@mkbabb/glass-ui/forms";
const _x: ReturnType<typeof useGlobalDark> = useGlobalDark();
```

Run `cd /tmp/glass-ui-subpath-probe && npm init -y && npm i ../glass-ui && npx tsc --noEmit index.ts`. Verify clean exit.

### Step 4 — `scripts/release.sh` updated

Add a synthetic-consumer probe to `scripts/release.sh`:

```bash
# After build, before tag:
for sp in forms composables/dark composables/keyboard; do
  node -e "import('@mkbabb/glass-ui/$sp').then(m => console.log('$sp:', Object.keys(m).length, 'exports'))" || { echo "subpath $sp resolve failed"; exit 1; }
done
```

(Or a more rigorous scratch-tsc probe.)

### Step 5 — Bump v0.9.3 → v0.9.4 + release

`package.json` version `0.9.3 → 0.9.4`. `CHANGELOG.md` v0.9.4 entry: "fix: subpath dts publication gap (K.WS regression — vue-tsc couldn't resolve `dist/composables/{dark,keyboard}.d.ts` due to broken `'../src/...'` re-export)".
