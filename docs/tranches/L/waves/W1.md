## Purpose

K.WS Phase 1 (additive subpath split at v0.9.3) did NOT close the vueuse SCC trap. Per X.W3.c re-probe (speedtest, 2026-05-09): with vueuse manualChunk applied + v0.9.3 link, modulepreload reappears (1 directive), entry chunk drops to 139,748 B gz, vueuse leaf 33,579 B gz, **net +1.92 KB regression** — matching glass-ui's own audit byte-for-byte.

Mechanism: Rollup walks `src/index.ts`'s `export *` across vueuse-bearing leaves (Input/Textarea/Combobox*/useGlobalDark/useKeyboardShortcuts); the additive subpath surface doesn't break that walk because the root barrel still re-exports the same symbols. Identical to V.W1.T7 vue-echarts trap mechanism.

**Phase 2 fix**: remove vueuse-bearing symbols from the root barrel. Consumers must import them from explicit subpaths. Breaking change → v1.0.

Per Rε's combined recommendation, L.W1 bundles 4 transpositions into one HEADLINE wave:

1. **Root barrel curation** — `src/index.ts` strips vueuse-bearing re-exports (Lane A).
2. **`src/api/` discovery layer** — canonical public types + constants barrel (Lane B).
3. **Subpath flatten** — `@mkbabb/glass-ui/dark` + `/keyboard` over nested `/composables/dark` + `/composables/keyboard`; add new `/carousel` subpath (Lane C).
4. **dts publication coherent** — verified self-contained dts emission for every public subpath (continues W0 Lane III's fix).

## Lane A — Root barrel curation

Worktree-isolated (REQUIRED). Repo-relative paths only.

### Step 1 — Audit current root barrel surface

```
rg "from\s+['\"]@vueuse" src/components/ src/composables/  # find all vueuse-importers
```

Identify the closure: every file in `src/index.ts`'s re-export chain that transitively imports vueuse. Per Rε §B.1.2 and K W-S-vueuse-inventory.md: 14 direct vueuse-importers (Input, Textarea, 8 Combobox*, useGlobalDark, useKeyboardShortcuts, useCarousel).

### Step 2 — Strip vueuse-bearing re-exports from `src/index.ts`

Currently `src/index.ts` exports the entire ui/ + custom/ + composables/ chains. Remove or rescope:

- `useGlobalDark` — remove from root barrel; consumers use `@mkbabb/glass-ui/dark` (Lane C).
- `useKeyboardShortcuts` + `registerShortcut` + family — remove from root barrel; consumers use `@mkbabb/glass-ui/keyboard` (Lane C).
- `Input`, `Textarea`, `Combobox*` — remove from root barrel; consumers use `@mkbabb/glass-ui/forms` (already exists).
- `useCarousel` — remove from root barrel if Lane C adds `@mkbabb/glass-ui/carousel`.

Document the new curated root surface in a comment block at the top of `src/index.ts`.

### Step 3 — Verify SCC trap closed

After Lane B + Lane C land + the orchestrator integrates, run the SCC probe (similar to W0 Lane III's release script). Speedtest re-link → speedtest `npm run build` → `grep "modulepreload" dist/index.html` should return empty. Entry chunk gz should drop ≥ 15 KB vs pre-WS baseline.

## Lane C — Subpath flatten + carousel subpath
