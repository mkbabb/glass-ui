- Re-run β-style overfitting audit at HEAD with visual-load-bearing-ness probe.

- Re-run δ-style idiomatic-gestalt audit at HEAD with per-story consumption sweep.
- Re-run recovery-diary canonical grep against src/ + demo/.
- Re-run Playwright probe at ≥ 3 viewports (375×667, 1024×768, 1440×900) over canonical surfaces + every L-modified surface.
- Re-run ι integrity-sweep: walk L.md prescriptions + wave-spec hard gates + K residuals + Rβ chronic-deferrals + L invariants + `git reflog` (new in L W0).

- Verify PROGRESS.md status entries match reality.
- Verify `MIGRATION.md` is comprehensive vs L W1 + W2 + W3 + W7 breaking changes.
- Stage `audit/L-pre-close.md` listing every artefact's final disposition + commit hash.

### B. 7-agent post-close audit (strengthened, parallel)

Per the canonical pattern:

- **Lane α — plan-vs-actual**: walk every wave spec line-by-line against PROGRESS.md + close docs.
- **Lane β — substrate-without-consumer (visual-load-bearing-ness)**: re-run overfitting audit with rendered-state probe.
- **Lane γ — doc-drift**: walk DESIGN.md + CLAUDE.md + README.md + CHANGELOG.md + MIGRATION.md + PROGRESS.md + each wave-spec status line + L.md against current source.
- **Lane δ — idiomatic gestalt + per-story consumption sweep**: walk every L-introduced CVA/utility/token; grep demo/ for canonical consumption.
- **Lane ε — performance**: re-run bundle audit; verify dts emission (every public subpath self-contained); verify bundle-budget gate at v1.0 baseline; re-measure speedtest's SCC trap status.
- **Lane π — visual-runtime (multi-viewport)**: 3 viewports × every L-modified surface + canonical baseline.
- **Lane ι — integrity-sweep**: walk L.md prescriptions + wave-spec hard gates + K residuals + Rβ chronic-deferrals against artefacts at HEAD. PLUS `git reflog` scan (new in L per W0 SPEC clause).

Each lane writes `docs/tranches/L/audit/L-audit-{α,β,γ,δ,ε,π,ι}-*.md`.

### C. Findings absorb

For every accepted finding:
- **Doc-only fix**: orchestrator applies in W8 (within-wave absorb).
- **Source fix**: open a residual entry in `audit/L-residuals.md` with named M-tranche destination.
- **Gestalt fix**: same as source-fix.
- **ι-flagged silent miss**: P0 — must absorb in W8 before FINAL.md is final.
- **MIGRATION.md gap**: P0 — must absorb in W8 (v1.0 ship requires complete migration guide).

### D. FINAL.md authoring

After clean audit returns, write `docs/tranches/L/FINAL.md`:
- Tranche thesis, opening + closing date.
- Wave-by-wave table with status + commit hash + close evidence.
- Substrate convergence stats: residuals absorbed; chronic deferrals closed; orphan tokens decided.
- Process hardening stats: precept files updated (5 lessons + 3 SPEC clauses + 1 dispatch field + 1 ORCHESTRATION clause from W0; any further from W8).
- Architectural transpositions executed (W1 HEADLINE; W7 aurora unification + keyframes lift; W2 modularization).
- v1.0 cohort summary: breaking changes shipped; migration path documented.
- Cross-tranche debt + named-destination residuals (L residue list — should be small after L's binary substrate-without-consumer rule + v1.0 freeze).
- Brittleness windows (W1 declared; restored via MIGRATION.md).
- Cross-repo: speedtest Y.A3 disposition, speedtest re-link commit.
- Authority — L closes clean.

### E. Lessons-learned reconciliation

Append any new process-failure incidents to `docs/precepts/instructions/LESSONS-LEARNED.md`.
