# Orchestrator note: CHANGELOG prose

The owner added a second rule on 2026-11-05 for anything consumers read, the CHANGELOG included.

Don't write telegraphic lead-ins or squeezed summaries, such as label-colon fragments, verbless tallies, noun stacks, or sentences with the subject or reason cut out. Write each item as a full sentence you would say out loud: say who does what, use the verb, and keep the "so" or "since" that carries the reason.

A colon may end only a sentence that is already complete without the list after it.

So "Removed: --scale-hover-dock." becomes "We removed the --scale-hover-dock token, so a stylesheet that sets it should drop that line."
