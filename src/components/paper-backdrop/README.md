# PaperBackdrop

`PaperBackdrop` is the semantic mount for the shared `paper-underpaint` content-field recipe,
exported from `@mkbabb/glass-ui/paper-backdrop`.

```vue
<PaperBackdrop />
```

The component adds no material variant or per-instance paint controls. Retint or attenuate the
global paper variables at the owning route when the field needs a different context.
